# 默认清单封面

- `playlist-favorites.png`：我喜欢，石墨底色上的书签与低饱和玫瑰色爱心。
- `playlist-watch-later.png`：稍后观看，相同材质的时钟与低饱和蓝色播放符号。
- `playlist-recently-played.png`：最近播放，灰色历史回转箭头与低饱和灰绿色播放符号；使用用户确认的第 1 张独立方形方案，中央主体约占 57%，背景与前两张同一材质。

由内置 Image Gen 生成，沿用用户选定的第一组设计；分别生成独立、无文字、无外部圆角框的方形资源，再校准图案比例。最终编辑要求为：保留底色、形状、材质与光照，仅调整中央图案大小；书签约占宽 43%／高 55%，时钟播放组合约占宽高 57%。圆角与边框由 `PlaylistCover` 提供，不能把设计展示板、清单名称或其他封面一起放进图片。

资源在 renderer 中打包，全局内置清单使用 `system_kind`，本机最近播放使用 `local_kind`；不依赖名称、不写入数据库，也不通过 `media://` 请求。自定义封面优先；默认图案不应用隐私模糊，自定义图片保持原有隐私处理。全局清单的列表、详情与选择器使用同一资源，本机最近播放不作为手动添加／导入的目的地。
