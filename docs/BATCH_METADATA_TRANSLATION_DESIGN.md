# 批量元数据翻译

用户可从桌面媒体库一次提交多部影片的简体中文翻译，后台生成标题和简介的译文，并选择预览后确认或翻译后直接应用。领域词汇沿用[领域上下文](../CONTEXT.md)，持久化与写入边界见 [ADR-0034](adr/0034-stage-metadata-translations-on-originating-desktop.md)。

## 发起与运行

1. 在媒体库多选影片，点「翻译元数据」。弹窗显示来源媒体库、选中影片数和将使用的模型。默认选择标题和简介，可单独取消。「翻译后直接应用」开关每次发起时默认为关闭，开启时明确提示新译文会替换资料库里的所选字段原文。云端模型显示原文会发送到所选服务的说明。
2. 点「开始后台翻译」。提交成功后弹窗自动关闭，并显示一条消息。标题和简介按字段处理。空原文和相同译文计为跳过，单个字段失败时显示原因并继续其余字段。
3. 在「任务中心 → 翻译」查看当前资料库中的影片翻译任务。关闭弹窗、切换页面、最小化或应用仍驻留托盘时，后台继续。每部影片可单独暂停或继续。已开始的字段可完成，其余影片继续执行。退出后保留草稿和进度，重启后按影片继续。
4. 任务沿用提交时确认的模型。模型不可用时暂停对应影片并说明原因。「换模型继续」展示新模型及其本地／云端属性，经确认后用于该影片未生成或明确重译的字段。已生成的译文仍可预览与应用。

影片刮削设置中的「刮削后自动翻译」仅对本次任务生效。勾选标题或简介后可开启，实际写入的非空文本会进入同一翻译队列。默认生成待审译稿，也可单独开启「翻译后直接应用」。有多个刮削候选时，在发起任务的桌面确认候选后再翻译；放弃候选会一并取消这次翻译请求。

## 预览、审批与应用

- 翻译列表按影片任务计数，同一任务的标题与简介始终一起展示。标题完整显示。简介的原文或译文超过三行时，可在任一列展开或收起，两列同步切换。因译文与原文相同而跳过时，状态下直接显示原因。有详细说明的状态带信息图标，点击可查看完整原因。
- 「进行中 / 暂停」管理排队、翻译、暂停和正在应用的任务。可全部开始、全部暂停或确认移除。开始和暂停控制后续翻译，正在写入媒体库的任务受保护。
- 「需处理」优先收纳含待确认译文、失败、冲突、应用受阻、资源移出或缺失、待核对回执的任务。可逐字段处理，或跨影片应用勾选的译稿。影片还有排队字段时仍可单独暂停和继续。
- 全部字段均已应用、跳过或丢弃时，影片任务归入「已完成」。清空记录只清理本机翻译历史。批量操作覆盖当前筛选的所有分页，确认后再次按任务状态检查资格。
- 若影片的字段均已跳过或丢弃，且没有原文和译文可对照，列表用一行显示各字段的结果与原因。番号旁的信息按钮可查看来源媒体库、模型、应用方式和提交时间。
- 标题和简介均在译文列内使用多行文本框编辑。编辑框按内容和列宽自动增减高度，最多占窗口高度的 45%，更长的译文可在框内滚动。手动上下拖动后，本次编辑使用手动高度，重新打开时再按内容适配。「保存」更新草稿，保存后可直接应用，也可勾选后批量应用。编辑时可用 Ctrl／⌘ + Enter 保存，按 Esc 取消。单字段重译期间保留旧草稿，成功后重新勾选，失败时可查看原因并再次重译。原文冲突显示媒体库中的当前原文及基于旧原文的译文。
- 字段默认不勾选。可按影片或字段勾选，表头复选框负责跨页全选和取消全选。待确认、失败、冲突、应用受阻和资源移出或缺失的字段均可勾选。操作栏统一显示已选字段数，仅部分可应用时补充可应用数，全部不可应用时显示原因或提示。「应用所选」只提交待确认译文，其余字段继续保持勾选。
- 「丢弃所选」在确认框中列出影片数和字段数，确认后将这些字段标记为「已丢弃」并清除本机译稿。确认使用打开弹窗时选定的版本，任一字段已变化时整次操作取消，需重新勾选变化的字段。已写入媒体库的资料与其他字段会保留。
- 单条审批可直接点击标题或简介行的「应用」，只写入该字段当前保存的译稿，其他字段的勾选保留。编辑中需先保存或取消，再应用。写入受阻时，同一位置提供「重试应用」。
- 批量审批使用「应用所选」。点击时冻结所选字段及待确认译文版本，可在剩余字段继续翻译时提交。已应用、已跳过和已丢弃是字段的结束状态。
- 应用后反馈成功、原文冲突、被待确认刮削锁定、影片已移出来源媒体库或已删除等结果。已应用项刷新媒体库和影片详情。一个字段受阻时，继续处理本批中其余符合条件的字段。

## 翻译后直接应用

- 开启开关并提交任务，即授权将本批选定字段的新译文直接写入。译文生成后执行常规应用校验，已写入的结果在影片的字段行中显示为「已应用」，仍可查看原文和译文。
- 原文冲突、刮削锁、影片归属变更或确定的写入失败会保留译文供用户处理。需要按新原文重译或手动修改时，新译文进入待确认流程。已存在于其他批次的译文仍按原批次的流程处理。
- 批次保存本次应用方式。暂停后继续生成时沿用本次授权，发起下一批时开关重新显示为关闭。

## 重复发起与资料变化

| 场景 | 处理 |
| --- | --- |
| 同一资料库、同一影片和字段已有排队项或待确认译文 | 提交消息提示已有记录。主动选择「重新翻译」才执行新推理。标题和简介独立检查。 |
| 重新刮削、手动编辑或清空改变了待应用字段的原文 | 标记原文冲突。可根据当前原文重译。评分等其他字段的修改不构成原文冲突。 |
| 影片离开来源媒体库，其他媒体库仍引用它 | 保留预览并标记状态，跳过本批写入。可从当前所属媒体库重新发起，旧结果不阻挡新任务。 |
| 影片删除、ID 被复用、切换资料库或恢复了不同资料库 | 保护原目标身份，阻止向其他版本的影片或资料库应用。 |
| 同一远程资料库在两台电脑上各有译文 | 草稿留在各自设备。先提交的有效译文写入共享资料，后提交的设备按当前原文重新校验。 |

## 实施边界

- 桌面主进程持有任务和推理生命周期。沿用文本翻译模型配置、代理和推理路径，单设备顺序执行待生成字段。按字段保存进度。暂停某部影片后，队列跳过该影片的后续字段，已经发出的模型请求按其结束状态结算。
- 提交设置、影片的暂停状态和模型选择、逐字段草稿及应用意图落在现有桌面工作存储 `desktop-work.db`。身份包含资料库标识、远程服务端标识、来源媒体库 ID、影片 ID 与影片代次。模型记录保留引用、本地／云端属性和连接身份，凭据仍由现有模型管理读取。
- 通过 `CatalogBackend` 写入。由本机或远程的权威维护端在同一个影片事务中校验写权限、目标身份、媒体库成员关系、待确认刮削锁和每个请求字段未经归一化的原文，再提交符合条件的译文并递增影片版本。写入字段是标题、简介及版本和更新时间，遵守既有累计刮削状态和刮削时间规则。原文比较覆盖[清空元数据时影片版本未递增的路径](../packages/library/src/db/videoRepo.ts#L1748)。
- 每次应用时，桌面为提交的影片生成操作 ID，并随授权范围内的字段和译文版本一同保存，再发起写入。连接或进程中断时，用同一操作 ID 查询回执或重试同一请求。按回执更新对应草稿版本，避免重复应用或把较新的草稿误记为已应用。配套远程管理合同随桌面版一起实现。
- 「任务中心 → 翻译」集中管理进度与待确认译文。概览按影片任务计数。每页最多读取 20 部影片的字段文本，跨页勾选保留确切的译稿版本。

## 验收场景

- 多选影片提交标题和简介，离开媒体库后继续生成。关闭应用再启动，已生成结果仍可预览，手动继续其中一部时，只处理该影片的未完成字段，其余暂停任务保留原进度。
- 在运行中编辑某部影片的标题译文并应用。简介原文仍在，新增译文没有加入刚才确认的范围。跨页勾选两次提交的影片后应用，核对每个已选字段。
- 验证开关默认关闭，生成结果进入待确认。开启后，合格的新译文直接应用，发生冲突的译文保留供处理，已存在于其他批次的译文不受影响。重启后继续同一批沿用原模式，新批次仍默认关闭。
- 重启后核对手动校对的草稿和未完成字段，按影片重试未收到回执的写入。单字段失败可重试，主动重译失败保留旧译文。重复发起时提示已存在的字段。从本地模型切换云端后，已有任务继续沿用提交时确认的模型。
- 审批之前修改标题、清空元数据或移出来源媒体库，分别得到正确反馈。用更新评分验证无关修改仍可应用。含待确认刮削结果的影片遵守现有锁定。
- 验证本机资料库和可编辑的远程资料库。用两个远程设备对相同原文并发应用，验证后提交的旧译文被拦截。模拟写入已提交但回执丢失，确认重试后只有一次资料变更。
- 1440×900 和 1000×640 下验证浅色／深色、长简介的滚动与对照、批量勾选及键盘操作。
