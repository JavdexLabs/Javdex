# 局域网 Web 访问

## 使用方式

1. 在桌面端打开 **设置 → 网络 → 局域网访问**。
2. 设置访问账号与独立的 12–128 字符密码，选择端口（默认 `8096`），开启服务并保存。
3. 让手机、平板、电脑或电视连接同一局域网，在浏览器打开桌面端显示的非 `127.0.0.1` 地址。
4. 在桌面点击「开启配对（5 分钟）」，新设备网页选择「与桌面配对」，填写设备名称并获取六位码。
5. 在桌面输入该码，点击「核对设备」，确认名称、来源地址及只读范围后批准。新设备会自动进入媒体库。也可切换「密码登录」使用原有账号密码。
6. 手机可扫描桌面「手机扫码打开访问地址」中的二维码打开网页；二维码不含登录凭证。电视只需显示配对码，无需用遥控器输入密码。

勾选「记住此设备」可跨应用重启保持登录，仍受闲置 24 小时与原始授权起最长 7 天的期限限制。临时登录不跨应用重启保留。桌面设备列表自动刷新，可查看和修改设备名称，查看最近访问与到期时间，并确认后逐台撤销。设备名称由浏览器提供，仅用于辅助核对。

可浏览、搜索、筛选和播放；资料编辑、扫描、刮削及资源管理仍在桌面端完成。

服务默认关闭，跟随 Javdex 桌面进程运行。在“设置 → 外观与隐私 → 窗口行为”开启托盘开关后，关闭窗口仍可继续提供 Web 访问；从托盘菜单选择“退出 Javdex”才会退出应用。退出应用即停止；下次启动会恢复已保存的启用配置。系统可能要求允许防火墙访问。如果端口被占用，可更换端口并保存或重试启动。

## 浏览范围与播放

- 提供活动媒体库中未隐藏的影片、包含这些影片的清单、演员与标签筛选、搜索、排序、年份过滤、分页及影片详情。
- 网页不开放编辑、删除、导入、评分修改、任务执行、磁盘路径或桌面 IPC；所有资料、图片和流媒体请求都需要有效会话。
- 已归档媒体库、隐藏成员及其独占资源不在 Web 可见范围。一个影片仍在其他活动媒体库可见时，其共享资料继续可见。
- 本地文件必须属于当前有效、启用的媒体库根目录。未关联根目录的旧资源需先在桌面端整理。
- MP4、WebM 等文件通过浏览器 `<video>` 原生播放，支持分段读取、拖动进度、浏览器原生音量和全屏控制。具体编码是否可用取决于浏览器及设备；容器扩展名不等于解码能力。
- HTTP/HTTPS 直连资源（包括 STRM 指向的直连视频）在认证后交由浏览器访问，不由服务器代理下载。目标必须无需 URL 用户名密码，播放仍取决于来源服务、浏览器和网络可达性。网页、磁力、ed2k 链接不提供播放。
- 不进行转码、HLS 打包、外部字幕转换或应用内播放进度写回。原生播放失败时可重试或换其他资源。

## 认证与网络

采用本地只读账号与服务端会话，参考 [Jellyfin 本地用户](https://jellyfin.org/docs/general/server/users/) 和 [OWASP 会话管理](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)：

- 密码通过随机盐和 scrypt 保存，仅保留哈希；配置保存在应用数据目录的 `web-access.json`，不通过普通设置快照或 Web 接口返回。
- 登录生成随机 256 位令牌，服务端仅存摘要。Cookie 使用 `HttpOnly`、`SameSite=Strict`；不把令牌放进 URL 或 localStorage。
- 会话空闲 24 小时或累计 7 天过期。记住的设备摘要与原始时间保存于权限为 `0600` 的 `web-devices.json`，不保存明文令牌；重启不重置期限。最近活动按分钟持久化。
- 退出登录、逐台撤销会撤销相应凭证；关闭 Web 服务、更改账号、重设密码或退出所有会话会撤销全部授权。普通应用重启、保存未更改身份的服务配置保留有效的已记住设备。
- 桌面逐台撤销只关闭目标设备的当前请求和播放连接；全部撤销才关闭所有 Web 连接。无法收回已下载的视频或浏览器缓存。
- 配对请求限时 5 分钟，批准后最多 60 秒内兑换且不延长原期限。六位码只用于桌面核对，兑换另需绑定浏览器的随机秘密，且只创建一个会话。授权响应丢失时，同一浏览器临时秘密可在原批准窗口内重新领取同一会话；仅短暂保留交付凭证，停止服务或全部撤销时清空，撤销后的会话不能再次领取。拒绝、取消、过期、服务重启或撤销全部授权均使待配对请求失效。刷新网页通过 HttpOnly 临时 Cookie 恢复配对；暂时断网后自动退避重试，倒计时使用服务端剩余时长，服务端决定过期。只有桌面能批准，普通只读浏览器没有授权其他设备的能力。
- 持久登录仍受浏览器 Cookie 清理和访问主机地址影响；局域网 IP 改变后需要重新登录，建议通过路由器保留固定地址。
- 撤销和重命名先原子保存再更新内存；写盘失败会保留原授权并明确提示“操作未生效”，可检查磁盘空间和权限后重试。设备文件损坏导致服务无法启动时，桌面提供「重置浏览器授权」，确认后清空设备记录、保留账号密码及媒体库，并恢复服务。
- 登录有每来源与全局尝试额度，以及并发密码校验限制。
- 仅监听 IPv4，接收局域网/回环来源；Host 必须匹配本机地址或 localhost。拒绝跨站 Origin / Fetch Metadata，所有认证 POST（含配对）还要求同源 Origin 与自定义请求头。不信任 `X-Forwarded-*`。
- **当前为局域网 HTTP**，因此 Cookie 不设置 `Secure`，传输内容也不加密。只在可信局域网使用独立密码，不要映射公网端口。此版本不支持反向代理或自定义域名认证入口；公网发布、TLS 与多用户权限属于后续独立范围。

## 开发与验证

独立 React/Vite 浏览器入口在 `src/web`，构建至 `out/web`，随 Electron 包一起发布；不加载桌面 renderer 或 preload。开发桌面应用前会自动构建 Web 页面。需要持续修改 Web 时，另开终端运行 `npm run web:dev`（监听并重建），刷新浏览器即可。

HTTP 模块在 `src/main/web`。`WebCatalog` 是只读目录适配层，输出显式 DTO；文件传输先按资源 ID 验证归属及真实根目录，再对打开的文件描述符复核身份，通过流式 HTTP Range 响应发送。它不接受任意文件路径或代理 URL。

```sh
npm run web:build
npm run typecheck
node scripts/run-electron-tests.mjs src/main/web/webServer.test.ts src/main/web/pairing.test.ts src/main/web/catalog.test.ts
npm test
npm run build
```

可选的浏览器端到端检查（需要 Chrome 和 PATH 中的 ffmpeg）：

```sh
node --import tsx scripts/web-smoke.mjs
node scripts/web-desktop-smoke.mjs
node --import tsx scripts/web-auth-recovery-smoke.mjs
```

第一个检查启动仅限回环的临时服务，使用合成目录和生成的三秒视频，不读取用户媒体库。在手机、平板、桌面、电视视口验证无横向溢出、网格列数、登录、搜索、详情、原生播放、返回、刷新和退出；截图保存在输出的临时目录。可用 `JAVDEX_WEB_QA_OUTPUT` 指定截图目录。第二个检查使用独立临时数据目录启动真实 Electron，验证设置入口、桌面批准配对、地址二维码、密码持久化、记住设备跨重启恢复、临时会话失效、逐台撤销与停止服务。

布局采用 CSS Grid `auto-fill/minmax`、`clamp`、媒体查询、触控目标与 `focus-visible`；电视方向键按空间位置移动焦点，输入框和原生播放器保留自身按键行为。遵循 `prefers-reduced-motion`。屏幕尺寸测试不替代实体电视和各平台解码器测试。

技术依据：[MDN HTTP Range](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Range_requests)、[MDN 媒体查询](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Media_queries)。

认证恢复检查覆盖轮询断网、配对中刷新、客户端时间偏差和批准响应丢失；HTTP 测试覆盖撤销连接隔离、写盘失败一致性与损坏记录重置。
