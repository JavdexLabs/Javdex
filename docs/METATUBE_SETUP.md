# MetaTube 配置指南

[返回产品介绍](../README.md) · [使用指南](USER_GUIDE.md) · [第三方说明](THIRD_PARTY_NOTICES.md)

MetaTube 是 Javdex 内置的可选影片刮削来源，用于连接你自行部署的 `metatube-server`。Javdex 不提供公共服务地址，也不随安装包分发或启动 MetaTube 服务端、数据库和服务进程。

本指南说明 Javdex 侧的连接与使用；服务端部署请查阅 MetaTube 项目自己的说明，上游项目和许可入口见 [第三方说明](THIRD_PARTY_NOTICES.md)。

## 配置连接

开始前准备好可访问的服务端地址，以及服务端启用认证时需要的访问令牌。

1. 打开“设置 → 刮削来源 → 影片”，找到 MetaTube 并打开其配置。
2. 填写完整 HTTP(S) 服务端地址；支持反向代理的路径前缀。本机地址示例为 `http://127.0.0.1:8080`，请换成自己的实际地址与端口。
3. 服务端要求令牌时，在“访问令牌（可选）”填写；未启用认证时留空。
4. 如需通过应用的刮削代理连接，勾选“使用 Javdex 刮削代理连接此服务”，并先在“设置 → 网络”配置相应代理。
5. 使用“测试连接”检查当前输入，然后保存配置；测试连接不代替保存。
6. 保存服务地址后，将 MetaTube 设为默认来源或加入组合来源。也可在具体媒体库的“刮削”设置中选择它。

`127.0.0.1` 指运行 Javdex 的这台电脑。服务部署在其他机器时，填写那台机器从当前电脑可访问的地址。

首次安装时 MetaTube 显示“待配置”，配置完成前不能用作默认来源或加入组合。已有令牌时，输入框留空表示保留；需要移除时使用“清除令牌”并保存。

## 使用与结果确认

在影片详情或批量刮削中选择 MetaTube，按所需字段获取资料。服务端可能从多个 Provider 返回同番号候选；出现歧义时，到“待确认”核对影片身份后选择结果。

MetaTube 提供哪些站点的数据、哪些字段和图片可用，取决于你部署的服务端及其 Provider 配置。连接测试成功只说明连接测试通过，不保证每个番号都有结果。

## 联网与凭证

- Javdex 会向配置的服务发送查询番号并读取返回资料；是否进一步请求上游站点由该服务端的配置决定。
- 访问令牌由主进程通过系统凭证保护能力保存在独立凭证文件中，不会交给插件 Worker，也不写入普通设置、URL、日志或插件导出包。
- 远程 HTTP 连接会提示隐私风险；远程 HTTP 与令牌同时使用时，保存前需要确认。非本机服务建议使用 HTTPS。
- 勾选刮削代理后，请求会经过所配置代理；本机或局域网服务应根据实际网络选择是否使用。

## 当前兼容范围

Javdex 的集成验收基线为 MetaTube Server v1.4.0，运行时按 `/v1` 接口契约判断兼容性，不按版本号硬性拦截。这是项目的验证基线，不表示上游最新版本。

| 项目 | 当前约定 |
|---|---|
| 演员 | 返回的 `actors` 全部按女性演员导入 |
| 发行方 | `label` 近似映射为 Javdex 的发行方，需注意两者语义并不完全相同 |
| 图片 | 封面和样张使用 MetaTube 原生公开 `/v1/images` 路由，图片 URL 不携带访问令牌 |
| 额外图片认证 | 当前不支持在额外反向代理层为这些图片单独增加认证要求 |

## 常见问题

| 现象 | 检查方向 |
|---|---|
| 一直显示“待配置” | 是否已保存有效服务端地址，而不只是测试连接 |
| 连接失败 | 服务是否启动，地址、端口、路径前缀和代理是否正确，当前电脑是否能访问 |
| 认证失败 | 令牌是否与服务端一致，是否已保存，反向代理是否另设认证 |
| 资料正常但图片加载失败 | 图片路由是否可达，反向代理是否额外要求图片认证 |
| 某个番号没有结果 | 服务端 Provider 是否启用、可访问，以及是否有对应影片资料 |
| 返回多部同番号影片 | 在待确认中核对发行商、日期和图片，不要只按番号判断 |

反馈问题时提供 Javdex 版本、服务端版本和脱敏错误信息，不要附上访问令牌。更多集成背景见 [第三方说明](THIRD_PARTY_NOTICES.md)。
