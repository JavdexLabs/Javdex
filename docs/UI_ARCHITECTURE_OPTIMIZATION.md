## 实现边界

1. `interaction/interactionLayers.ts` 拥有父子层级与键盘仲裁，`useInteractionLayer` 是 DOM 适配器。Modal、FloatingLayer、SelectControl、图片预览、筛选面板和 NFO 前台任务接入同一规则。最上层忙碌弹窗消费 Escape；模态层的 Tab 包含 portaled 子控件；背景 inert 保留原值并处理晚加入的节点；最后一个模态层退出才恢复原有 overflow。全局搜索不越过模态层。插件卡片与待确认菜单移除重复注册，定位用的非可聚焦容器不作为返回焦点。普通弹窗不新增 history 记录，图片预览保留原 history token/back 合同。
2. `usePluginDevDraft` 原子处理新建、载入、生成包与编辑；`pluginDevRunProjection` 投影宿主事件和恢复快照，不接管 Agent runtime、命令仲裁或快照游标。`useVideoScrapeController` 拥有详情刮削及导演选择/重试；`useStorageSettingsController` 拥有加密、目录选择与确认/提交。I/O 从调用方显式传入，页面负责展示、提示与导航，不暴露工作流状态 setter。
3. `browseWindow` 共用最多三页与二十个轻量锚点的有界机制；`browseSession` 统一请求世代、启停、陈旧作用域和 A→B→A 保护。`useWindowedCatalog` 仍保留精确总数、读取版本与范围身份验证，`useContinuousPage` 仍保留未知总数/hasMore 的估算和串行加载。没有合并查询适配器或缓存完整媒体 DTO 到锚点记忆。
4. 新增共享层级 token；21 个单所有者 classification/organization 变量移到实际消费的 CSS Module 作用域，尤其保留 portal 自有根作用域。组件契约明确 className 是布局插槽、variant 是显式语义；工作区密度仍取决于 DOM 继承，不建立 React 密度上下文。CSS 架构检查禁止相关单所有者变量回流全局。
5. `test:ui` 使用生产组件、合成数据和真实浏览器输入，作为 PR CI 的独立小型任务；`test:ui:matrix` 保留完整页面/主题/尺寸检查与截图。头像批处理通过 Context Provider 适配，分析通过外部 Worker 接口适配，移除生产源码字符串替换。测试服务器禁用文件监听，避免长矩阵被开发热更新打断。
6. 设置路由及插件开发、外观、模型、备份四个低频面板使用选择性加载与局部 Suspense；全局任务 Provider、Layout、常用列表保持原有挂载方式。构建生成 renderer manifest，`measure:renderer` 去重统计静态依赖闭包并检查五个功能 chunk 没有回流初始包；相关统计逻辑纳入 `test:packaging`。
