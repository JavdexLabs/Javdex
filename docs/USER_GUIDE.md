# Javdex 使用指南

[返回产品介绍](../README.md) · [MetaTube 配置](METATUBE_SETUP.md) · [NFO 兼容性](NFO_COMPATIBILITY.md)

## 安装与更新

体验 Beta 请到 [全部发布版本](https://github.com/JavdexLabs/Javdex/releases) 选择预发布条目；稳定版更新提醒不会提示 Beta。升级前退出应用并完整备份数据目录，升级后的数据库不要直接用旧版本打开；回退应恢复升级前备份。

在 [官网](https://javdexlabs.github.io/Javdex/) 或 [GitHub Releases](https://github.com/JavdexLabs/Javdex/releases/latest) 选择对应系统和架构的安装包。

| 平台 | 使用方式 |
|---|---|
| Windows x64 | EXE 按向导安装；ZIP 完整解压后运行其中的应用，保留同目录配套文件 |
| macOS | Apple Silicon 选择 arm64，Intel 选择 x64；打开 DMG，将应用拖到“应用程序” |
| Linux x86_64 | AppImage 赋予执行权限后启动；DEB 使用系统的软件安装器安装 |

安装包尚未进行商业代码签名，系统可能显示发布者或安全提示。下载来源与具体版本以项目 Release 页面为准。

在“设置 → 关于”检查版本并前往下载。更新前退出应用，再安装或解压新版本；应用程序目录与资料目录分开，ZIP 免安装版也不会自动把资料保存到解压目录。数据库如需升级，会在新版本首次启动时处理，版本说明见 [更新日志](../CHANGELOG.md)。Agent 工作记录会在任意桌面首次启动时单向拆到 `desktop-work.db`，见 [数据保存在哪里](#数据保存在哪里)。

## 资料库连接：本地或远程

只在一台电脑使用时，保留默认本地模式即可。希望 NAS 或常开电脑持续扫描并提供网页访问时，先按 [Docker 部署步骤](SERVER_MODE.md#docker-compose-快速开始) 启动服务，再连接桌面。浏览器只用于浏览和播放，资料管理仍使用桌面应用。

首次连接需要部署者在服务机器生成一次性令牌，并在桌面“正在使用”中完成首次授权；网页账号密码不能代替此步骤。远程媒体库添加目录时，从服务端配置的挂载（示例为 `library`）及其子目录中选择，不使用这台电脑上的路径。播放服务端本地影片前必须在“播放设置”选择这台电脑上的播放器并保存；未配置不影响连接和浏览。Windows 可点击“检测默认播放器”，按 MP4、MKV、AVI 的顺序寻找可直接调用的默认程序，检测结果只填入设置草稿，保存后再试播。系统文件关联不保证网络播放兼容；未检测到程序或其他系统请使用“选择程序”，也可输入绝对路径。此操作不会修改系统默认应用。

默认使用本机资料库。若把资料库放在独立服务上，打开“设置 → 存储与导出 → 资料库连接”，选择“远程资料库”，填写服务地址，先点“测试连接”检查服务是否可达及版本是否匹配，再保存并点击“立即重启”。测试只读取服务的公开连接信息，不会保存地址或验证写入凭据。页面的“正在使用”显示当前会话；保存后会另外显示重启后将使用的资料库。切换连接不会复制本机资料，切回本地后仍会记住上次填写的服务器地址。远程模式使用同一套管理界面，不再打开本机 `library.db`，也不在本机恢复扫描或启动网页服务。插件、采集助手和头像裁切仍在这台电脑上运行。“图片资源”会显示服务端当前目录；该目录由服务端部署配置管理，本机图片目录和加密设置不会随模式切换而改变。

桌面与服务必须是同一应用版本；版本不一致时不会写入远程资料库，也不会自动改连其他地址。工作记录尚未复制完成时，先回到本地模式完成准备，不要在远程模式打开原库。独立服务的部署、认主、迁库与恢复限制见 [服务端模式](SERVER_MODE.md)。同一局域网的只读网页见下文 [局域网浏览与播放](#局域网浏览与播放)。

远程模式沿用这台电脑上的 `desktop-work.db`。该文件在任意桌面首次启动时就会建立，不依赖是否切换远程，见 [数据保存在哪里](#数据保存在哪里)。它不是服务端资料库的副本；服务端备份只包含正式资料和正式图片，不含此电脑上的 Agent 运行记录和草稿。

## 从第一个媒体库开始

1. 打开“设置 → 媒体库”，新建媒体库并填写名称，也可选择图标和标识颜色。
2. 添加影片所在的来源目录；可以添加多个目录，也可以先创建空库，稍后添加影片。
3. 确认扫描、刮削和显示选项。已有本地 NFO 时，可保留默认开启的“自动导入本地 NFO”。
4. 在完成创建时选择立即扫描，或进入该库的“来源与扫描”手动启动扫描。
5. 扫描后查看影片列表与扫描结果。有归属歧义的资源会进入“待确认”，核对后再关联。

本地和远程资料库使用相同的四步创建向导。远程模式的“选择目录”浏览服务端已配置的媒体挂载，支持选择子目录；不会打开这台电脑的目录选择器。基本信息、来源目录和扫描配置一起保存，校验失败时可在原向导修改后重试。

每个媒体库分别管理目录、扫描策略和资源；同一影片的资料可由多个媒体库共享。启用的来源目录不能与其他媒体库的目录相同或互相包含。网络盘需要先成为当前系统可访问的目录。

### 后续扫描与导入

在“设置 → 媒体库”选择需要管理的库，在“来源与扫描”查看来源和扫描记录，在“常规”调整自动扫描等行为。自动扫描由运行中的应用执行。

扫描支持本地视频与 STRM 文件。STRM 是指向播放地址的文本文件；后续扫描会识别其目标变化，不会把远端影片下载到本地。遇到目录离线或不可访问时，先恢复连接，再查看扫描结果。

本地文件请在该库的“来源与扫描”添加目录，再点“扫描并导入”。只有链接、相关页面，或想先建一条无资源影片时，从媒体库页面选择“添加影片”：填写番号，可选添加可播放的资源链接（HTTP/HTTPS 直链、网页、Magnet、ED2K）或相关链接。直链旁的“读取大小”只探测文件大小，不验证能否播放；网页链接请直接保存。无资源影片若开启“扫描后自动清理无资源成员”，完整扫描成功后可能被移出当前库；已加入清单的会保留。

扫描结果里的“异常与待办”会列出无法识别番号的文件。手工填写番号即可导入，目标默认“新建独立影片”；若已有同番号影片，再从下拉改选。

## 补齐影片和演员资料

### 选择刮削来源

打开“设置 → 刮削来源”，分别管理影片与演员来源。选择可用插件作为默认来源；媒体库也可以在自己的“刮削”设置中指定默认影片来源。

普通插件刮削根据插件能力获取资料，无需 AI 模型；联网来源需要能访问对应网站或服务。MetaTube 显示“待配置”时，先按 [配置指南](METATUBE_SETUP.md) 连接自己的服务。

网站类插件可在配置中开启“刮削前预登入”。开启后，该插件每次刮削会先打开网站主页；请在当前页完成登入或验证（不支持弹出新窗口），再点窗口顶部操作栏“登入完成”。遇到 Cloudflare 人机验证时，同样使用窗口顶部操作栏的“验证通过”；若同时需要登入，只显示登入菜单。同一批量任务中每个插件只询问一次；组合来源会按字段源依次打开需要登入的主页。应用不会保存账号密码。MetaTube、Gfriends 等接口或 GitHub 来源没有此项。

可以创建组合来源，为不同字段选择不同插件。例如，一个来源提供标题和简介，另一个提供封面和样张。组合只能使用相应插件支持的字段，保存前需补齐界面指出的缺失或失效来源。

### 单部、批量与手动修改

在影片或演员详情中执行刮削；批量处理时，从列表选择条目并使用批量操作。按需要选择更新字段和更新方式，批量任务可暂停、恢复或取消。远程模式同样支持单部和批量刮削：插件仍在此电脑运行，正式资料写入当前服务器，不会打开原来的本地资料库。远程一次已选条目最多 200 个，更大范围请用筛选条件；取消批量只停止本机采集，不会撤销已经写入服务器的结果。

刮削结果不准确时，可重新匹配或手动编辑。影片详情也支持维护相关链接和自定义评分。不同来源可提供的资料不同，某个字段为空不代表整次刮削都失败。

### 使用 AI 从指定网页采集

先在“设置 → AI 模型 → 提供商与模型”配置连接和可用模型，再到“用途与运行”选择并保存应用默认模型或对应助手的模型。模型配置保存后只影响新任务。

插件开发可独立选模型；影片/演员采集、清单导入与媒体库整理共用整理用途的模型。思考强度及输出、超时等限制仍可调整；缓存与上下文压缩自动管理。已有任务继续使用启动时保存的设置。

应用重启后可恢复有效的 Agent 会话检查点。如果检查点损坏或不兼容，会提示新建任务，不再尝试从历史重建对话。已有资料、草稿、操作记录和插件工作区保留；插件工作区可由你明确清除。

1. 在影片或演员详情中选择“Agent 刮削”。
2. 粘贴对应详情页地址，开始采集。
3. 如任务要求登录或处理验证，按界面提示操作后继续。
4. 查看采集草稿、图片与身份提示，勾选需要的字段和应用方式。
5. 预览后应用；也可稍后处理或丢弃草稿。

AI 采集会访问指定网页，并向配置的模型服务发送任务所需内容。可用性取决于网页、网络和模型能力；模型服务的账户、额度与费用由你配置的服务决定。

远程模式下，模型、浏览器和草稿仍只在此电脑运行。点击预览时服务器根据当前资料库核对影响；点击应用时才上传结构化候选和已勾选的图片。若服务端资料在两步之间变化，界面会要求重新检查预览，不会按旧预览覆盖。

## 浏览、清单与影片资源

首页可跨库搜索，查看近期添加和随机发现。库内可按番号、标题或演员搜索，结合筛选和排序缩小范围；演员、标签、制作商、发行商、导演和系列入口可继续查看关联影片。

清单、导演、系列和机构列表可向下滚动连续浏览；演员作品、分类关联影片与清单影片也随详情页滚动加载。演员作品与清单影片在刷新或查看详情再返回后可恢复浏览位置。

### 自己整理清单

在侧栏“清单”创建清单，并从影片详情或批量操作添加影片。清单可维护名称、封面和相关链接，也可同时引用不同媒体库的影片。

清单引用的是影片资料，不会复制视频文件。没有播放资源的影片也可以保留在清单里。

### 从网页导入外部清单

此功能需要可用 AI 模型，配置方式与上面的 AI 采集相同。

1. 在“清单”页选择“导入外部清单”；本地模式追加到已有清单时，也可在该清单详情选择“从网页导入”。
2. 填写来源地址，选择新建清单或已有清单，并指定目标媒体库。远程模式当前只支持新建清单。
3. 决定是否为未匹配条目创建无资源影片，以及是否保留相关来源链接。
4. 开始导入，查看收集与匹配进度，按提示完成登录、验证或候选身份确认。
5. 结束后查看导入结果与跳过条目。

已有影片会跨库匹配；目标媒体库主要决定新建影片的归属。导入不会下载播放资源，也不保证任意网页都能完整读取。运行期间保持应用和任务弹窗打开；终止任务后不能继续原任务。

### 打开与管理资源

一部影片可以关联多个本地文件或链接。在详情中选择主资源，点击“播放”时优先打开它；实际播放、浏览网页或处理 Magnet/ED2K 链接由系统默认应用负责。

需要整理关联时，可合并同番号影片，或将非主资源拆分到新影片。相同番号不一定表示同一部作品，操作前核对发行商、日期和资源。

## 处理待确认与媒体库维护

“待确认”集中展示扫描资源归属、资源身份、影片刮削候选与演员名称冲突。根据分类核对文件名、NFO 番号、图片和候选资料，再作出选择；丢弃待办前注意确认弹窗中的影响说明。

不同维护操作的结果不同：

| 操作 | 影响 |
|---|---|
| 从清单移除影片 | 取消清单引用，不删除影片文件 |
| 从媒体库移出影片 | 移除本库成员与资源记录，保留全局资料、其他库成员和磁盘文件；目录仍参与扫描时可能再次导入 |
| 归档媒体库 | 暂停扫描并从侧栏隐藏，保留资料与来源；可在“设置 → 媒体库”选择归档库恢复 |
| 永久删除媒体库 | 删除该库成员、资源记录和扫描等数据，保留本地文件与全局影片资料 |
| 永久删除影片 | 删除全局影片资料、各库成员与资源记录，并删除关联的本地视频和 STRM 源文件 |

执行前以操作弹窗的影响预览为准。只想暂时隐藏整库时，可以归档；不要用永久删除影片代替隐藏。

## 利用本地 NFO 导入与导出资料

NFO 是保存在影片旁的资料文件，可包含标题、演员等信息以及图片引用。

### 导入已有资料

已覆盖以下工具的常见 NFO 格式和本地图片约定：

| 来源工具 | 已覆盖内容举例 |
|---|---|
| Movie_Data_Capture（MDC） | 番号、制作商、发行方、发行日期、时长、简介及评分 |
| MDCx | 同名 NFO、发行方、系列、原始简介及本地封面查找 |
| Javinizer | 番号、系列、演员，以及封面、背景、演员头像和额外图片目录约定 |
| JavSP | 番号、系列、发行日期、制作商，以及 `movie.nfo`、海报和背景图约定 |

验证基线记录于 **2026-09-05**，使用依据各工具固定提交版本制作的合成样例和自动化测试，不代表各版本、所有自定义配置或未知字段都完整兼容。固定版本与样例范围见 [兼容样例说明](../test-fixtures/nfo/README.md)，字段与命名依据见 [原始调研](NFO_IMPORT_EXPORT_RESEARCH.md)。

在媒体库创建向导或该库“常规”设置中启用“自动导入本地 NFO”。扫描首次发现资源时，会尝试读取相邻 NFO，为尚未刮削成功的影片补齐空字段。

没有 NFO 是正常情况；已刮削成功的影片不会被自动覆盖，已有正式资源也不会在每次扫描时重复读取 NFO。文件名和 NFO 的番号冲突时，需要到“待确认”核对。

导入图片仅接受媒体库根目录内的安全本地文件；远程图片地址和越界引用会被忽略。修改 NFO 后，Javdex 不会持续同步这些变化。

### 导出给其他媒体软件

1. 打开“设置 → 存储与导出 → 导出影片资料”。
2. 选择一个或多个媒体库，以及目标软件。
3. 选择封面、背景和可选附件；影片资料与演员名单始终导出。
4. 点击“预览导出”，核对文件位置、新建、跳过、覆盖和提示信息。
5. 确认后执行导出，结束时查看逐项结果，再到目标软件刷新本地资料或图片。

| 选项 | 使用前了解 |
|---|---|
| 已有文件 | 默认跳过；需要更新时显式选择覆盖同名文件，并重新预览 |
| 写入位置 | 写到对应本地视频或 STRM 源文件旁；普通链接没有本地写入位置，会被跳过 |
| 样张 | 默认关闭，作为备份或迁移附件保存，不承诺在播放器中显示为样张画廊 |
| 演员头像 | 默认关闭，各软件对本地头像的支持不同 |
| 运行方式 | 导出期间保持应用打开，其他操作暂时锁定；停止后保留已写入文件 |

支持通用/Kodi、Jellyfin、Emby、Plex NFO Agent 和 Infuse 的导出选项。Plex 需要相应 NFO Agent，Infuse 需要启用本地资料；完整要求与已验证范围见 [NFO 兼容性说明](NFO_COMPATIBILITY.md)。

导出不是持续同步或完整备份，不包含清单、个人评分等全部应用数据。预览过期或某些文件失败时，查看原因、重新预览后再处理。

## 外观、图片与本地数据

### 调整显示

在“设置 → 外观与隐私”选择主题、封面显示方式、详情背景和头像智能构图。头像人脸检测在本地执行；演员列表还可筛选未检测到人脸的头像，便于逐个检查。

隐私模式可按范围遮盖图片、替换头像或禁用图片预览，只改变界面显示，不会加密原文件。

### 备份与恢复

打开“设置 → 存储与导出 → 备份与恢复”。创建备份会保存**当前正在使用**的本机或服务端资料库，文件保存到这台电脑；服务端需先完成写入授权。备份期间暂停资料写入，完成、取消或失败后继续正常使用。

备份包括全部媒体库的正式资料、影片与资源关联、演员、分类、标签、清单、个人评分，以及正式封面、头像、样张和写真。**不包含原始视频、插件和模型配置、桌面工作记录、待确认候选、运行任务及登录凭据**。加密图片在备份副本内解密，源图片不变；第一版备份文件不加密，请妥善保管。归档与解压数据各有 64 GiB 上限。

新版可恢复同版或旧版生成的备份：当前支持备份格式 1、正式数据库版本 17 至当前软件的数据库版本。系统先校验原包，再复用数据库升级流程处理临时副本，原备份文件保持不变；成功后显示升级说明并进入目录对应。更高应用版本或数据库版本生成的备份、未知包格式及不受支持的开发版结构会被拒绝。旧离线迁库包不属于此兼容范围。数据库版本未变化时，也不再要求应用版本完全相同。

若来源资料登记的图片文件缺失，备份会停在“核对缺失图片”，汇总数量和路径。可取消并补齐图片后重试，也可点击“确认缺失并继续备份”：仅在备份副本中清除缺失图片的文件引用，保留其他资料、图片和已有来源网址，原资料库不变。缺失清单写入备份，操作记录和恢复预览会提示这些图片无法恢复。缺失清单变化后需要重新确认。覆盖恢复前的目标自动备份仍要求完整，失败则停止覆盖。

操作记录中的已完成、失败和已取消项可点击“删除记录”，核对确认框后删除。默认只移除记录；可勾选同时清理该任务在 Javdex 备份区内的备份和临时文件，确认框会显示所在设备、目录及预计释放空间。手动另存到电脑的副本、选择用于恢复的原始备份、当前资料库和原始视频均保留。文件清理无法撤销；清理失败会保留记录，供继续重试。

删除恢复记录不会连带删除恢复前的自动保护备份；保护备份须通过自己的记录单独处理，并会提示失去该恢复点。仍被未结束恢复任务使用的保护备份不能清理文件。运行中、传输中及“需要恢复处理”的任务不能删除；未执行的恢复任务可先取消，再删除记录。下载刚结束时可能需要稍后重试，以免中断分块传输。

远程使用过程中若出现“写入授权已失效”，桌面会暂停后续远程请求，并提供“打开连接设置”入口。授权统一在“设置 → 存储与导出 → 资料库连接”处理：请部署者在服务端运行 `recover` 命令取得一次性令牌，再在设置中领取新凭据。授权恢复后先核对资料是否已保存，再手动提交尚未完成的修改。桌面不会自动重放失败的写入，也不会自动切回本地资料库。

恢复使用独立向导，可点击“稍后继续”暂时关闭，当前页面会保留目录选择。确认后，执行进度显示在页内任务卡；结束后结果归入操作记录。操作记录分页显示，“展开详情”和“收起详情”始终在原记录行操作，不改变记录位置和总数，也不影响当前恢复向导的目录选择。

恢复步骤：

1. 选择这台电脑上的 `.javdex-backup` 文件，等待上传和校验，查看备份摘要。
2. 为每个来源目录选择目标目录。本地模式使用系统目录选择器；远程模式选择服务端挂载及其子目录，不能填入桌面电脑的路径。不需要对应视频时，明确选择“仅保留资料”。无来源目录的本地资源也需要单独确认舍弃关联。
3. 核对当前目标中的资料数量、资源关联移除数、缺失文件及自动备份目录。缺失不代表播放已验证；涉及缺失或舍弃资源的媒体库会关闭“自动清理无资源影片”。正在运行的任务和待确认事项须先处理。
4. 勾选已核对覆盖范围、目录对应和缺失资源，再点击“备份当前资料并恢复”。系统先生成并校验目标自动备份，再恢复资料和图片。提交阶段不可取消。完成后资料库内容身份更新，旧草稿、旧页面和播放凭据不再适用于新资料；服务端身份及当前写入授权保留。

已连接并认主的远程模式还可“从本机资料库导入”：桌面使用隔离的导出宿主读取这台电脑原有资料库，自动导出和上传，再进入同样的目录对应和覆盖确认步骤。**本机资料库保留且可独立使用，两份资料不自动同步**。此操作不移动或复制原始视频。

上传、下载中断可在任务卡或对应操作记录中重试传输；不要更改原备份文件。恢复失败会保留原因；如提示“需要恢复处理”，重启资料库所在设备上的 Javdex，让它先完成日志恢复，再查看原任务。不要反复创建覆盖任务。操作记录中的自动备份可另存到本机；本轮不自动清理备份。自动备份位于目标用户数据目录的 `backups/`（Docker 默认 `/data/backups/`，宿主位置取决于 `/data` 卷挂载）。

旧离线迁库命令仍保留原格式及冻结源库的语义，与本页的备份、恢复和导入分开。

### 迁移图片目录与加密

在“设置 → 存储与导出 → 图片资源”查看当前图片目录。选择新目录并确认后，应用会迁移已有图片。此操作不移动原始视频或应用数据库。

图片加密覆盖封面、头像、样张、写真与清单封面，不包含影片文件或整个数据库。启用或关闭时会处理全库图片，完成前应用暂时锁定。

加密图片的读取依赖当前机器、用户与应用数据路径；不要把复制加密图片目录当作可跨设备恢复的备份。整库迁到独立服务时，源端会在导出包内自动解密正式图（源目录保持加密），密钥与别名约定见 [服务端模式](SERVER_MODE.md)。

### 数据保存在哪里

应用使用系统的 Javdex 用户数据目录，与安装目录分开。默认目录结构如下，`userData` 表示实际应用数据目录，并非需要手动创建的文件夹：

```text
userData/
  desktop-work.db              # 此电脑的 Agent 运行记录、候选草稿和恢复状态
  data/library.db              # 影片、演员等资料数据库
  settings.json                # 应用设置
  scraper-service-secrets.json  # 刮削服务凭证
  media_assets/                # 默认图片目录，可在应用中迁移
    covers/
    avatars/
    actress_gallery/
    samples/
    playlist_covers/
```

升级后的任意桌面都会在首次启动时做这项拆分，包括只使用本机资料库、从未开启服务端或远程模式的安装：当时 `library.db` 里的 Agent 状态被单向复制到 `desktop-work.db`，之后的运行记录和草稿只写在工作库中，不会再复制回 `library.db`。只备份、导出或迁移 `library.db`，以及不含 Agent 工作记录的资料库离线包，都会漏掉这次升级之后的 Agent 运行记录和草稿。降级到 0.7.x 可能读不到 `desktop-work.db` 里的升级后 Agent 活动。

这只是主要文件示意，应用还会保存插件、模型配置和任务数据等文件。需要手动备份时，先完全退出应用，再保存整个用户数据目录和自定义图片目录；其中应同时包含 `desktop-work.db` 与 `data/library.db`。原始视频需另行保存。系统保护的服务凭证迁移后可能需要重新配置。

联网刮削、AI、更新检查和打开外部链接会访问各自的服务；本地保存资料不意味着所有功能都离线执行。

## 遇到问题

| 现象 | 先检查 |
|---|---|
| 扫描后找不到影片 | 当前媒体库、来源目录是否启用且可访问、扫描结果、最小时长设置与待确认项 |
| 刮削来源不可用 | 来源是否配置完成、网络是否可访问、组合来源的字段分配是否有效 |
| AI 无法开始 | 是否已添加可用模型，并保存默认模型或对应助手用途配置 |
| 影片无法播放 | 主资源是否存在，系统是否已配置能处理该文件或链接的应用 |
| 远程资料库连不上 | 服务是否在运行、地址是否可访问、桌面与服务版本是否相同；版本不符或缺少写入凭据时按界面提示处理，不会自动改回本机库 |
| 导出后目标软件没变化 | 是否跳过了已有文件、目标软件是否启用本地资料并刷新，以及兼容性说明中的限制 |
| 归档后侧栏找不到媒体库 | 在“设置 → 媒体库”选择归档库并恢复 |

仍无法解决时，请 [提交 Issue](https://github.com/JavdexLabs/Javdex/issues/new)，附上应用版本、操作系统、复现步骤及界面显示的错误。分享日志或截图前隐去令牌、私人路径和不希望公开的资料。

## 局域网浏览与播放

1. 在桌面端打开“设置 → 网络 → 网页服务”，设置访问账号、独立密码与端口，开启服务并保存。设置概览的状态卡片也可进入该页。
2. 让手机、平板、电脑或电视连接同一局域网，在浏览器打开桌面显示的局域网地址；手机也可扫描“访问入口”中的二维码。
3. 使用账号密码登录，或在桌面点击“开启配对”，让新设备选择“与桌面配对”并显示六位码，再在桌面输入、核对并批准。
4. 按需勾选“记住此设备”，重启应用后仍可保持登录；在桌面设备列表中可查看、重命名或撤销设备授权。修改账号或密码会让所有设备重新登录。

网页可浏览活动媒体库、搜索影片、查看清单与详情，通过随机发现和近期添加挑选影片。手机可在“浏览范围”切换媒体库或清单；返回列表会恢复浏览位置，剧照可点击预览和缩放。

影片详情可播放浏览器支持的本地视频与直连资源，支持拖动进度和全屏，也可下载本地资源或复制、打开其他链接。不提供转码，能否播放取决于浏览器、设备编码支持和资源可达性。

Web 端只读，编辑、扫描和刮削仍在桌面端完成。桌面应用需保持运行，当前使用未加密的局域网 HTTP，仅在可信局域网使用，不要映射公网端口。完整配置、播放限制和网络说明见 [局域网 Web 访问](LAN_WEB.md)。

### 关闭窗口后保留后台运行

在“设置 → 外观与隐私 → 窗口行为”开启“关闭窗口后最小化到系统托盘”（默认关闭、立即生效）。之后关闭窗口只会隐藏主窗口，网页服务与后台任务继续运行。点击托盘图标或选择“打开主窗口”可恢复；选择“退出 Javdex”或使用系统的退出应用命令会完全退出并停止服务。前台 NFO 导出期间仍需先完成或终止任务。
