## 安装与更新

在“设置 → 关于”检查更新，再前往实际已发布的正式 Release 下载。下载入口跟随最新正式版，不跟随源码中的待发布版本号。

在 [官网](https://javdexlabs.github.io/Javdex/) 或 [GitHub Releases](https://github.com/JavdexLabs/Javdex/releases/latest) 选择对应系统和架构的安装包。

| 平台 | 使用方式 |
|---|---|
| Windows x64 | EXE 按向导安装；ZIP 完整解压后运行其中的应用，保留同目录配套文件 |
| macOS | Apple Silicon 选择 arm64，Intel 选择 x64；打开 DMG，将应用拖到“应用程序” |
| Linux x86_64 | AppImage 赋予执行权限后启动；DEB 使用系统的软件安装器安装 |

安装包尚未进行商业代码签名，系统可能显示发布者或安全提示。下载来源与具体版本以项目 Release 页面为准。

更新前退出应用，再安装或解压新版本；应用程序目录与资料目录分开，ZIP 免安装版也不会自动把资料保存到解压目录。数据库如需升级，会在新版本首次启动时处理，版本说明见 [更新日志](../CHANGELOG.md)。

### 从 0.8.0 升级到 0.9.0

1. 确认目标正式 Release 已提供所需平台安装包；使用服务端时，同时核对同版本镜像与对应架构的升级文件。
2. 在旧版中完成或停止任务，可先通过“备份与恢复”创建资料库备份；然后完全退出桌面、正常停止服务，另存完整桌面用户数据目录、自定义图片与模型目录，以及服务端数据、图片和部署配置。应用内备份不含模型配置、Agent 工作记录、最近播放或续播位置，不能代替完整升级备份；原始视频另行保存。
3. 更新桌面；远程部署同步采用 0.9.0 服务端。正式 0.8.0 没有托管更新能力，首次须按 [服务端部署与首次采用](SERVER_UPDATE.md#部署与首次采用) 更换镜像并增加独立的 `/program` 卷，保留原数据卷与媒体挂载。这次基础镜像切换不会自动生成托管升级快照，必须先完成上一步备份；不要执行 `docker compose down -v`。
4. 首次使用新版时，正式数据库 schema 19 直接升级到 20，模型管理文档 schema 3 直接升级到 4，保留已有连接、密钥及用途选择。升级后核对媒体库、清单、图片与 AI 配置，再开始新任务；桌面与服务端都使用 0.9.0 才能正常管理远程资料。

不要用旧版打开升级后的数据，也不要手动降低 schema。需要回退时，停止新版并恢复升级前完整备份及对应旧版程序。旧开发快照和不完整的开发版数据库不属于正式兼容路径，不能通过改版本号强行升级。

### 服务端后续更新

0.9.0 使用单个 Docker 容器，更新管理器随镜像提供。按 [服务端托管更新](SERVER_UPDATE.md) 保留 `/data`、`/program` 和媒体挂载，在“设置 → 存储与导出 → 资料库连接 → 服务端更新”粘贴容器生成的配对信息。更新配对与资料库写入授权是两套凭据。

在线更新依次选择“检查更新 → 准备在线更新 → 安装更新”，确认“停服并更新”后执行。离线更新选择与服务器架构匹配的单个 `.javdex-update` 签名完整升级文件；无需另选 JSON 或程序归档，也不要上传源码包或 Docker 镜像归档。部署示例从所选版本源码获取，附件以对应 Release 为准。在线检查只读取正式 Release，拒绝同版本重装与降级。

安装会中断服务访问与播放，先创建完整升级快照，再切换、迁移和验证；提交前验证失败会恢复旧程序与升级前资料。出现“需要人工恢复”时保留现场，按更新指南处理。更新完成后桌面也须使用相同版本。管理器和容器运行环境不随业务升级文件更新，仍由管理员更换基础镜像；保留程序卷，不能通过清空卷强制切换已选业务版本。

## 资料库连接：本地或远程

只在一台电脑使用时，保留默认本地模式即可。希望 NAS 或常开电脑持续扫描并提供网页访问时，先按 [单容器部署步骤](SERVER_UPDATE.md#部署与首次采用) 启动同版本服务，再连接桌面；媒体配置见 [服务端指南](SERVER_MODE.md#媒体目录权限)。浏览器只用于浏览和播放，资料管理仍使用桌面应用。

首次连接需要部署者在服务机器生成一次性令牌，并在桌面“正在使用”中完成首次授权；网页账号密码不能代替此步骤。远程媒体库添加目录时，从服务端配置的挂载（示例为 `library`）及其子目录中选择，不使用这台电脑上的路径。默认使用内置播放器播放本机及服务端影片文件，外部程序的配置见 [选择默认播放方式](#选择默认播放方式)。

默认使用本机资料库。若把资料库放在独立服务上，打开“设置 → 存储与导出 → 资料库连接”，选择“远程资料库”，填写服务地址，先点“测试连接”检查服务是否可达及版本是否匹配，再保存并点击“立即重启”。测试只读取服务的公开连接信息，不会保存地址或验证写入凭据。页面的“正在使用”显示当前会话；保存后会另外显示重启后将使用的资料库。切换连接不会复制本机资料，切回本地后仍会记住上次填写的服务器地址。远程模式使用同一套管理界面，不再打开本机 `library.db`，也不在本机恢复扫描或启动网页服务。插件、采集助手和头像裁切仍在这台电脑上运行。“图片资源”会显示服务端当前目录；该目录由服务端部署配置管理，本机图片目录和加密设置不会随模式切换而改变。

桌面与服务必须是同一应用版本；连接设置显示桌面版本，以及服务端握手返回的版本，便于核对。版本不一致时不会写入远程资料库，也不会自动改连其他地址。工作记录尚未复制完成时，先回到本地模式完成准备，不要在远程模式打开原库。托管镜像的首次令牌与凭据恢复使用容器管理入口，命令见 [配对与客户端使用](SERVER_UPDATE.md#配对与客户端使用)。同一局域网的只读网页见下文 [局域网浏览与播放](#局域网浏览与播放)。

远程模式沿用这台电脑上的 `desktop-work.db`。该文件在任意桌面首次启动时就会建立，不依赖是否切换远程，见 [数据保存在哪里](#数据保存在哪里)。它不是服务端资料库的副本；服务端备份只包含正式资料和正式图片，不含此电脑上的 Agent 运行记录和草稿。

## 从第一个媒体库开始

1. 打开“设置 → 媒体库”，新建媒体库并填写名称，也可选择图标和标识颜色。
2. 添加影片所在的来源目录；可以添加多个目录，也可以先创建空库，稍后添加影片。
3. 确认扫描、刮削和显示选项。已有本地 NFO 时，可保留默认开启的“自动导入本地 NFO”。
4. 在完成创建时选择立即扫描，或进入该库的“来源与扫描”手动启动扫描。
5. 扫描后查看影片列表与扫描结果。有归属歧义的资源会进入“待确认”，核对后再关联。

本地和远程资料库使用相同的四步创建向导。远程模式的“选择目录”浏览服务端已配置的媒体挂载，支持选择子目录；不会打开这台电脑的目录选择器。基本信息、来源目录和扫描配置一起保存，校验失败时可在原向导修改后重试。

**远程媒体库的来源目录必须对服务端进程开放读写权限**，包括实际使用的子目录及文件。首次添加目录需写入 `.javdex-root` 标记，导出 NFO 和重命名文件也需要写权限。Docker 媒体卷应使用读写挂载，同时配置宿主机或 NAS 的文件权限；仅让数据目录 `/data` 可写并不足够。部署检查见[媒体目录权限](SERVER_MODE.md#媒体目录权限)。

每个媒体库分别管理目录、扫描策略和资源；同一影片的资料可由多个媒体库共享。启用的来源目录不能与其他媒体库的目录相同或互相包含。网络盘需要先成为当前系统可访问的目录。

### 后续扫描与导入

在“设置 → 媒体库”选择需要管理的库，在“来源与扫描”查看来源和扫描记录，在“常规”调整自动扫描等行为。自动扫描由运行中的应用执行。

扫描支持本地视频与 STRM 文件。STRM 是指向播放地址的文本文件；后续扫描会识别其目标变化，不会把远端影片下载到本地。遇到目录离线或不可访问时，先恢复连接，再查看扫描结果。

本地文件请在该库的“来源与扫描”添加目录，再点“扫描并导入”。只有链接、相关页面，或想先建一条无资源影片时，从媒体库页面选择“添加影片”：填写番号，可选添加可播放的资源链接（HTTP/HTTPS 直链、网页、Magnet、ED2K）或相关链接。直链旁的“读取大小”只探测文件大小，不验证能否播放；网页链接请直接保存。影片属于多个媒体库时，某个库的全部资源记录移除后会自动移出该库；清单引用和置顶会阻止清理。只有一个归属时，由原“清理无资源成员”开关决定是否在安全扫描后移除。所有资源类型均计入判断，清理归属不会删除全局影片资料。

扫描结果里的“异常与待办”会列出无法识别番号的文件。手工填写番号即可导入，目标默认“新建独立影片”；若已有同番号影片，再从下拉改选。

## 补齐影片和演员资料

### 选择刮削来源

打开“设置 → 刮削来源”，分别管理影片与演员来源。选择可用插件作为默认来源；媒体库也可以在自己的“刮削”设置中指定默认影片来源。

普通插件刮削根据插件能力获取资料，无需 AI 模型；联网来源需要能访问对应网站或服务。MetaTube 显示“待配置”时，先按 [配置指南](METATUBE_SETUP.md) 连接自己的服务。

网站类插件可在配置中开启“刮削前预登入”。开启后，该插件每次刮削会先打开网站主页；请在当前页完成登入或验证（不支持弹出新窗口），再点窗口顶部操作栏“登入完成”。遇到 Cloudflare 人机验证时，同样使用窗口顶部操作栏的“验证通过”；若同时需要登入，只显示登入菜单。同一批量任务中每个插件只询问一次；组合来源会按字段源依次打开需要登入的主页。应用不会保存账号密码。MetaTube、Gfriends 等接口或 GitHub 来源没有此项。

可以创建组合来源，为不同字段选择不同插件。例如，一个来源提供标题和简介，另一个提供封面和样张。组合只能使用相应插件支持的字段，保存前需补齐界面指出的缺失或失效来源。

### 单部、批量与手动修改

在影片或演员详情中执行刮削；批量处理时，从列表选择条目并使用批量操作。按需要选择更新字段和更新方式，批量任务可暂停、恢复或取消。远程模式同样支持单部和批量刮削：插件仍在此电脑运行，正式资料写入当前服务器，不会打开原来的本地资料库。远程一次已选条目最多 200 个，更大范围请用筛选条件；取消批量只停止本机采集，不会撤销已经写入服务器的结果。

刮削结果不准确时，可重新匹配或手动编辑。影片详情也支持维护相关链接和自定义评分。不同来源可提供的资料不同，某个字段为空不代表整次刮削都失败。

影片详情的“编辑影片资料”中，相关链接上方的“外部评分”以紧凑表格列出各来源的评分及评分人数。可以直接编辑来源名称、分数和人数，点击“新增评分”添加来源；评分人数可留空，来源名称不能重复，人数须为非负整数。左侧单选控件选择默认评分，右侧图标删除评分；所有改动保存后生效。保存前可撤销删除，新增行可直接移除。详情页只显示默认来源的评分，该来源也作为支持它的 NFO 导出的默认评分。升级时为尚无默认来源的影片选择获取时间最新的有效评分，时间相同时按来源名称排序；已有手动选择保留。删除默认评分后按同一规则选择剩余来源，没有评分时隐藏详情页外部评分。重新刮削可能重新获取已删除的评分，但不会替换仍有效的默认选择。自定义评分不受影响。

在“编辑影片资料”的“演职员与标签”中，每个演员和刮削标签单独显示，点击其移除按钮可删除。输入名称可以搜索已有项，或按回车添加新名称；也可以粘贴用逗号、顿号或换行分隔的多个名称，重复项自动忽略。女优和男优分别编辑，刮削标签的改动不影响自定义标签。所有增删点击“保存”后生效，尚未按回车的末尾输入也会保存。

### 使用 AI 从指定网页采集

先在“设置 → AI 服务 → 云端服务”配置连接和可用模型，再到“功能”页选择并保存应用默认模型或对应助手的模型。Agent 模型需支持工具调用，模型配置保存后只影响新任务。本机部署的 Ollama 等 API 服务也在云端服务页配置；应用直接下载和管理的语音识别与翻译模型位于“本地模型”页，用于字幕和文本翻译，不会自动成为 Agent 模型。

添加自定义连接时填写名称、服务地址和密钥，通过名称区分不同连接；需要时可在“高级连接选项”中调整协议。

云端服务支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 和 Google Gemini 原生协议。Responses 用于提供 `/responses` 的服务；现有 OpenAI 连接升级后保留原协议，可在高级连接选项中显式切换。Google Gemini 预设使用原生接口，地址默认为 `https://generativelanguage.googleapis.com/v1beta`；若使用 Google 的 OpenAI 兼容入口，请另建 Chat Completions 连接并填写 `https://generativelanguage.googleapis.com/v1beta/openai`。填写基础地址，不要附加具体请求路径。

新建 MiniMax 连接默认使用官方推荐的 Anthropic Messages，基础地址为 `https://api.minimax.cn/anthropic`。已有 MiniMax 连接保留原协议、地址和用途绑定；需要切换时，在高级连接选项中同时修改协议和基础地址，再测试模型。继续使用 Chat Completions 时，官方基础地址为 `https://api.minimax.cn/v1`。

阿里云百炼预设使用北京地域的 OpenAI 兼容地址 `https://dashscope.aliyuncs.com/compatible-mode/v1`；其他地域需填写对应地域的地址和密钥，模型及工具调用能力以服务商在该地域提供的功能为准。Gemini 与百炼可查询远程模型，也可手动添加账户可用的模型 ID。升级补齐新预设，保留已有连接地址、协议、密钥、模型和用途选择。四种协议的模型查询、生成测试、在线文本翻译及 Agent 请求均使用设置中的 AI 服务代理。

提供商详情的“模型管理”在同一弹窗内切换“已添加／远程查询／手动添加”。远程查询可按名称或 ID 搜索，并筛选待添加或已添加模型；查询只读取列表，需要逐项添加。手动添加填写服务商的完整模型 ID，显示名称可选，同一连接不能重复添加相同 ID；添加失败保留输入，添加模型不会改变用途绑定。连接有未保存更改时，先保存再查询、添加或测试。展开已添加模型可测试生成响应，并在该条目内查看原始响应或错误详情；查询成功不表示模型测试通过。每个模型的“能力与上限”展示自动识别值、手动覆盖及依据，可重置为自动值。

内置模型目录更新时，已退出新目录的内置模型，未被用途引用则自动删除；仍被默认模型或某个用途引用时，转为“手动添加”，保留原模型 ID、显示名称、能力覆盖及用途绑定。仍在新目录中的内置模型和用户手动添加的模型保留，已有连接与密钥也保留。新预设只补入同一连接中尚不存在的模型 ID；相同 ID 保留你的记录。未被用途引用的手动模型可以删除，删除后重启不会重新补回。新增预设不会自动替换默认模型；如旧模型已停用，需在“功能”页显式换用其他模型。新 OpenAI 预设使用 Responses 接口，现有模型继续使用原协议。预设不是账户访问授权，实际可用性需通过远程查询和模型测试确认。

插件开发可独立选模型；影片/演员采集、清单导入与媒体库整理共用整理用途的模型。思考强度及输出、超时等限制仍可调整；缓存与上下文压缩自动管理。已有任务继续使用启动时保存的设置。

应用重启后可恢复有效的 Agent 会话检查点。如果检查点损坏或不兼容，会提示新建任务，不再尝试从历史重建对话。已有资料、草稿、操作记录和插件工作区保留；插件工作区可由你明确清除。

1. 在影片或演员详情中选择“Agent 刮削”。
2. 粘贴对应详情页地址，开始采集。
3. 如任务要求登录或处理验证，按界面提示操作后继续。
4. 查看采集草稿、图片与身份提示，勾选需要的字段和应用方式。
5. 预览后应用；也可稍后处理或丢弃草稿。

AI 采集会访问指定网页，并向配置的模型服务发送任务所需内容。可用性取决于网页、网络和模型能力；模型服务的账户、额度与费用由你配置的服务决定。

远程模式下，模型、浏览器和草稿仍只在此电脑运行。点击预览时服务器根据当前资料库核对影响；点击应用时才上传结构化候选和已勾选的图片。若服务端资料在两步之间变化，界面会要求重新检查预览，不会按旧预览覆盖。

## 浏览、清单与影片资源

首页可跨库搜索，查看近期添加和随机发现。库内可按番号、标题或演员搜索，结合筛选和排序缩小范围；演员、标签、制作商、发行商、导演和系列入口可继续查看关联影片。

媒体库排序栏保留“发行”和“添加”快捷项；“更多”菜单可选择发行日期、添加时间、番号、自定义评分和外部评分，旁边的箭头切换升降序。外部评分按影片当前默认来源的分数排序，没有外部评分的影片始终排在最后。

资料库自带“收藏”和“稍后观看”两个默认清单。媒体库影片卡片左下角的爱心可加入或移出“收藏”，加入后显示红色实心爱心；编辑入口保留在卡片更多菜单中。媒体库和首页卡片右上角的时钟可加入或移出“稍后观看”。默认清单不能删除或改名，同名的自建清单不受影响。原“我喜欢”按内置身份显示为“收藏”，已有影片和封面保留。

桌面清单页上方“内置清单”按“收藏 → 稍后观看 → 最近播放”排列，下方“我的清单”展示自建清单并连续分页。搜索同时筛选两组，用户自建的同名清单仍归入“我的清单”。

自建清单的影片数量只显示在名称下方，封面不叠加数量角标。“收藏”和自建清单支持资源筛选；“稍后观看”和“最近播放”展示全部资源类型，不提供资源筛选。“播放后移除”开关位于“稍后观看”详情顶部的操作区。

桌面端两个默认清单使用固定的书签爱心／时钟播放封面，添加或移除影片不会改变封面；可在清单编辑中设置自定义图片，移除后恢复默认封面。普通清单继续自动使用其中影片的封面。隐私模式保留默认图案，自定义图片仍按隐私设置处理。

桌面清单页另有“最近播放”，使用回转箭头与绿色播放符号封面。它是本机独立历史，按资料库身份隔离，不同步到服务器或其他设备、不纳入资料库备份，也不形成清单引用保护。内置播放器输出画面且播放时钟推进后记录；外部播放器／系统接受打开影片资源时记录，不代表已经看完。按影片去重，最近一次播放置顶；本机跨资料库合计最多保留 1,000 部，记录文件超过 8 MiB 时提前淘汰最旧记录。记录保存播放时的简要资料，后来修改、合并或删除的影片不会自动改写历史快照，进入详情时仍读取当前资料。可移除单条或确认清空当前资料库的本机历史，不影响影片、其他设备或续播进度；不支持手动添加、改名或编辑封面。

“稍后观看”始终按加入时间从早到晚显示。“播放后移除”开关默认关闭；开启后，外部播放器／系统接受打开资源时自动移出，启动失败则保留。内置播放等待真实画面输出且时钟推进，加载暂停首帧或等待续播选择不会移除。两种方式都不检测影片是否播放完毕。

清单、导演、系列和机构列表可向下滚动连续浏览；演员作品、分类关联影片与清单影片也随详情页滚动加载。演员作品与清单影片在刷新或查看详情再返回后可恢复浏览位置。

### 自己整理清单

在侧栏“清单”创建清单，并从影片详情或批量操作添加影片。清单可维护名称、封面和相关链接，也可同时引用不同媒体库的影片。

清单引用的是影片资料，不会复制视频文件。没有播放资源的影片也可以保留在清单里。

### 从网页导入外部清单

此功能需要可用 AI 模型，配置方式与上面的 AI 采集相同。

1. 在“清单”页选择“导入外部清单”；本地模式追加到已有自定义清单时，也可在该清单详情选择“从网页导入”。
2. 填写来源地址，选择新建清单或已有自定义清单，并指定目标媒体库。收藏和稍后观看不支持从网页导入；远程模式当前只支持新建清单。
3. 决定是否为未匹配条目创建无资源影片，以及是否保留相关来源链接。
4. 开始导入，查看收集与匹配进度，按提示完成登录、验证或候选身份确认。
5. 结束后查看导入结果与跳过条目。

已有影片会跨库匹配；目标媒体库主要决定新建影片的归属。导入不会下载播放资源，也不保证任意网页都能完整读取。运行期间保持应用和任务弹窗打开；终止任务后不能继续原任务。

### 打开与管理资源

一部影片可以关联多个本地文件或链接。在详情中选择主资源，点击“播放”时优先打开它。文件播放遵循“设置 → 存储与导出 → 资料库连接 → 播放器”中的本机偏好；网页和 Magnet/ED2K 等链接仍由外部应用处理。

需要整理关联时，可合并同番号影片，或将非主资源拆分到新影片。相同番号不一定表示同一部作品，操作前核对发行商、日期和资源。

## 播放影片

### 选择默认播放方式

默认使用基于 **libmpv 原生渲染**的内置播放器，本机文件与服务端原文件共用同一播放引擎。远程模式从服务器读取原文件，仍在此电脑解码，无需先配置外部播放器。直链、STRM 中的网络目标、网页、Magnet 和 ED2K 等链接继续外部打开，不属于内置文件播放。

在“设置 → 存储与导出 → 资料库连接 → 播放器”选择“默认播放方式”，点击卡片右上角保存，从下一次播放生效。新安装及未记录播放方式的旧设置都默认内置播放；明确选择过的外部播放、程序路径与续播选项会保留。仅填写外部程序路径不会自动切换默认方式。

选择外部播放器时须先填写程序绝对路径，也可通过“选择程序”或 Windows 的“使用系统默认播放器”填入；路径为空时无法保存。Windows 按 MP4、MKV、AVI 顺序检测可直接调用的默认程序，只填入设置草稿，需保存后再试播，不会修改系统默认应用。检测不到时手动选择程序；系统文件关联不保证网络播放兼容，服务端文件需要支持网络播放的外部程序。文件资源菜单可单次选择“内置播放”或“外部播放”，不改默认设置。内置运行库不可用时会提示错误，不自动换播放器；播放中出错可重试同一资源、显式外部打开或关闭。

Linux 内置播放支持 X11／XWayland。需完整退出后使用 `--javdex-x11`（或 `--ozone-platform=x11`）启动，并提供 X11/XWayland 显示；这是启动参数，不是设置页开关。原生 Wayland 暂不支持。使用完整安装包中的匹配播放运行库；不要混用其他架构的运行文件。可播放的格式、硬件解码和音频输出取决于运行库、文件及设备，不能据此推断网页端也支持相同格式。

### 展开、全屏与底部迷你播放器

在影片详情点击“播放”打开主资源，也可在文件资源菜单中指定。展开播放器占满应用窗口并隐藏左侧导航；点击“收起到底栏”后，可边播放边浏览资料库。底栏有正在播放的实时小视频，并非封面缩略图；点击小视频或“恢复展开”返回大画面。底栏只占主内容区，不覆盖左侧导航；番号与标题可点击进入影片详情，播放继续。停止后释放底部空间。

播放区域支持空格播放／暂停、←/→ 定位 5 秒、Shift+←/→ 定位 30 秒、M 静音、F 全屏与 Esc 返回。Windows 窗口未聚焦时，单击展开或全屏的视频画面只恢复焦点；已聚焦时单击播放／暂停。在 macOS 全屏中可用 Tab/Shift+Tab 遍历控制，Space/Return 激活按钮，滑杆方向键调整自身。播放结束可选择“从头重播”。隐藏或最小化主窗口会暂停内置播放，不能把系统托盘当作视频后台播放入口。

返回操作会先关闭播放设置、退出全屏或收起展开播放器，保留当前会话；底栏状态下再次返回才执行页面导航。Alt+Left、macOS 的 ⌘[ 使用同样的分层返回。设置草稿和插件未安装更改在真正离开页面时仍按界面提示确认。

### 播放设置与字幕

“播放设置”在底部工具栏右侧、全屏按钮左边，打开后有“播放／字幕／信息”页签。底栏模式需先恢复展开。

| 页签 | 可操作内容 |
|---|---|
| 播放 | 选择当前媒体库内同一影片的文件来源、外部打开、切换音轨、倍速和章节 |
| 字幕 | 选择字幕轨道、加载本机 SRT/ASS、调整纯文本字号与字幕延迟、使用 AI 日中字幕 |
| 信息 | 查看本机／远程来源、视频编码与分辨率、实际硬件解码、音频及快捷键 |

切换来源会重新打开所选文件，不修改主资源，也不会自动换源；外部打开成功后停止当前内置会话，失败则保留。轨道名称显示可用的语言、编码及音轨声道提示，声道标记不代表设备实际输出。ASS 自带样式和图像字幕不提供字号覆盖；字幕延迟可按 0.5 秒提前、延后或重置。倍速支持 0.5×、0.75×、1×、1.25×、1.5×、2× 和 3×，工具栏也有快捷菜单。

Windows 非全屏使用固定双层工具栏；全屏控制覆盖在视频上，进入顶部区域显示标题栏、进入底部区域显示控制栏。画面中央移动不会唤出控制栏，暂停时也相同；打开播放设置、拖动滑杆、键盘聚焦控件或打开菜单时保持相关操作区域显示。

### 本机续播进度

“保存续播进度”默认开启，仅在此电脑记录内置播放进度；已有有效位置时，先暂停等待选择“继续”或“从头播放”。在播放器设置卡片右上角保存更改；开启后从下一次播放生效，关闭后立即停止当前记录，但保留旧进度。需要删除旧进度时，另行点击“清除全部本机续播进度”并确认。

外部播放器自行管理续播，此模式下开关不可操作，切回内置会保留原选项。续播进度不写入服务端、不跨设备同步、不纳入资料库备份；收起与恢复当前会话不属于持久续播。进度与音量偏好分开，关闭续播仍记住音量；清空“最近播放”不会清除续播进度。

## AI 日中字幕

AI 字幕在内置播放器中识别日语音轨并翻译为中文，无需配置云端 AI 服务。

1. 打开“设置 → AI 服务 → 功能 → AI 字幕”，分别选择语音识别和字幕翻译模型、精度与发布者。语音识别使用 Kotoba Whisper，翻译可选 Qwen3 1.7B 或 HY-MT2 7B。
2. 对尚未下载的精度点击“前往下载”，在“本地模型”中下载所需文件和运行依赖，再“返回用途配置”并保存选择。下载文件本身不会自动修改用途。
3. 播放影片，在“播放设置 → 字幕 → AI 日中字幕”点击“开启 AI 字幕”。也可从“字幕模型设置”收起播放器并跳转到上述功能设置。
4. 等待当前位置附近的识别与翻译，按需选择中日双语、仅中文或仅日语，以及专用字号。可先暂停，让字幕生成一段再继续播放。

识别与翻译均在本机执行，不使用在线模型、不上传音频或字幕文本。首次下载需要联网，模型权重不包含在基础安装包内；运行要求见 [本地模型管理](#本地模型管理)。默认 Kotoba Q5_0／Qwen3 Q4_K_M 组合首次下载约 1.83–1.93 GB，依平台运行依赖而变；文件大小不等于运行内存需求。生成速度依电脑及音频而变，识别错词会影响译文，不能保证实时或完全准确。

任务从当前位置开始，并预先处理后续区间；跳转后优先生成新位置，尚未翻译的区间先显示日语。窗口与全屏共用同一字幕轨道。可“导出已生成字幕”为 SRT/ASS；导出只包含当前已生成内容。停止 AI 字幕后恢复此前选择的字幕，换片或关闭播放会停止任务。远程影片仍需从已授权服务器读取音频，离线推理不能代替远程网络连接。

再次开启会复用本机缓存，不同音轨使用独立缓存。切换识别精度会使用新的识别缓存；切换字幕翻译模型或精度保留日语原文、重新生成中文。可在播放器“清除本片缓存”清除当前影片、当前音轨缓存，或在本地模型页清理全部推理缓存。字幕缓存独立于续播设置，任务临时音频和显示文件在任务结束时清理；诊断方式见 [查看 AI 字幕日志](#查看-ai-字幕日志)。

### 查看 AI 字幕日志

在播放器的“AI 日中字幕”设置中点击“查看日志”，使用默认浏览器打开格式化的本机快照。按时间段对照展示“识别原文 · 日语”和“翻译结果 · 中文”，未完成译文明确标记；最多展示最近 500 条字幕。Kotoba 原始 JSON、翻译提示词、模型原始响应（包含结束原因）及任务错误收在默认折叠的“原始诊断日志”中；译文校验失败时仍保留原始响应。缓存命中会明确标记，不会为了查看日志重新推理。再次点击可更新快照。

日志从本次开启 AI 字幕开始记录，无法追溯旧版本的推理。停止字幕后仍可查看本次记录；重新开启或切换影片后重新记录。最近日志在内存中限量保留，单条过长和较早记录的截断／淘汰会标明。只有点击查看时才写入本机 `cache/local-ai/work/ai-subtitles/AI-subtitle-log.html`，下次查看覆盖，下次应用启动清理。该路径位于用户数据目录；标准 Windows 安装位于 `%LOCALAPPDATA%\Javdex`。日志不会记录远程影片地址或推理访问密钥，也不会上传，但包含字幕原文和译文，分享前请核对内容。

## 本地模型管理

本地模型为字幕和文本翻译共用；“设置 → AI 服务 → 本地模型”管理文件，“功能”页设置各用途。模型页按“语音输入 → 文本”和“文本输入 → 文本”分组，点击“管理精度”查看发布者、文件大小、运行状态和用途引用，包括尚未安装的文件。

| 模型系列 | 用途与可选精度 |
|---|---|
| Kotoba Whisper v2.0 GGML | 日语语音识别；Q5_0（推荐）、F16 |
| Qwen3 1.7B GGUF | 字幕或文本翻译；bartowski Q4_K_M（推荐）、Q5_K_M、Q6_K，Qwen 官方 Q8_0 |
| HY-MT2 7B GGUF | 字幕或文本翻译；腾讯官方 Q4_K_M（推荐）、Q6_K、Q8_0，约 4.62／6.16／7.98 GB |

### 下载、导入与修复

在“模型文件”卡片直接选择“下载来源”：默认 Hugging Face 官方源，也可使用 HF-Mirror 第三方镜像，选择后立即保存，用于后续下载与修复。切换不改变已安装文件、固定版本与 SHA-256 校验；GitHub 运行依赖仍从原地址下载。下载等文件操作期间不能切换来源，镜像不可用时可取消下载、切回官方源重试。

每个精度可“下载模型”，已安装时显示“校验与修复”；下载按顺序执行，可取消并续传，期间仍可浏览其他系列。精度行的“更多”菜单提供：

- “复制下载地址”：跟随当前下载来源，可交给浏览器或下载工具。
- “导入模型文件”：选择与该精度、发布者匹配的 GGUF／BIN 文件，核对大小和 SHA-256 后复制，保留原文件。导入只处理模型，不补运行依赖；缺失时再用“校验与修复”。
- “导出模型文件”：在所选目录创建按模型、精度和发布者命名的子目录，包含模型文件、来源与许可，不包含运行依赖和缓存。HY-MT2 7B 附 Apache-2.0 许可和腾讯版权声明；导出字幕仍在播放器中操作。
- “删除此精度”：仅删除该精度文件，保留其他精度、共享运行依赖、缓存和影片资料；被用途引用的精度需先在“功能”页改选，运行中的精度不能覆盖导入或删除。

模型来源固定到具体仓库版本，下载、导入、修复和导出均校验文件。下载、导入或浏览精度不会改变功能选择；“已下载”也不等于运行依赖已就绪。

### 分别设置字幕与文本翻译

“功能 → AI 字幕”分别保存语音识别与字幕翻译选择；“功能 → 文本翻译”单独设置标题、简介等翻译的模型来源、精度与发布者。每组保存后用于新任务，“前往下载”与“返回用途配置”之间保留未保存选择。

文本翻译可“继承应用默认模型”，通过已配置的 API 服务执行；也可“使用本地模型”，选择 Qwen3 或 HY-MT2 7B。本地来源无需配置在线提供商，所选文件未安装或不可用时会报错，不自动切换到其他模型或在线服务。修改文本翻译不会改变字幕翻译、应用默认或 Agent 用途。

使用时打开“编辑影片资料”，在标题或简介旁点击“AI 译中”。译文填入当前编辑草稿，核对后点击“保存”才写入资料库；取消编辑则不应用。演员、分类和清单简介中带“AI 译中”的字段使用同一文本翻译设置。

本地模型商店是 0.9.0 新增功能，配置从格式 1 开始；不承诺读取未发布开发快照中的中间格式。已有云端连接和 Agent 模型配置按独立升级流程保留，不会被本地模型选择替换。

### 保存位置与清理

“模型文件”卡片显示“保存位置”，可“更改并迁移”或“恢复默认位置”。标准 Windows 安装默认在 `%LOCALAPPDATA%\Javdex\local-ai`，其他系统在应用用户数据目录的 `local-ai`；自定义配置目录使用该配置目录下的位置。

模型按“系列／发布者／固定版本／精度”组织并保留上游文件名，运行依赖按“引擎／版本／平台与架构”共享保存，不按功能重复下载。更改位置会先复制并校验模型、共享运行依赖和未完成下载，成功后切换位置并清理旧副本。缓存独立保存，不随模型迁移；共享运行依赖修复和目录迁移需等待相关任务结束。

“临时文件与缓存”中可“清理未完成下载”或“清理推理缓存”，保留已安装模型、运行依赖和影片资料；运行任务期间不可清理。未完成下载保留七天供续传，安装暂存保留一天，过期文件自动清理。推理缓存清理会删除可复用字幕和工作文件，再次使用需重新生成。

### 运行环境

本地推理支持 Windows x64、macOS 13.3+（Apple Silicon／Intel），以及满足运行依赖要求的 Linux arm64／x64。Linux 需要 glibc 2.38+、GCC 14 的 C++ 运行库与 xz-utils，例如已更新的 Ubuntu 24.04；Debian 12、Ubuntu 22.04 和 musl 系统不在当前推理支持范围内。macOS 安装包提供识别与音频工具，无需另装编译器。

支持的平台会补齐匹配系统、架构的运行依赖；不同平台工具分开保存。其他平台仍可管理、下载和导出权重，但不能启动本地推理。请检查精度行是否“可运行”、系统依赖及可用内存，模型文件大小不是内存需求；不会因某模型无法运行而自动改用在线服务。

## 处理待确认与媒体库维护

“待确认”集中展示扫描资源归属、资源身份、影片刮削候选与演员名称冲突。根据分类核对文件名、NFO 番号、图片和候选资料，再作出选择；丢弃待办前注意确认弹窗中的影响说明。

不同维护操作的结果不同：

| 操作 | 影响 |
|---|---|
| 从清单移除影片 | 取消清单引用，不删除影片文件 |
| 自动清理空归属 | 多库影片在某个库的资源记录归零后自动移出该库；此规则保留最后一个归属；清单引用和置顶会阻止清理，影片资料、评分和图片保留 |
| 归档媒体库 | 暂停扫描并从侧栏隐藏，保留资料与来源；可在“设置 → 媒体库”选择归档库恢复 |
| 永久删除媒体库 | 删除该库成员、资源记录和扫描等数据，保留本地文件与全局影片资料 |
| 永久删除影片 | 删除全局影片资料、各库成员与资源记录，并删除关联的本地视频和 STRM 源文件 |

不再提供手动“移出媒体库”操作。原“清理无资源成员”开关保留：开启后，安全扫描也可清理影片的最后一个无资源归属；清单引用和置顶仍阻止清理，不删除全局影片。资源删除、跨库移动、目录迁移和备份恢复在操作完成后检查空归属；扫描只在完整扫描且所有目录在线的安全清理阶段检查。NAS 断线、目录无权限或扫描失败不会仅凭文件不可访问移除归属。

执行前以操作弹窗的影响预览为准。只想暂时隐藏整库时，可以归档；不要用永久删除影片代替隐藏。

## 利用本地 NFO 导入与导出资料

NFO 是保存在影片旁的资料文件，可包含标题、演员等信息以及图片引用。

### 导入已有资料

已覆盖以下工具的常见 NFO 格式和本地图片约定：

| 来源工具 | 已覆盖内容举例 |
|---|---|
| Movie_Data_Capture（MDC） | 番号、制作商、发行方、发行日期、时长、简介及评分 |
| MDCx | 同名 NFO、发行方、系列、原始简介及本地封面查找 |
| Javinizer | 番号、系列、演员，以及封面、背景、演员头像和额外图片目录约定 |
| JavSP | 番号、系列、发行日期、制作商，以及 `movie.nfo`、海报和背景图约定 |

验证基线记录于 **2026-09-05**，使用依据各工具固定提交版本制作的合成样例和自动化测试，不代表各版本、所有自定义配置或未知字段都完整兼容。固定版本与样例范围见 [兼容样例说明](../test-fixtures/nfo/README.md)，字段与命名依据见 [原始调研](NFO_IMPORT_EXPORT_RESEARCH.md)。

在媒体库创建向导或该库“常规”设置中启用“自动导入本地 NFO”。扫描首次发现资源时，会尝试读取相邻 NFO，为尚未刮削成功的影片补齐空字段。

没有 NFO 是正常情况；已刮削成功的影片不会被自动覆盖，已有正式资源也不会在每次扫描时重复读取 NFO。文件名和 NFO 的番号冲突时，需要到“待确认”核对。

导入图片仅接受媒体库根目录内的安全本地文件；远程图片地址和越界引用会被忽略。修改 NFO 后，Javdex 不会持续同步这些变化。

### 导出给其他媒体软件

1. 打开“设置 → 存储与导出 → 导出影片资料”。
2. 选择一个或多个媒体库，以及目标软件。
3. 选择封面、背景和可选附件；影片资料与演员名单始终导出。
4. 点击“预览导出”，核对文件位置、新建、跳过、覆盖和提示信息。
5. 确认后执行导出，结束时查看逐项结果，再到目标软件刷新本地资料或图片。

| 选项 | 使用前了解 |
|---|---|
| 已有文件 | 默认跳过；需要更新时显式选择覆盖同名文件，并重新预览 |
| 写入位置 | 写到对应本地视频或 STRM 源文件旁；普通链接没有本地写入位置，会被跳过 |
| 样张 | 默认关闭，作为备份或迁移附件保存，不承诺在播放器中显示为样张画廊 |
| 演员头像 | 默认关闭，各软件对本地头像的支持不同 |
| 运行方式 | 导出期间保持应用打开，其他操作暂时锁定；停止后保留已写入文件 |

支持通用/Kodi、Jellyfin、Emby、Plex NFO Agent 和 Infuse 的导出选项。Plex 需要相应 NFO Agent，Infuse 需要启用本地资料；完整要求与已验证范围见 [NFO 兼容性说明](NFO_COMPATIBILITY.md)。

导出不是持续同步或完整备份，不包含清单、个人评分等全部应用数据。预览过期或某些文件失败时，查看原因、重新预览后再处理。

## 外观、图片与本地数据

### 调整显示

在“设置 → 外观与隐私”选择主题、封面显示方式、详情背景和头像智能构图。头像人脸检测在本地执行；演员列表还可筛选未检测到人脸的头像，便于逐个检查。

隐私模式可按范围遮盖图片、替换头像或禁用图片预览，只改变界面显示，不会加密原文件。

### 备份与恢复

打开“设置 → 存储与导出 → 备份与恢复”。创建备份会保存**当前正在使用**的本机或服务端资料库，文件保存到这台电脑；服务端需先完成写入授权。备份期间暂停资料写入，完成、取消或失败后继续正常使用。

备份包括全部媒体库的正式资料、影片与资源关联、演员、分类、标签、自建清单、收藏、稍后观看、个人评分，以及正式封面、头像、样张和写真。**不包含原始视频、插件和模型配置、本地模型文件、桌面工作记录、最近播放、续播进度、AI 字幕缓存、待确认候选、运行任务及登录凭据**。加密图片在备份副本内解密，源图片不变；备份格式 1 不加密，请妥善保管。归档与解压数据各有 64 GiB 上限。

新版可恢复同版或旧版生成的备份：0.9.0 支持备份格式 1、正式数据库版本 17 至 20。系统先校验原包，再复用数据库升级流程处理临时副本，原备份文件保持不变；成功后显示升级说明并进入目录对应。更高应用版本或数据库版本生成的备份、未知包格式及不受支持的开发版结构会被拒绝。数据库版本未变化时，也不再要求应用版本完全相同。

若来源资料登记的图片文件缺失，备份会停在“核对缺失图片”，汇总数量和路径。可取消并补齐图片后重试，也可点击“确认缺失并继续备份”：仅在备份副本中清除缺失图片的文件引用，保留其他资料、图片和已有来源网址，原资料库不变。缺失清单写入备份，操作记录和恢复预览会提示这些图片无法恢复。缺失清单变化后需要重新确认。覆盖恢复前的目标自动备份仍要求完整，失败则停止覆盖。

操作记录中的已完成、失败和已取消项可点击“删除记录”，核对确认框后删除。默认只移除记录；可勾选同时清理该任务在 Javdex 备份区内的备份和临时文件，确认框会显示所在设备、目录及预计释放空间。手动另存到电脑的副本、选择用于恢复的原始备份、当前资料库和原始视频均保留。文件清理无法撤销；清理失败会保留记录，供继续重试。

删除恢复记录不会连带删除恢复前的自动保护备份；保护备份须通过自己的记录单独处理，并会提示失去该恢复点。仍被未结束恢复任务使用的保护备份不能清理文件。运行中、传输中及“需要恢复处理”的任务不能删除；未执行的恢复任务可先取消，再删除记录。下载刚结束时可能需要稍后重试，以免中断分块传输。

远程使用过程中若出现“写入授权已失效”，桌面会暂停后续远程请求，并提供“打开连接设置”入口。授权统一在“设置 → 存储与导出 → 资料库连接”处理：请部署者在服务端运行 `recover` 命令取得一次性令牌，再在设置中领取新凭据。授权恢复后先核对资料是否已保存，再手动提交尚未完成的修改。桌面不会自动重放失败的写入，也不会自动切回本地资料库。

恢复使用独立向导，可点击“稍后继续”暂时关闭，当前页面会保留目录选择。确认后，执行进度显示在页内任务卡；结束后结果归入操作记录。操作记录分页显示，“展开详情”和“收起详情”始终在原记录行操作，不改变记录位置和总数，也不影响当前恢复向导的目录选择。

恢复步骤：

1. 选择这台电脑上的 `.javdex-backup` 文件，等待上传和校验，查看备份摘要。
2. 为每个来源目录选择目标目录。本地模式使用系统目录选择器；远程模式选择服务端挂载及其子目录，不能填入桌面电脑的路径。不需要对应视频时，明确选择“仅保留资料”。无来源目录的本地资源也需要单独确认舍弃关联。
3. 核对当前目标中的资料数量、资源关联移除数、缺失文件及自动备份目录。缺失不代表播放已验证；舍弃资源后按统一规则清理多库影片的空归属，保留最后一个归属和受清单、置顶保护的归属。缺失或舍弃资源的媒体库会关闭“清理无资源成员”，避免后续扫描清理仅保留资料的影片。正在运行的任务和待确认事项须先处理。
4. 勾选已核对覆盖范围、目录对应和缺失资源，再点击“备份当前资料并恢复”。系统先生成并校验目标自动备份，再恢复资料和图片。提交阶段不可取消。完成后资料库内容身份更新，旧草稿、旧页面和播放凭据不再适用于新资料；服务端身份及当前写入授权保留。

已连接并认主的远程模式还可“从本机资料库导入”：桌面使用隔离的导出宿主读取这台电脑原有资料库，自动导出和上传，再进入同样的目录对应和覆盖确认步骤。**本机资料库保留且可独立使用，两份资料不自动同步**。此操作不移动或复制原始视频。

上传、下载中断可在任务卡或对应操作记录中重试传输；不要更改原备份文件。恢复失败会保留原因；如提示“需要恢复处理”，重启资料库所在设备上的 Javdex，让它先完成日志恢复，再查看原任务。不要反复创建覆盖任务。操作记录中的自动备份可另存到本机；备份文件不会自动定期清理，可在删除记录时明确选择清理托管文件。自动备份位于目标用户数据目录的 `backups/`（Docker 默认 `/data/backups/`，宿主位置取决于 `/data` 卷挂载）。

资料转移统一使用本页的备份、恢复和导入。未正式发布的旧离线迁库命令、接口和专用包格式已移除，不提供旧包导入。

### 迁移图片目录与加密

在“设置 → 存储与导出 → 图片资源”查看当前图片目录。选择新目录并确认后，应用会迁移已有图片。此操作不移动原始视频或应用数据库。

图片加密覆盖封面、头像、样张、写真与清单封面，不包含影片文件或整个数据库。启用或关闭时会处理全库图片，完成前应用暂时锁定。

加密图片的读取依赖当前机器、用户与应用数据路径；不要把复制加密图片目录当作可跨设备恢复的备份。整库迁到独立服务时，源端会在导出包内自动解密正式图（源目录保持加密），密钥与别名约定见 [服务端模式](SERVER_MODE.md)。

### 数据保存在哪里

应用使用系统的 Javdex 用户数据目录，与安装目录分开。默认目录结构如下，`userData` 表示实际应用数据目录，并非需要手动创建的文件夹：

```text
userData/
  desktop-work.db              # 此电脑的 Agent 运行记录、候选草稿和恢复状态
  data/library.db              # 影片、演员等资料数据库
  settings.json                # 应用设置
  this-computer.json           # 此电脑的连接、播放方式、音量与续播选项
  recent-playback.json         # 此电脑按资料库隔离的最近播放历史
  playback-progress.json       # 此电脑的内置播放续播位置
  local-models.json            # 本地模型保存位置、下载来源与用途选择
  scraper-service-secrets.json  # 刮削服务凭证
  local-ai/                    # 模型与共享运行依赖，标准 Windows 安装另存于 LOCALAPPDATA
  cache/                      # AI 字幕缓存和任务临时文件
  media_assets/                # 默认图片目录，可在应用中迁移
    covers/
    avatars/
    actress_gallery/
    samples/
    playlist_covers/
```

`desktop-work.db` 自 0.8.0 起独立保存 Agent 状态；尚未完成旧资料拆分的桌面首次启动时，会将原 `library.db` 中的 Agent 状态单向复制到工作库。只使用本机资料库的安装也执行此步骤，之后的运行记录与草稿不会复制回 `library.db`。只保存 `library.db` 或应用内资料库备份，会漏掉这些工作记录；不能把它们当作完整桌面备份。

这只是主要文件示意，应用还会保存插件、云端模型配置和任务数据等文件。需要手动备份时，先完全退出应用，再保存整个用户数据目录、自定义图片目录及实际本地模型目录；标准 Windows 安装的模型与推理缓存位于 `%LOCALAPPDATA%\Javdex`，也须单独考虑。备份中应同时包含 `desktop-work.db` 与 `data/library.db`，原始视频另行保存。系统保护的服务凭证迁移后可能需要重新配置。

联网刮削、AI、更新检查和打开外部链接会访问各自的服务；本地保存资料不意味着所有功能都离线执行。

## 遇到问题

| 现象 | 先检查 |
|---|---|
| 扫描后找不到影片 | 当前媒体库、来源目录是否启用且可访问、扫描结果、最小时长设置与待确认项 |
| 刮削来源不可用 | 来源是否配置完成、网络是否可访问、组合来源的字段分配是否有效 |
| Agent 采集或清单导入无法开始 | 是否已添加支持工具调用的可用模型，并保存默认模型或对应助手用途配置；本地字幕模型不能代替 Agent 模型 |
| 内置影片无法播放 | 所选资源是否为可访问的影片文件、安装包是否含匹配运行库；Linux 是否显式启用 X11／XWayland；远程连接与授权是否有效。可重试同一资源或显式外部打开 |
| 外部播放或链接打不开 | 播放器程序路径是否有效；远程文件是否使用支持网络播放的程序，网页或 Magnet/ED2K 是否有对应应用 |
| AI 字幕或本地翻译不可用 | “功能”页的模型与精度是否已保存；对应文件和运行依赖是否“可运行”，系统、内存是否满足要求；先校验与修复，再查看字幕日志或错误详情 |
| 最近播放或续播没有出现在另一台设备 | 两者均只在当前电脑保存，按资料库身份区分，不会同步；最近播放记录开始播放，不表示已看完，也不等于续播进度 |
| 远程资料库连不上 | 服务是否在运行、地址是否可访问、桌面与服务版本是否相同；版本不符或缺少写入凭据时按界面提示处理，不会自动改回本机库 |
| 导出后目标软件没变化 | 是否跳过了已有文件、目标软件是否启用本地资料并刷新，以及兼容性说明中的限制 |
| 归档后侧栏找不到媒体库 | 在“设置 → 媒体库”选择归档库并恢复 |

仍无法解决时，请 [提交 Issue](https://github.com/JavdexLabs/Javdex/issues/new)，附上应用版本、操作系统、复现步骤及界面显示的错误。分享日志或截图前隐去令牌、私人路径和不希望公开的资料。

## 局域网浏览与播放

1. 在桌面端打开“设置 → 网络 → 网页服务”，设置访问账号、独立密码与端口，开启服务并保存。设置概览的状态卡片也可进入该页。
2. 让手机、平板、电脑或电视连接同一局域网，在浏览器打开桌面显示的局域网地址；手机也可扫描“访问入口”中的二维码。
3. 使用账号密码登录，或在桌面点击“开启配对”，让新设备选择“与桌面配对”并显示六位码，再在桌面输入、核对并批准。
4. 按需勾选“记住此设备”，重启应用后仍可保持登录；在桌面设备列表中可查看、重命名或撤销设备授权。修改账号或密码会让所有设备重新登录。

网页可浏览活动媒体库、搜索影片、查看清单与详情，通过随机发现和近期添加挑选影片。手机可在“浏览范围”切换媒体库或清单；返回列表会恢复浏览位置，剧照可点击预览和缩放。

影片详情可播放浏览器支持的本地视频与直连资源，支持拖动进度和全屏，也可下载本地资源或复制、打开其他链接。不提供转码，能否播放取决于浏览器、设备编码支持和资源可达性。

Web 端只读，编辑、扫描和刮削仍在桌面端完成；网页不使用桌面的 libmpv、本机续播或本地 AI 字幕，也不显示此电脑的“最近播放”。桌面本地网页服务需保持应用运行，独立服务端则由服务进程提供访问。当前使用未加密的局域网 HTTP，仅在可信局域网使用，不要映射公网端口。完整配置、播放限制和网络说明见 [局域网 Web 访问](LAN_WEB.md)。

### 关闭窗口后保留后台运行

在“设置 → 外观与隐私 → 窗口行为”开启“关闭窗口后最小化到系统托盘”（默认关闭、立即生效）。之后关闭窗口只会隐藏主窗口，网页服务与后台任务继续运行。点击托盘图标或选择“打开主窗口”可恢复；选择“退出 Javdex”或使用系统的退出应用命令会完全退出并停止服务。前台 NFO 导出期间仍需先完成或终止任务。
