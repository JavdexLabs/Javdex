# 将 Gfriends 作为可选演员头像源

Javdex 将以标准 bundled `actress` 插件内置 `Gfriends`，但只声明支持 `avatar`，不作为演员身份、别名或完整资料的权威来源。它默认不启用；用户明确选择后，插件按主名、再按别名进行精确匹配，对首个命中的名称采用 Gfriends 质量升序索引中的最后一个候选，并按索引原样使用包括 `AI-Fix` 在内的推荐结果；未命中时保留现有头像且不隐式回退 Xslist。

为避免每次下载约 6.5 MB 的 `Filetree.json`，现有 `fetchBuffer` Interface 将增加受主进程配额约束的插件级持久缓存：首次下载后保存，最多每 24 小时通过 ETag 检查更新，成功时原子替换，失败时允许使用最后一次成功结果。Gfriends 以官方 Raw 为主源、当前命名空间的 jsDelivr 为首次获取回退；插件仍使用一次性 Worker，只有基准测试证明批量解析不可接受时才另行调整 Worker 生命周期。

组合演员刮削将按字段源隔离故障：单个来源失败时产生警告并继续应用其他来源的结果，只有所有已请求来源都失败时整次失败。Javdex 保持 MIT；项目明确接受 Gfriends 未提供标准数据许可证、声明禁止商业用途且图片权利属于第三方所带来的集成风险，不把取得上游书面授权设为实现或发布的前置条件。
