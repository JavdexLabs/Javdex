# 演员删除模式、显式确权与事务边界

演员删除提供两种语义明确的模式：

- `only-unlinked` 是默认安全模式。主进程执行时重新检查整批演员；任一演员仍有关联影片时整批拒绝删除。
- `unlink-videos-and-delete` 是高风险模式。界面必须先展示主进程根据当前数据库返回的关联演员数与受影响影片数，并只能通过独立的“我已了解，仍要删除”操作提交；普通确认、回车或默认焦点不能触发该模式。

真正执行时，主进程不信任预览计数，而是在同一个 SQLite 事务内重新读取关联关系、按所选模式解除 `video_actress` 关联，并删除演员名称归属、待确认结果和演员档案。任一步失败都回滚整个批次。两种模式都绝不删除、移动或重写影片记录及影片资源。

演员头像、头像源、写真和待确认暂存资源在数据库事务提交后尽力清理。文件系统无法加入 SQLite 事务，因此清理失败不会恢复演员档案；应用服务记录日志并返回具体路径与错误，供界面提示诊断。
