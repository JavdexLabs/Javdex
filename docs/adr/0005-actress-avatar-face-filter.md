# 演员页无人脸头像筛选采用会话级本地检测

演员页新增 `avatar=without-face` 筛选。首次进入该筛选时，Renderer 使用现有本地 MediaPipe 人脸模型串行扫描全库所有可用展示头像，并在 Renderer 进程生命周期内按演员 ID 与头像内容指纹缓存“有脸 / 无脸”结果；不把检测结果写入数据库。搜索、性别、刮削状态和排序变化只对这份全量缓存重新组合，模型或图片异常作为识别失败单独提示，不归入“无人脸”。

## Consequences

- `avatar=without` 继续表示没有可用头像，`avatar=without-face` 只表示有头像但推理成功且未检测到人脸。
- 缓存与“是否需要全量重扫”标记在离开演员页后仍保留，直到应用退出或 Renderer 刷新；头像内容变化会使对应缓存项失效，未覆盖的新头像会增量补扫。
- 取消扫描不会切换到“无人脸”筛选；取消前已完成项保留缓存供下次续扫，识别失败项不缓存，并在后续重新进入筛选时重试。
