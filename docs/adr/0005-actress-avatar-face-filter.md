# 演员页无人脸头像筛选采用会话级本地检测

演员页新增 `avatar=without-face` 筛选。首次进入该筛选时，Renderer 使用现有本地 MediaPipe 人脸模型串行扫描全库所有可用展示头像，并在当前页面会话按演员 ID 与头像内容指纹缓存“有脸 / 无脸”结果；不把检测结果写入数据库。搜索、性别、刮削状态和排序变化只对这份全量缓存重新组合，模型或图片异常作为识别失败单独提示，不归入“无人脸”。

## Consequences

- `avatar=without` 继续表示没有可用头像，`avatar=without-face` 只表示有头像但推理成功且未检测到人脸。
- 刷新页面或离开演员页后缓存失效；头像内容变化会使对应缓存项失效。
- 取消扫描不会应用不完整结果；已识别的失败项不缓存，后续重新进入筛选时重试。
