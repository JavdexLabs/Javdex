# ADR-0014：统一影片资源运行时合同

影片来源曾同时以“文件”和“资源”两套运行时合同存在：本地来源额外暴露文件集合、文件计数、主文件路径和专用 IPC，而链接来源使用影片资源。双合同使列表计数、详情展示、主资源切换和删除行为容易分叉。

## 决策

运行时只使用**影片资源**合同：

- 列表只投影资源总数、主资源类型和主资源优先的有序资源类型；详情只返回一个有序影片资源集合。
- 本地文件是 `local` 类型的影片资源。磁盘路径、大小、时长和修改时间分别保存在该资源的 locator 与本地属性中，不再转换成文件专用 DTO。
- 打开、设主、编辑和移除都以资源 ID 为入口。`local` 资源允许“在文件夹中显示”和删除其磁盘文件；按 ADR-0019 受 `.strm` 源文件托管的链接资源允许定位和删除该源文件。普通链接资源不提供磁盘文件操作。
- 有资源的影片至多有一个主资源；第一条资源自动成为主资源。主资源移除后按“可访问本地资源、视频直链、Magnet、ED2K、网页链接”选择候选，同类型按添加时间和 ID 稳定排序。打开失败不会自动尝试其它资源。
- 媒体库扫描核对本地资源，并按 ADR-0019 核对受 `.strm` 源文件托管的链接资源。只有已确认可访问目录中的缺失本地文件或 STRM 源文件可以移除对应资源；普通链接资源和离线目录中的源文件不参与缺失清理。文件扫描阶段取消或全局失败时不进入延迟目录清理和无资源成员移除；清理开始后的批次提交、取消与失败规则按 [ADR-0028](0028-batch-scan-cleanup-at-commit-boundaries.md) 执行，保留已提交批次及其真实审计。

## 迁移边界

历史数据库升级仍识别 `video_files` 并一次性迁移为 `video_resources(kind = 'local')`，随后删除旧表。除迁移及其回归测试外，运行时模块、IPC、共享类型和渲染端不得引用旧表或文件专用合同。

## 结果

资源数量和主资源选择只有一套来源，网络来源与本地来源可以共同维持影片记录。涉及真实磁盘文件的操作仍保留明确的本地文件文案，应用自有图片继续使用独立的**媒体资源**术语和 `MediaAssetStore` 边界。
