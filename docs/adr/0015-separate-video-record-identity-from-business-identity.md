# 分离影片内部身份与业务身份

Javdex 继续以永久内部影片 ID 标识和关联影片，不再以番号充当记录身份；完整的“发行商分类实体 + 规范化番号 + 发行日期”构成硬唯一的影片业务身份。扫描初建且三项未齐的影片属于身份待定，允许与同番号影片并存；后续刮削或编辑补全身份时若撞上现有完整身份，不静默覆盖，而进入待用户合并影片或修正身份字段的冲突流程。为保持日期模型简单，只有年月的刮削值继续规范为当月 `01` 日并参与同一身份约束，不另存日期精度。这样既支持现实中的重复番号，也避免在扫描阶段缺少发行商和日期时伪造唯一性。

升级时重建影片表以移除番号唯一约束，但保留既有内部 ID、资料与关系，并只对完整业务身份建立唯一索引。迁移前若发现旧数据已违反新约束，升级保持数据库原样并报告冲突影片，不自动合并影片或清空身份字段。
