# 在影片记录之外持久保存未决扫描与刮削决定

Javdex 不用半成品影片或第四种累计刮削状态表达歧义：无法唯一归属的新扫描资源持久保存在待确认扫描组中；同一源文件的文件名与本地 NFO 给出不同规范化番号时持久保存为待确认资源身份；多候选或身份冲突的影片刮削则以每部影片至多一份的自包含快照保存完整候选、来源参数与全部候选资源。三类未决结果确认前均不写入正式影片资料，前两类也不建立影片资源或媒体库成员；它们跨重启保留且不自动过期。待确认扫描组只能由用户完整分配全部资源，或在后续安全扫描确认组内资源均已不存在时清理；待确认资源身份由用户选择采用文件名或 NFO 身份，源文件确认缺失时清理；待确认影片刮削结果则由用户确认、显式丢弃、有效替换或所属影片清理时原子处置。影片刮削待确认期间锁定影片元数据，但不锁定影片资源与播放列表。
