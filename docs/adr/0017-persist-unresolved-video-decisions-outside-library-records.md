# 在影片记录之外持久保存未决扫描与刮削决定

Javdex 不用半成品影片或第四种累计刮削状态表达歧义：无法唯一归属的新扫描资源持久保存在待确认扫描组中，确认前不进入普通媒体库；多候选或身份冲突的影片刮削则以每部影片至多一份的自包含快照保存完整候选、来源参数与全部候选资源，确认前不写入影片资料或改变累计状态。两类未决结果均跨重启保留且不自动过期；待确认扫描组只能由用户完整分配全部资源，或在后续安全扫描确认组内资源均已不存在时清理，待确认影片刮削结果则由用户确认、显式丢弃、有效替换或所属影片清理时原子处置。影片刮削待确认期间锁定影片元数据，但不锁定影片资源与播放列表。
