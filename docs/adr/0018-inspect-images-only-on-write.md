# 图片探活仅发生在写入

空字段补齐、缺失字段筛选和批量目标计数曾把「封面/样张是否为可读本地文件」做成同步读盘探活，并与标量字段判定绑在同一条全库扫描上。设置页对库内全部影片勾选缺失「标题」时，主进程会逐条 `getVideoById` 并检查每部片子的封面和样张，界面表现为卡死。

决定：只有写入新图片时才探活——下载落盘前用 `isUsableImageBuffer` 校验字节，HTML、空响应和损坏图视为资源不可用，不得清空或局部替换已有资源。空字段补齐与缺失字段筛选只看媒体资源引用或远程链接是否存在；库里还有路径或 URL 时，即使本地文件丢失或损坏也不算缺失。批量目标用 SQL 表达这些引用谓词，不再逐条探盘。演员批量缺失头像同样只看 `avatar_path`。
