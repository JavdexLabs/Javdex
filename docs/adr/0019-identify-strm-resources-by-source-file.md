# 以源文件标识 STRM 影片资源

STRM 影片资源由本地 `.strm` 源文件持续托管，因此其稳定身份采用源文件而不是当前目标链接：目标或链接类型变化时原地同步，不同源文件指向同一目标时仍保留为独立资源，并可与相同目标的普通手动链接并存。普通手动链接之间继续按规范化目标去重；这一差异使每个 STRM 源文件都能独立参与重定位、缺失清理和恢复，而不会争用另一源文件的资源记录。源文件只在完整文件名与规范化链接目标均唯一匹配时跨目录重定位，重命名则按新旧两个资源处理，避免仅凭公共链接误认文件身份。源文件同时是目标与链接类型的唯一权威来源，应用只读并随扫描同步，不反向改写文件或覆盖独立的用户维护展示信息；删除资源或影片时则与本地视频文件一样安全删除源文件，但不访问远端内容。

存储继续以 `video_resources` 作为唯一资源表，不新增 `strm` 资源类型或平行表；STRM 记录增加可空源路径，并以规范化源路径生成资源唯一键，现有类型与 locator 仍表示实际目标。源文件修改时间与大小不持久化，因为同步每次读取内容，重定位也不依赖文件指纹。
