# 跨媒体库共享全局影片资料并显式保存成员关系

Javdex 将影片、演员、分类实体、标签与清单保留在一个全局目录中，以永久影片 ID 和既有影片业务身份约束维护一份共享资料；命名媒体库只拥有独立配置、根目录、影片成员、影片资源与扫描状态。同一影片可通过显式成员关系进入多个媒体库，但每条影片资源恰属一个媒体库，主资源也只在该媒体库成员内选择。相比给 `videos` 增加单一 `library_id`，这个决策避免跨库搜索出现同一作品的资料副本；相比仅由资源推导成员，它保留无资源成员、独立加入时间和可恢复归档。代价是所有库共享影片刮削结果，读取、播放、资源变更和删除都必须携带明确的媒体库作用域；首期不增加每库元数据覆盖。
