# 0027 — 隔离只读局域网 Web 访问

为手机、平板、桌面浏览器与电视提供与 Electron 管理界面独立的 React 浏览入口。Web 端不能调用 preload 或桌面 IPC。主进程内的 HTTP 模块仅提供固定白名单的查询、认证和流媒体路径，目录适配层显式投影无磁盘路径的 DTO，并对每次详情、图片、播放访问复核活动媒体库与可见成员归属。

局域网服务默认关闭，账号、端口、启停和会话撤销只由可信桌面 IPC 管理；独立密码哈希配置不进入普通设置快照。使用本地只读账号、随机会话 Cookie、服务端摘要与时限，防止跨站请求、DNS rebinding 和无上限密码尝试。第一版只支持可信局域网 IPv4 HTTP；不默认开放公网、代理头信任、TLS 或用户角色管理。

本地视频按数据库资源 ID 定位，通过既有媒体库根目录身份检查与打开文件描述符复核后分段流式发送，遵循 ADR-0024；不提供任意路径读取或任意 URL 的服务器代理。直连视频交给浏览器访问，不转码、不写播放历史。图片继续通过 MediaAssetStore 读取（含已加密资源），仅允许被可见影片正式引用的图片。

浏览器列表筛选与排序存入 URL，详情保留来源 query，列表保持挂载以保留滚动。其自适应网格和原生视频播放是独立浏览表面，不改变桌面端现有嵌套详情栈与编辑路由。

认证扩展采用桌面批准的短期六位码配对，浏览器以独立高熵秘密单次兑换只读会话。批准与设备撤销仅走可信桌面 IPC；网页仅开放配对申请、查询/兑换及取消端点。用户明确选择记住后，服务端持久化随机凭证摘要与原始授权时间，跨重启恢复但不延长闲置或绝对期限；密码/账号变更及禁用服务撤销全部授权。普通只读浏览器不具备委托授权权。地址二维码仅帮助打开网页，不携带永久凭证。
