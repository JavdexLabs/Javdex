# 批量译文在发起设备暂存，确认后写入全局目录

模型运行与未应用译文归发起的桌面端。本机资料库和拥有编辑权限的远程资料库都可发起批量翻译。关闭弹窗或切换页面后任务继续，应用退出时保留进度，重启后由用户继续。其他可信设备可读取已应用的资料。此分工沿用 [ADR-0029](0029-server-mode-extends-root-and-web-isolation.md)。

每批任务默认生成待确认译文，用户在预览后通过「应用所选」授权写入。也可在提交时开启「翻译后直接应用」，提前授权写入本批所选字段的新译文。两种方式都由全局目录的权威写入端在同一事务内核对影片身份、来源媒体库成员关系及所选字段原文，并写入匹配的字段。原文已经修改或清空的字段保留为冲突，其他符合条件的字段仍可应用。写入遵守既有待确认刮削锁定与累计刮削状态规则。

任务作用域固定到发起资料库和来源媒体库，影片移出来源媒体库后须从当前所属媒体库重新发起。模型由用户提交任务时确认，每部影片独立调度。模型失效时暂停受影响的影片任务，为这部影片换模型须再次确认。这两项边界让后台恢复延续提交时的资料范围和模型选择。交互、恢复和验收见[批量元数据翻译方案](../BATCH_METADATA_TRANSLATION_DESIGN.md)。
