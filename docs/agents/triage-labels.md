# 分类标签

工程技能使用五种标准分类角色。下表定义这些角色在本仓库 Issue 跟踪器中对应的实际标签。

| 标准角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估和分类 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可以交给 AI Agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工判断或实现 |
| `wontfix` | `wontfix` | 已决定不处理 |

当技能提到某种分类角色时，使用表中对应的本仓库标签。若以后修改 GitHub 标签命名，应同步更新本文件右侧一列。
