# 0.9.0 预览阶段历史更新记录

本页保留正式版本准备前的逐次变化与当时验证边界，不作为当前安装、升级或发布状态说明。当前说明见 [0.9.0 发布说明](../../../.github/release-notes/v0.9.0.md)。

## 0.9.0-beta.3 — 2026-10-15

- 精简后续 Release 附件：四个平台的播放源码材料按 SHA-256 汇总去重为一个总源码包，保留各平台构建材料、安装包与运行库对应清单及恢复工具；总包校验通过后才允许发布服务端镜像。部署示例改用版本对应链接，升级公钥仍内置镜像，不再重复上传这三个辅助附件。已公开版本不变。
- 服务端每个架构的完整升级归档与签名 JSON 合并为一个 `.javdex-update` 文件，发布附件进一步减至 10 个；客户端单次选择文件并支持内层归档断点续传，在线检查和下载使用新格式。不保留历史 Beta 的分离格式入口，签名信任根、架构、版本、摘要、解压与原生验收门禁保持不变；旧容器管理入口需随基础镜像升级。

## 0.9.0-beta.2 — 2026-10-14

- 修复 Beta.1 桌面安装包缺少内置播放运行库：四个原生目标从固定源码构建 libmpv，随包交付配套源码和许可；包内加载、PCM EOF、来源闭包与 macOS 签名加入发布门禁。
- 修复 Windows 的构建工具路径、静态 pkgconf、必需线程后端和 GNU 导出表解析；修复 Linux 静态字体依赖链接及搬移前测试加载路径。
- 修复模型管理器关闭与启动的竞态、既有重复 CSS 规则及跨平台测试路径/换行假定。
- 维持数据库 schema 20、模型管理文档 4；不覆盖 Beta.1、稳定 latest 或 main。桌面和服务端使用相同 Beta.2，升级包仍严格校验签名、来源和版本。发布状态以 [Beta.2 Release](https://github.com/JavdexLabs/Javdex/releases/tag/v0.9.0-beta.2) 为准。

## 0.9.0-beta.1 — 2026-10-13

这是 0.9.0 的首个 Beta。安装包与镜像的发布状态以对应 Release 为准，预发布不会触发稳定版更新提醒；版本与升级说明见 [Beta 发布说明](../../../.github/release-notes/v0.9.0-beta.1.md)。

### 服务端更新

- 官方 Linux 容器内置常驻更新管理进程，用户只部署一个容器，无需宿主机助手或 Docker socket。支持签名完整发行包、在线准备、离线断点上传、持久版本选择、非 root 业务进程监督、完整快照、待验证启动、失败恢复和跨版本更新授权；首次只需配对，Node/系统运行环境仍通过维护镜像更新。
- Beta 与正式发布都生成服务端双架构签名升级包，缺少签名配置时在上传镜像前失败；显式离线上传支持 Beta 升级，版本比较遵循 SemVer，拒绝降级。默认在线检查仍只跟踪正式版。桌面打包只收录正式桌面/Web 构建，排除容器管理器、测试报告与诊断日志。
- 修复 Beta 桌面检查正式更新时被误判为无效版本；同系列正式版可以提示升级，旧正式版不提示降级，更新通道仍不接收 Beta。

### AI 云端服务

- MiniMax 新连接默认使用官方推荐的 Anthropic Messages 与国内服务地址，保留已有连接配置；提高思考模型的连接测试与短文本翻译预算，Agent 后续工具调用和会话恢复完整保留思考块。

- 按官方目录更新各供应商的内置生成模型；过时且无用途引用的内置模型自动删除，有引用的转为“手动添加”并保留模型 ID、名称、能力覆盖及用途绑定，仍在目录中的内置模型和用户手动模型保留。新预设按同一连接内的模型 ID 去重补入。OpenAI 新预设使用 Responses，模型测试与实际调用遵循相同协议。

- 补齐 OpenAI Responses 与 Google Gemini 原生协议，接通模型查询、连接测试、在线文本翻译、JSON 调用及 Agent 流式工具调用与会话恢复；新增 Gemini、阿里云百炼预设。升级保留已有连接和用途选择，并补齐新预设；Gemini Agent 网络请求继续遵循 AI 服务代理设置。

### 许可证

- 当前源码整体采用 GPL-3.0-or-later（GPL v3 或后续版本），同步项目、workspace、关于页及官网许可说明；此前按 MIT 发布的版本保留原有授权，第三方版权与许可声明保持。

### 维护

- 将 MCP 开发依赖链中的 `proxy-addr` 锁定至 2.0.8，修复 IPv4-mapped IPv6 代理信任网段告警；其他依赖版本不变。

- 以已发布 0.8.0 为基线，将数据库升级合并为单次 schema 19 → 20、模型管理文档单次 schema 3 → 4；本地模型配置统一为初版 v1，删除开发期多版本兼容与重复用途字段。内置云端模型目录改用发布序号，运行库输入与分发投影各自从 v1 开始并严格区分用途。已发布数据升级路径保留，旧开发快照不自动降级或改写。

- macOS Option＋左右方向键保留文本按词编辑行为；修复 AI 字幕重绘收尾期间改变显示模式可能未立即生效的问题。

- 修复前台 NFO 导出被历史导航绕过、字幕检查吞掉原生控制及字幕命令失败终止播放的问题；字幕显示错误保留到显式重试。本机字幕缓存跨重连复用，模型用途按实际默认配置显示就绪状态，取消推理时回收未响应的子进程。

- 资料库连接的本机导入说明改为轻量提示条，描述中的“备份与恢复”可直接跳转。外部清单导入的目标选择改为搜索浮层与紧凑候选列表；影片演员、标签和演员别名统一复合输入样式，仅由外框显示聚焦提示，保留别名设为主名操作。

- 桌面清单页区分内置入口与用户清单，内置按“收藏、稍后观看、最近播放”排列；“我喜欢”更名为“收藏”并保留已有关联。分组搜索与自定义清单分页按内置身份处理，同名自建清单不受影响。

- 自定义清单移除封面数量角标；收藏和稍后观看不再支持从网页导入，导入目标仅包含自定义清单。稍后观看与最近播放移除资源筛选并清除旧链接筛选条件，播放后移除开关移至稍后观看详情顶部。

- 新增桌面本机“最近播放”清单，使用历史回转默认封面，按影片去重并按最近播放倒序；资料库之间隔离，支持单条移除和确认清空，不同步服务器、不影响续播记录或影片资料。

- 为桌面端“我喜欢”和“稍后观看”设计固定默认封面，统一用于清单列表、详情与选择器；保留自定义封面优先级，普通清单自动封面不变。

- 演员与刮削标签编辑改用可搜索的多值输入，支持标签移除、键盘操作、批量粘贴及重复项提示；未确认的输入随资料保存，已有名称及自定义标签保留。

- 修复连续调整自定义评分时使用过期影片版本导致冲突的问题；合并连续点击并串行保存，每次更新后读取最新版本，切换影片时隔离旧请求。

- 设置入口改名为“AI 服务”，文本翻译置于 AI 字幕上方；本地模型默认展示全部模型与精度，统一设置行对齐、图标间距与保存反馈，并修复系列卡片行间距和排序“更多”的尺寸与重复选项。

- 影片资料的外部评分改为紧凑表格，支持行内编辑来源、评分与评分人数，新增来源、默认来源选择及删除撤销；所有修改随资料保存生效，校验冲突时保留草稿并回滚整次保存。

- 设置表单统一为无外框的紧凑保存条：精简状态区、细分隔线与无框撤销按钮，固定状态区和按钮尺寸，支持撤销、保存中及失败重试；错误详情在所属卡片内展开，保留当前修改，并支持展开及复制技术信息。

- 重构本地模型存储：权重按系列、发布者、版本和精度组织并保留上游文件名；运行库按引擎版本与平台共享。Windows 使用 LocalAppData，推理缓存与任务文件独立；迁移携带续传文件，并提供过期临时文件及手动缓存清理。

- 精简 Qwen3 1.7B 的可选精度：保留 bartowski 的 Q4_K_M／Q5_K_M／Q6_K 和 Qwen 官方 Q8_0，默认仍推荐 Q4_K_M；下载、导入及用途配置使用相同目录。

- 将本地模型与 AI 字幕解耦：默认保存到独立 `local-ai` 目录，安装、运行依赖及文本推理由共用模型服务管理；字幕通过该能力生成字幕。

- 移除未发布的内置 Index-Translate 9B、本地模型目录与用途选项；本地翻译保留 Qwen3 和 HY-MT2 7B。
- 修复清单及分类列表滚动清空待提交搜索、详情返回后迟到滚动回调重新打开详情，以及导演／系列分页错误提示显示 undefined 的问题。
- 恢复演员冲突候选卡片样式，修复窄窗刮削字段操作被配置区遮挡及多媒体库时侧栏维护入口超出视口的问题。
- 将演员选择器验收更新为虚拟连续列表；纠正登录截图重置触控仿真造成的横屏字号误判，补充键盘、跨页、重试及会话隔离检查。
- 修复演员 → 影片 → 演员详情叠层丢失的问题，分别保留父层和末层演员身份，返回时保持父层状态。
- 隔离末层演员与父层关联影片的分页参数；程序性滚动恢复不再把页码误写到上一页，关闭末层保留父层位置。
- 修复清单影片移除按钮悬停后仍不可点击、分类主图保存失败的长错误内容被裁切的问题；保留草稿和失败重试。
- 收敛桌面与网页的功能样式归属，详情、原生播放器、剧照、演员卡片及共用文本也使用独立 CSS Module；删除网页剩余全局功能类，保留现有布局和操作行为。修正方向键导航对旧 skip 样式类的依赖；全局契约审计及最终视觉回检单独记录，不以类名清零宣称完整 GUI 验收。
- 统一编辑弹窗的提交锁、忙碌按钮与失败重试反馈；错误提示支持保留、查看详情和复制，图片部分导入失败后重试不重复导入已成功项目。
- 改善弹窗关闭后的键盘焦点恢复、翻译按钮点击区域和减少动态效果支持。
- 整理清单导入的身份判断与预览校验、影片详情操作流程及桌面／服务端共享查询入口，保留现有业务与事务规则。
- 校验远程影片来源和删除／移动预览及提交结果；保留旧移出结果的兼容 schema，不恢复已停用的手动移出操作。补充详情操作的重复提交、失败重试和切换影片时旧请求隔离测试。
- 修复同影片资源编辑的重复保存、关闭后延迟重开及旧请求关闭新编辑会话的问题；保存期间显示忙碌状态。

### 内置播放（未发布）

- 精简播放界面：底栏只保留倍速选择并新增 3×，音轨与字幕在设置面板切换；移除指定时间输入和当前资源进度清除入口，快捷键以键帽分行展示。收起后的标题显示番号与影片名，支持单行省略及跳转详情；无展示名的资源显示文件名。
- 修复字幕模型设置跳转定位和 Windows 播放画面的首次窗口聚焦点击；圆角浮层按实际轮廓遮挡原生画面。外部播放保存设置前须填写程序路径，续播开关仅用于内置播放。

- 本地 AI 运行库增加 macOS 13.3+ 与兼容 Linux 的 arm64／x64 适配，按系统、架构隔离工具并复用权重／模型配置。macOS 固定源码构建识别与音频 CLI，随应用分发，翻译运行库按需下载；Linux 使用固定 glibc 发布资产，需要 glibc 2.38+、GCC 14 C++ 运行库及 xz-utils。macOS arm64 和断网 Ubuntu 24.04 arm64 完成 Kotoba／Qwen 真实推理，Intel Mac 工具完成交叉编译；其他架构推理、完整播放器及安装包仍需验收。
- 修复 macOS 等价路径导致本地模型恢复默认保存位置后仍显示为自定义位置的问题；恢复按钮状态与持久化配置保持一致。
- 统一翻译、音频提取／识别和运行库解压进程的环境隔离；模型导出按真实路径检查，防止通过目录别名或符号链接写入模型保存目录。
- 本地模型商店新增腾讯官方 HY-MT2 7B 的 Q4_K_M／Q6_K／Q8_0，支持下载、精度与翻译模型显式切换、带版权声明导出及目录迁移；字幕和本地文本翻译共用所选模型。保留已有千问及在线默认设置，不自动回退；修正固定 GGUF 的结束 token 配置。HY 7B 的真实推理效果和性能尚待本机验收。
- 本地模型页新增模型商店：列出 Kotoba v2.0 GGML 与 Qwen3-1.7B 实际发布的精度，支持多精度共存、显式切换、单精度删除和带来源／许可导出；识别与翻译缓存跟随所选权重隔离。不支持推理的系统仍可管理可移植模型文件。
- 设置的“AI 模型”新增“本地模型”页，统一管理字幕使用的 Kotoba/Qwen3：分别下载、续传、校验修复、删除、导出及保存目录迁移；标题和简介等 AI 文本翻译也可选择本地 Qwen3，模型不可用时明确报错。模型使用中阻止删除与迁移。

- Windows x64 新增可选离线 AI 日中字幕：Kotoba 分段识别日语，Qwen3 本机翻译，按当前位置和跳转优先生成，支持音轨隔离缓存、中日双语/单语显示、字号调整及 SRT/ASS 导出。模型按需下载，不增加基础安装包体积；首次生成有等待，准确率和速度依音频与硬件而变。

- 默认使用内置播放器并开启本机续播，设置选项移除“验证中”。升级保留已明确保存的播放方式、续播选择与外部程序路径；缺少对应字段时使用默认值，失败不自动切换播放器。
- 接入应用内展开、实时小视频底栏与全屏的单会话播放器，本机和远程原文件均由客户端 libmpv 解码；补充轨道、字幕、定位、音量与默认关闭的可选续播，Web 和服务端转码范围不变。平台历史验证、运行库分发与发布边界分别记录，不将默认值调整当作版本已发布。
- 图片预览和播放共用临时返回历史，设置及插件草稿共用离开保护，避免各自写入 history trap。
- 新增 Linux X11／XWayland 原生嵌入代码与显式兼容显示启动选项，复用桌面的 libmpv 会话和端侧解码；原生 Wayland 后续补齐。
- 补齐 Linux 原生开发构建及 ELF 打包输入的架构、来源清单和运行库内依赖检查；开发 addon 不自动进入安装包，隔离编译/测试不代表播放运行库已经可分发。
