# 演员列表分页与虚拟化基准（#54）

## 测量口径

- 日期：2026-08-07
- 环境：Windows，本仓库 Electron/SQLite 运行时，10,000 位女性演员，无头像与影片关联。
- 数据就绪代理：预热后各执行 5 次，比较旧的全量 `listActresses` 与新的首屏
  `listActressPage({ limit: 240, offset: 0 })`；数值不包含 Electron 窗口启动时间。
- DOM 规模：按 1536 × 864 内容区、132 px 最小卡片和 12 px 间距计算，并由
  `actressGridLayout.test.ts` 固定布局边界。

## 结果

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 10,000 条数据就绪平均耗时 | 44.97 ms | 6.23 ms |
| 首次查询返回记录 | 10,000 | 240 |
| 演员卡片 DOM 上界（上述视口） | 10,000 | 约 80（可见行 + 缓冲行） |
| DOM 随总量增长 | 线性 | 与视口大小相关，基本恒定 |

首屏数据查询耗时降低约 86%，卡片 DOM 数量降低约 99.2%。滚动路径由浏览器维护全部
卡片改为 `react-window` 只更新可见及缓冲单元；分页哨兵接近底部时加载下一页，滚动条槽位
固定，因此追加页面不会触发整库卡片重排或横向跳动。下一页失败时既有页面仍留在查询缓存，
用户可从原 offset 重试。

## 回归检查

- `actressRepo.test.ts`：分页边界、总数和稳定排序。
- `actressQueryService.test.ts`：真实 SQLite 分页，以及头像筛选快照跨页复用与首屏刷新。
- `actressListBehavior.test.ts`：条件切换、失败重试 offset、跨页选择和详情返回滚动恢复。
- `actressGridLayout.test.ts`：响应式列数、状态行位置和虚拟网格结构边界。
