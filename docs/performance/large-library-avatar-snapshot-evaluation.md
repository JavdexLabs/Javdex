# 头像快照初始化与分页的取舍

保留BC/BD快照分页：它固定任务目标并显著缩小首个返回载荷，但没有降低同步初始化成本。不能把分页首读约0.05ms当作整个任务启动耗时。暂不根据本次数据改变SQLite临时存储或缓存默认参数。

本机独立合成库，各10,000/100,000演员、每项4KiB简介、全部具有头像路径，没有影片关系或真实头像文件。演员规模是敏感性实验，不是Issue100用户演员分布复现。运行时Electron43.4.1/Node24.18.1；实际版本见原始结果。ANALYZE及预热后每项20个热样本；中位数为第10/11项均值，p95为排序后第19项（nearest rank）。固定先完整清单、后快照；计时不含正确性断言、JSON序列化、临时表释放。夹具刚写入，不能称冷盘。未运行其他本任务基准、完整测试或构建造成重叠。

100,000演员时，初始化并取首页的中位数比完整清单略高（23.0567对21.4146ms），两者本轮p95接近；只有20个样本，不把小差异当作稳定退化比例。首页载荷从4,588,896B降为4,336B，后续每页仍约4–5KB。后续首末页均通过主键范围SEARCH访问，避免深OFFSET；完整遍历ID断言无重漏。返回量有界并不消除首次扫描、复制和计数。

临时pager记录：page_size4096，temp_store回读0，编译选项TEMP_STORE=1。10,000演员的活动快照占51个pager页（pager页合计208,896B），100,000演员占516页（2,113,536B）。DROP后对应freelist为50/515且TEMP表已不存在，page_count仍51/516。这里的页数不代表实际驻留内存、磁盘读写字节或泄漏；释放表后pager可保留可复用页。关闭合成连接并删除夹具后结束实验。

后续处置：

- 当前保留快照分页与固定目标集合，继续以真实目标数测启动阻塞；本轮不能替代Windows/HDD、并发写入、长名称偏斜或真实IPC/图像任务验收。
- 将“快照初始化移到worker”的评估保留在工作包10/00。若实施，由同一worker持有快照至结束，并先验证只读连接和TEMP写入权限、断连清理及失败重试；不能把当前TEMP表句柄直接交给其他连接。
- 不根据这次热测将temp_store设为MEMORY，不关闭耐久性设置，也不因首末页快而关闭主进程阻塞风险。
- 没有生产代码变更，因此本批不重复全量测试/构建；BD的2,284通过、1跳过及构建仍是最后生产验证。新增探针独立运行通过，原始样本、EQP和参数保存在[BE清单](large-library-results/implementation/batch-be-manifest.json)。完整15工作包/42风险保持进行中。
