# 演员作品分页后端评估（BH）

2026-09-11，工作区基线4c953a9。当前只增加后端及typed IPC/preload；实际详情页与编辑封面选择仍使用旧完整详情，尚未取得页面端收益。

查询默认60条、最多240条，严格校验安全整数参数。活动库中未隐藏membership采用EXISTS，跨库共享作品不重计；日期降序、添加时间降序后增加ID升序作为同值规则。事务内读取存在性、精确总数、MATERIALIZED ID页和共享窄VideoCard投影，缺失演员null与无作品空页区分。

合成库每部4KiB简介、全部作品关联同一演员、相同日期/添加时间、50%跨库重叠，无资源。ANALYZE后一次预热、每项3个热样本，median取中间样本，固定旧接口先测。耗时排除断言与序列化，旧详情及ID oracle驻留；没有p95、冷盘、Windows/HDD、真实IPC或峰值内存结论。页耗时包含count、排序及投影，不能解释为纯卡片读取时间。旧详情含演员元数据，新接口仅作品页；字节比较是两个真实返回对象，非完全相同接口合同。

捕获的页面EQP包含MATERIALIZE page、按idx_videos_release_date扫描videos、对video_actress主键及可见成员索引查找、日期后两项临时排序；分页之后才查pending/资源。因此不能声称SQL只扫描本演员关系或成本只随页大小增长。计数计划未单独捕获。本夹具所有影片均关联同一演员，不证明稀疏演员、大量无关作品时的计划稳定性。

29项定向包含262可见作品的全分页卡片等值、隐藏/归档/孤立与跨库重叠、不同add_time、null/空串日期、稳定ID同值、多资源与pending、缺失/空、非法边界、WAL外部隐藏后的快照一致性。探针首末页只核对ID与total；不把其解释为5万全DTO等值。

后续接入须同时拆分演员元数据和完整作品数组，调整作品总数展示及编辑封面按需读取；不能只给旧完整数组加前端分页。UI需要有界页窗口和旧请求隔离。Card字符串仍无硬字节上限，资源聚合可随单作品资源数增长；后续窄显示字段合同、查询隔离、稀疏/偏斜与深页成本仍须处理。此批不关闭PERF-05/06/10/12。
