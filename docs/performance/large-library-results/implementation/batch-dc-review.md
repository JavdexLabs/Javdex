# DC 独立静态复核与验收边界

复核范围：scanFileInventory.ts、scanner.ts、对应新增测试。复核者未编辑或运行测试；下述测试结果由主任务实际终端验证。

首次复核发现 P2：已有调用方事务中，flush 保存点成功后推进内存 ordinal，外层回滚会使数据库内容与内存状态脱节。修复后创建、append、seal、dispose 都在修改状态前拒绝调用方事务；事务回滚后的缓冲、sealed状态及ordinal可用性有回归覆盖。读取暂停期间仍可执行独立业务事务。最终复核确认该问题关闭，无新增本批阻断。

分页先取最多256行窄元数据，再确定最多1MiB路径范围后投影；无 SQLite 活跃iterator跨回调或await。发现ordinal保持重复路径和跨根顺序。symlink只捕获stat错误；默认summary实际使用TEMP，显式detailed保持内存oracle。seal后不逐页删除，避免STRM缓存修订反复变化。取消、fatal与双重清理故障保持原异常和已提交计数。

175联合测试通过；全量2758通过/1跳过/0失败(2759总计)，含类型、边界、lint和packaging检查。完整构建结果见单独日志。12个inventory单测、11个scanner集成测试为本批新增23项；红测日志保留接入前实际失败记录。

合成探针60万路径三遍读取通过数量及checksum检查，但TEMP更慢：约1.37–1.38秒，相比内存约0.22秒。路径缓冲和页受预算控制，不能外推到总体RSS、SQLite TEMP占用、主线程全部阶段、真实扫描吞吐或Windows/HDD表现。持续DROP失败可残留TEMP至连接关闭，异常原因不被清理错误覆盖。
