# Windows CPU 播放前后对照

2026-10-27，针对用户反馈的 CPU 兼容模式卡顿，在同一台 Windows x64 设备上对照旧 Canvas、接入 video 后的主进程像素中转，以及当前 video 私有像素通道。当前私有通道在这些样本中吞吐更高；三种路径均不能流畅处理所测 4K 全屏负载。结果不足以排除其他素材或机器上的回归。

## 测量方法

- 设备为 i5-12600K，10 核／16 线程；Electron 44.9.3。三组均使用同一 `playback.node`、libmpv 和本机默认画面缩放，软件解码；Chromium 界面保持硬件加速。
- 媒体为同一批合成 H.264 测试素材，扩展至 48 秒；每次预热约 3 秒后连续采样 16 秒。1080p60 使用展开窗口，原生输出 1962×1065；4K24 使用全屏，原生输出 3842×2162。
- 每个场景分别按“旧、新、新、旧”运行两次。每次使用独立资料库和可见窗口，验证播放时钟持续推进、视图与输出尺寸保持不变，退出均正常；采样结束后的窗口截图均有实际画面。
- “旧 video 中转”在本轮隔离的编译产物中恢复五处平台条件，重现此前 Windows CPU 像素经主进程中转的实现；其他 video 消费逻辑与当前构建一致。“旧 Canvas”从 `b463974a` 的 Git 源码归档单独构建，使用相同 Electron 和同一组原生二进制，因此同时包含此前 Canvas → video 变更前后的其他相关应用代码差异。
- 系统 CPU 占用约 39%–55%，测试间存在背景负载变化。夸克网盘任务在用户协助暂停后完成本表；暂停前的额外样本和期间被切为底栏的一个无效全屏样本不用于对比。

## 旧 video 中转与当前私有通道

帧率是 `requestVideoFrameCallback` 观察到的帧率；间隔为回调间隔的 95 百分位。每格为两次运行的均值。回调观测的是合成管线，不能证明显示器的物理扫描输出。

| 素材／原生输出 | 旧中转帧率 | 私有通道帧率 | 旧／新间隔 P95 | 旧／新应用工作集 |
| --- | ---: | ---: | ---: | ---: |
| 1080p60／1962×1065 | 21.6 fps | 28.7 fps | 62.6／52.0 ms | 1275／1269 MiB |
| 4K24／3842×2162 | 5.4 fps | 7.7 fps | 263.9／180.6 ms | 2118／2148 MiB |

当前两次测得的帧率分别为 27.4／30.0 和 7.8／7.7 fps；对应旧路径为 21.6／21.6 和 5.6／5.1 fps。样本内私有通道均更快，但运行时间短、背景负载不完全一致，不应把差值当作所有设备的固定提升。工作集为各进程工作集合计，共享页可能重复计算，不等于独占内存。

## 旧 Canvas 与当前私有通道

两种路径均统计主进程收到的 CPU 帧提交回执。Canvas 的回执表示绘制提交，**不等于实际屏幕呈现**；因此以下表不能直接解释为两种路径的物理显示帧率。新 video 路径另有回调观察，结果与其提交帧率接近。

| 素材／原生输出 | 旧 Canvas 提交 | 当前 video 提交 | 当前 video 回调 | 旧／新应用工作集 |
| --- | ---: | ---: | ---: | ---: |
| 1080p60／1962×1065 | 21.4 fps | 30.2 fps | 30.2 fps | 1167／1295 MiB |
| 4K24／3842×2162 | 4.7 fps | 7.8 fps | 7.8 fps | 2005／2136 MiB |

旧 Canvas 两次提交分别为 21.7／21.2 和 4.7／4.6 fps；当前 video 为 30.1／30.3 和 7.7／7.9 fps。新路径的工作集合计在这两项对照中高约 129／131 MiB，存在潜在内存压力；这些样本未证明工作集增加是卡顿原因。

## 结论与边界

本次未复现“私有通道比前一版 video 中转更卡”，也未发现当前路径比本机旧 Canvas 有更低的提交吞吐。用户感受到的卡顿仍有实测依据：本机在上述 4K 全屏条件下只能观察到约 8 fps，1080p60 窗口也未达到素材帧率。

尚未分段测出软件解码、libmpv 软件绘制、颜色处理、像素复制和 video 呈现各自的成本，不能把瓶颈归因到某一段；`mpv` 丢帧计数与展示回调计数的含义不同，也不能直接相减计算实际屏幕丢帧。没有修改生产代码、默认缩放或 CPU 回退，尚未用用户实际影片、低负载独占设备、其他 CPU／GPU 或长期播放复核。
