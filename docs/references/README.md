# 来源与兼容性依据

本目录保存固定上游来源、许可和格式核查，供修改对应实现时追溯；不是待执行方案，也不保证外部产品的后续版本保持相同行为。当前操作与支持范围以文档站和工程合同为准。

| 依据 | 用途 |
| --- | --- |
| [NFO 格式与消费端](nfo-format-sources.md) | 固定上游方言、字段和样例来源 |
| [NFO 图片](nfo-artwork-consumers.md) | poster、landscape、fanart 的消费端约定 |
| [NFO 演员头像](nfo-actor-artwork.md) | 本地头像命名、路径与尚未实机验证的兼容边界 |
| [NFO 样张](nfo-sample-artwork.md) | Javdex 样张备份与外部背景图语义的区分 |
| [本地模型资产](local-model-assets.md) | Kotoba、Qwen 固定发布者、revision 与资产身份来源 |
| [HY-MT2 模型与许可](hy-mt2-model-evidence.md) | 官方 Apache 许可、7B 模板及终止 token 依据 |

已落地的实现步骤和候选方案不在这里继续维护；历史原文可从 Git 查询。修改模型目录以代码中的固定资产为准，不能把上游全部精度调查当作应用提供的下载列表。
