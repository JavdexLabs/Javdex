## Standards

初审 4 项，均已修复：

1. **P1：NFO 前台导出保护被历史导航绕过。** `before-input-event` 必须尊重已有 veto；统一历史入口持有窗口级可导航判定，键盘、系统 app-command、swipe 和原生播放器返回均不能绕过前台阻塞。依据 UI_COMPONENT_CONTRACTS 的前台导出保护要求。回归覆盖被拦截事件和所有入口；任务结束后正常恢复导航。
2. **P2：字幕检查吞掉原生控制动作。** 轨道查询不得调用消费型 `state()`；macOS/Windows 复用已有 `inspect()`，Linux 增加只读 snapshot。生产 wrapper 回归在三个模拟适配入口覆盖字幕增删/重载、选择和音轨查询，验证动作留给会话恰好消费一次。依据单一动作消费者合同。
3. **P2：重连使相同影片的字幕缓存失效。** 缓存以已经包含目录/服务器/资源身份和内容修订的稳定 `resumeKey` 作为身份，不再带入连接 generation/writer epoch；资源替换、音轨和识别精度仍隔离。依据 AI_SUBTITLES_IMPLEMENTATION 的缓存复用要求。
4. **P2：继承应用默认模型时无条件标记文本翻译已就绪。** 就绪状态读取默认用途的实际 resolution，未配置、读取失败不报 ready；本地用途独立读取已安装/可运行状态。依据用途就绪区分合同。

## Spec

初审 4 项，其中“历史写入失败阻止稍后观看移除”经实际 IPC 接线复核撤回：`registerRecentPlaybackHandlers` 返回的回调已捕获历史保存失败，内置和外部调用均使用该回调，没有修改已经正确隔离的业务效果。有效发现 3 项：

1. **P2：可选字幕命令失败终止视频。** mpv 异步字幕回复使用独立标记和失败计数，不写解码器 fatal error；AI 控制器读取非消费型计数，只报告字幕显示失败并允许重试。C++ 回归同时验证普通命令错误仍是 fatal。追加复检发现推理发布会清除未恢复的显示错误，已将显示错误与推理错误分别持有，直到显式重试/新任务，避免无字幕命令恢复时隐藏重试入口。
2. **P2：字幕检查吞控制动作。** 与 Standards 的同一事实分别记录，修复与回归见上。
3. **P2：取消/关闭只发送 SIGTERM，可能残留本机推理进程或无限等待。** 统一拥有停止 Promise，正常终止后两秒升级 SIGKILL 并等待进程回收；取消、超时、输出超限、服务关闭及启动失败采用同一退出规则。真实隔离子进程忽略 SIGTERM 的回归保留实际子进程句柄，确认 SIGKILL 与 close 事件，而不是只确认函数返回或依据可能复用的全局 PID 清理进程。
