# Linux 播放集成本地审查（2026-10-22）

本记录对应 `fix/linux-wayland-black-frame-diagnostics` 分支、基于 `1561fc6` 的累计 Linux 改动；是本地代码审查与提交记录，不是发布或最终画面验收记录。

## 范围与修正

检查了 GPU 设备匹配、X11 ANGLE visual/modifier 协商、DMA-BUF/CPU 帧所有权、回退恢复、preload 时钟与目标时间调度、设置/IPC 合同、原生子窗口移除，以及私有运行库闭包、AppImage 运行时与构建配方。57 个 Electron 上游 ANGLE 补丁逐个核对固定 SHA256 和序列；自定义 visual 补丁检查设备/屏幕选择和无效 visual 处理。没有重新进行全部上游补丁的独立安全审计。

本轮修复：

- GPU 信息查询增加 5 秒期限，避免可选 GPU 初始化无限阻塞资料库主窗口；失败后仍可选择 CPU。
- 显式模式或第二次故障保留原始异常，避免统一错误掩盖原因。
- CPU 回退恢复期间的新跳转更新恢复位置，防止旧位置覆盖新意图或造成恢复等待超时。
- CMake 明确查找 Vulkan 头文件，开发容器补齐 GL/Vulkan 开发依赖声明；没有在宿主安装系统包。
- 旧于 2.2 的 libmpv 开发头文件不引用不存在的纳秒 API；发布候选运行库仍固定为 mpv 0.41。
- 真实 helper 时钟烟测的超时也覆盖 destroy 后无法退出的情况。
- 校正 Canvas 提交计数、X11 能力例外和旧第一阶段打包说明；固定摘要的上游补丁不做空白重写。
