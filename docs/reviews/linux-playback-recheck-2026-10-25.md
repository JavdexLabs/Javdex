## 复检结论与修复

### 软件启动窗口隐藏

旧程序在 Wayland 软件启动时完成页面加载和视频解码，但隐藏窗口可能不触发 `ready-to-show`。手动显示能看到画面，说明不能仅凭 API/帧数判断启动成功。现在仅软件启动增加 `did-finish-load` 显示入口；与 `ready-to-show` 共用一次性、销毁及启动取消检查。硬件启动仍等待首次绘制，保留 GPU 启动故障保护。

### X11 冷启动误选 CPU

固定 ANGLE Vulkan 路径在窗口加载后仍可能短暂返回 `gpu_compositing=disabled_software`，同步设备工厂将其视作永久失败。旧包 10 次冷开中 2 次因此误入 CPU，随后合成状态又变为 enabled。新逻辑在解析媒体授权前最多异步等待两秒，之后仍执行严格设备检查；取消/换片不创建旧会话，软件启动及手动 CPU 不等待。

新包 10 次冷开全部进入 GPU，其中一次观察到真实的短暂软件合成状态并正确等待恢复。长期不可用、等待超时及取消由针对性测试覆盖；本轮没有放宽设备匹配和安全导入条件。

### GPU 提前预算漏算上游工作

原预算只观察渲染回调到提交的处理成本，不能覆盖回调之前的解码/下载耗时。本机旧自适应逻辑 4K60/65 秒约丢 371–387 帧；私有固定 40ms 对照在两种窗口系统下各 60 秒均为零丢帧，支持预算不足的归因。

现在保留 20ms 初值、8–40ms 范围，并从可见且正常播放时的持续上游丢帧学习会话下限，累计两帧压力时提高 4ms，调整不快于每两秒一次，零星压力约十秒过期。暂停、跳转、缓存等待、EOF、隐藏及 CPU 不产生该反馈。同一 GPU helper 跳转保留下限，新 helper 重置；目标时间提交和引用释放/槽位复用条件不变。诊断统计修正了实际在途 DMA-BUF 字段，并增加预算和提交迟到数据；这些回执仍不是物理扫描输出。

### CPU 线程竞争与能力边界

远程提交的 BT.709 SDR RGB16 查表已替代每像素三维查表。本轮进一步把 lavfi 图线程限制到逻辑核一半、最多四个，避免与解码、缩放、Canvas 各自争用全机线程。使用 mpv 长度引号传递 `o=threads=...`，保留 RGB16 中间精度、输出尺寸、HDR 和字幕顺序。曾试验 RGB8 中间输出，最终没有采用。

CPU 高分辨率仍受本机性能约束；能显示正确画面不代表能保持源帧率，具体实测结果见下方。没有降低显示尺寸、禁用色彩转换或把 CPU 标为硬解来掩盖负载。

### ASAR 解包索引不一致

旧 afterPack 在 ASAR 索引建立后删除 SQLite 外平台二进制与开发材料，留下 40 个无实体的 unpacked 条目。现改为索引建立前通过平台文件过滤排除；afterPack 只核验 SQLite，打包/包内检查逐项拒绝缺失的 unpacked 文件。macOS 保留 universal 两个 Darwin slice；Windows/Linux 按目标架构过滤，路径检查兼容两种分隔符。

### 验收环境与脚本问题

- 通用媒体/字幕脚本允许 Linux，音频输出按 PulseAudio 检查，并能手动选择 CPU。
- PGS 定位允许亮边双侧缩放舍入；透明边、透明洞、积分覆盖及色差门槛未放宽。
- 8-bit 输出允许独立参考值相差不足一码的暗灰量化相同；仍检查顺序、可分辨灰阶和绝对误差。原 RGB16 fast path 也有该量化，不能归咎于 RGB8 实验。
- 5K 截图原先把约 59MB 原始位图传出主进程后再传回分析，单张旧截图即可耗尽 PGS 等待期限。统计改在捕获主进程执行，只返回摘要；保留 NativeImage 合成捕获、原像素门槛和暂停刷新等待。独立 XComposite 窗口缓冲中也确认 PGS 真实存在，没有添加播放器字幕绕过逻辑。
- 运行故障恢复后按合同保留 CPU，停止/重开不应错误要求恢复 GPU。定时播放改为绝对时钟采样，截图与像素读回移至计时之后。
- 无 GPU 设备隔离验收等待软件重启后的真实窗口，重新连接替代进程的 CDP，并采样替代主进程的子进程树。
- 完整测试暴露列表测试只排空微任务、不让 React Query 定时通知执行的偶发失败；测试等待器补充事件循环轮次，产品列表代码未改。

## 未覆盖范围

不把 Canvas 提交、窗口捕获或解码音频时钟称作物理呈现/听感验收。本轮全自动执行，没有人工听音、量化音画时差、物理 HDR/扫描输出、其他 Linux 电脑、原生 Xorg、AMD、Windows/macOS GUI 或数小时/数天播放结果。deb 没有安装；该 AppImage 是本地验收构建，正式发行仍需完整配方、源码材料和各平台门禁。
