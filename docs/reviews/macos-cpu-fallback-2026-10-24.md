# macOS CPU 显示和自动回退验证

2026-10-24，在 `ac072bf3` 基线上为 macOS 补齐独立 CPU 视频输出和可检测图形故障自动回退，默认仍使用 CGL／IOSurface GPU 路径。软件输出与 Windows 共用实现；Linux 的独立 helper 和模式选择不变。本轮使用 Apple M4、macOS 26.5 arm64、Electron 43.8.0 和本机 Homebrew libmpv，属于开发构建验证，不是公开安装包或其他设备的验收。

## 输出与恢复合同

`native/softwarePlayback.h` 由 Windows 入口和 macOS addon 共同编译，使用独立 mpv 实例、`hwdec=no` 和 SW Render API。输出为复制的 RGBA 内存帧，不创建播放端 CGL／WGL、D3D 或共享 GPU 纹理。帧按物理 viewport 渲染，行宽 64 字节对齐，alpha 固定不透明，padding 清零；保留单边 8192、单帧 256 MiB 的安全限制，不增加 1080p 上限。

`softwarePlayback.ts` 保留可信 main frame 绑定、时序校验、最多两帧在途和消费超时，preload 在新建的软件 Canvas 上使用 `putImageData`。CPU 显示指视频解码、渲染和内存帧提交，不表示系统桌面合成完全不用 GPU。

`graphicsPlaybackFallback.ts` 与 Windows 共用错误分类和一次恢复调度。默认创建 GPU；初始化失败、结构化图形错误或禁用硬件加速时创建独立 CPU 后端，复用已授权来源，恢复可定位资源的位置、暂停意图、音量、静音、倍速、音轨、外挂字幕和 AI 字幕时间轴。新来源、停止及后来的控制意图优先，CPU 故障不循环重试。图形故障后本次应用运行保持 CPU；`--javdex-cpu` 可强制选择，独立 `--` 后的参数不生效。

GPU 未确认的租约仍留在原有三槽隔离中，不能因 CPU 启动而强行释放。页面销毁、媒体／授权／音频错误不触发图形回退；驱动同步调用完全挂死不保证进程内恢复。旧 NSOpenGLView 后端保持移除。

组合回归另发现长会话边界：GPU 播放超过 30 秒后，CPU 首次状态暂报 `loadedFiles=0`，会误用原会话的打开超时。相同状态下 1 秒会话继续打开、31 秒会话报错，Mac 与 Windows 的真实调度组合均能复现。共享播放会话现仅在自动转入 CPU 时重新起算一次打开期限；重复观察不能延期，普通／强制 CPU 的原始期限不变，恢复调度自身的 15 秒上界保留。原失败、短时对照和修正后的定向记录均保留。

另一项组合回归覆盖应用在首次 load 前写入记忆音量的真实顺序：原恢复记录被 load 清空，CPU 接管后从 37 回到原生默认 50。恢复记录现只保留全局音量，旧影片的其它控制仍按来源重置。测试使用真实的原生默认音量，避免 UI 沿用缺失字段掩盖问题；实际窗口通过播放控件保存 37、正常退出并冷启动，等待 31 秒后触发 PGS 生产故障，CPU 原生状态与页面均恢复到 37，未在当前影片中重新调整音量。

## 真实窗口检查

所有宿主使用隔离资料目录和合成媒体，不访问用户影片，不修改系统显卡设置。报告及截图保存在 `out/playback-acceptance/mac-cpu-KCuPn9`，命令日志、失败记录、原始 addon 备份及源码摘要在 `/tmp/javdex-mac-cpu.KCuPn9`。

后续提交前检视以远程 `92a72c7e` 为整合基线，保留 Windows HDR 映射修复，解决更新日志与播放说明的两处冲突。规范检视未发现可操作问题；需求检视发现两项恢复缺口，均补充回归并修正。

Mac 的 CPU 画布现不依赖共享纹理接收器注册成功，仍要求主 frame 和有效绘制上下文；隔离 preload 回归覆盖这三项边界。AI 字幕恢复不再把后续刷新使用的 `select=false` 当作隐藏意图，也不在故障后查询已失效的 GPU bridge；同一时间轴保留选择意图，外挂字幕与手动轨道选择继续优先。真实 libmpv wrapper 组合覆盖首次选中后多次刷新、隐藏、外挂字幕及重新选中 AI 字幕，并分别检查 GPU 状态仍可查询和已经失效的情况。

## 复现与边界

从仓库根目录完成 `npm run playback:native:build` 和 `npm run desktop:build`。使用 `node scripts/software-playback-acceptance.mjs --mode=forced <合成媒体...>` 检查软件画面；模式还包括 `disabled`、`initialization`、`producer-fault` 和 `gpu-fault`。生产异常每次只传一个素材，`--playing-fault` 检查播放意图恢复，`--aged-session` 在暂停会话等待 31 秒后注入故障，`--saved-volume=37` 通过真实操作保存音量并冷启动，覆盖旧打开超时和启动设置边界；`node scripts/playback-close-acceptance.mjs --javdex-cpu` 检查正常关闭。

本机结果不扩展为 Intel Mac、Windows／Linux 设备、所有驱动故障、长播性能、HDR 直通、人工听感或签名安装包通过。未下载或验收公开软件产物；首次实现验证时尚未提交、推送或发布，后续提交前整合见上一节。临时资料和旧二进制保留以便追溯。
