# 三平台播放统一验证（2026-10-24）

按 [ADR-0033](../adr/0033-unify-desktop-playback-capabilities.md) 整合 Mac CPU 实现，保留 Canvas 及 CPU 回退。用户确认未发布设置无需迁移，默认字幕使用系统字体，不随包加入字体文件。

## 基线与范围

先保留本机方案提交 `45ab5a54`，合并 Mac CPU `e2fdd70a`、Intel Mac 修复 `337962af`，形成 `b8a2ae84`。验收期间再合并远程 `adebbb2f`，形成 `a1c9f92a`。本轮没有发布应用版本、替换公开资产或迁移资料库。

三平台共用自动／GPU／CPU 设置、恢复状态机、帧绑定／时钟／自检／预算、具名渲染配置及物理尺寸边界。Windows/macOS 的 libmpv 与图形驱动进入独立 utility process；Linux 保留隔离 helper。主进程资源模块只导入／释放系统资源，GPU 租约继续等待真实消费者释放。旧窗口句柄、原生工具栏／全屏／焦点和空遮挡协议已移除。

GPU 和 CPU 均输出 203nit、静态 BT.2390 的 BT.709／sRGB／full SDR，CPU 转换在字幕合成前完成。系统默认字体允许不同平台的字形及度量差异；片源 ASS 和内嵌字体遵循片源样式。

## 已完成验证

证据保存在忽略目录 `out/playback-unification-20261024/`，报告与截图不进入安装包。

- Node、桌面 Renderer 及浏览器类型检查通过；桌面／Web 构建通过。全量 ESLint 仅发现一处已移除原生 Escape 后遗留的测试变量，清理后该文件复查通过。
- 播放／设置／Renderer 定向测试：414 项，394 通过、0 失败、20 平台或环境跳过。独立 D3D11 待复制帧回归在修复前稳定失败，修复后真实 GPU 测试通过。
- 播放构建合同两组分别为 66 项（65 通过、1 跳过）和 28 项全部通过；素材／参考测试 9 项中 8 通过、1 跳过。网站检查 28 页、2,045 个本地引用通过。
- Windows 新隔离宿主的 GPU 与 CPU 各完成五组 SDR full／limited、HDR10、HLG 和无亮度元数据 PQ，覆盖播放、暂停、前后跳转、底栏、展开、全屏和恢复播放。每个捕获阶段均确认实际 GPU／CPU 模式；跨路径 RGB 最大差异 1.32 字节，门槛为 4。静态灰阶参考最大误差约 1.04 字节。
- Windows 宿主退出、播放中无响应的自动 CPU 恢复通过，保留位置／暂停意图、音量、静音、倍速及字幕。实际 Canvas 字幕、全屏、慢消费和停止重开检查通过，普通退出无需强杀。
- 含中文、单引号、方括号和逗号的临时目录中，CPU 五组色彩素材均正常生成 LUT 和生产画面。
- WSL Ubuntu26 的系统 libmpv 开发库编译全部 Linux 原生目标；核心、布局／租约／时序检查通过。Linux Node 进程合同 15 项全部通过；真实软件 helper 经 FD 传输五组色彩帧，生产及 ACK／退出通过。

暂停偶发黑屏的根因为 Windows CopyResource 尚在完成时，时间轴重置清除了该待发送帧的时间信息，导致错误超时与回退。待复制帧现在持有独立时间信息；原生回归强制在提交复制和收集帧之间重置时间轴，防止再次发生。

## 尚未覆盖

- Windows 结果来自本机 RTX 4080；不将历史 UHD 770／混合显卡实测算作本次新宿主的验证。
- WSL 没有执行真实 Linux 桌面 Canvas、X11／Wayland 或物理 GPU 测试。
- macOS 新的跨进程 IOSurface／Mach 传输需在 Mac 编译并执行预检，随后完成真实 CGL／Canvas、CPU 和包内验收。
- 不包含物理 HDR 输出、显示器校准、长时间功耗及额外显卡／驱动组合。
- 本机开发安装包使用已核验的源码构建 libmpv 与本轮新 addon，标明 local-development；正式发行仍须按新源码重建审核运行库、签名并交付对应源码材料。
