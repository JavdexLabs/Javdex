# 远程写入版本字段回检

范围：桌面 IPC、RemoteCatalogBackend 参数适配、服务端管理处理器中的版本必填检查。

- NFO 预览与开始导出：去除不适用于多影片计划的单条 C/V/R/G 必填约束；保留 writer 授权、维护计划摘要、有效期、重启失效、单次消费和执行时目录授权。协议清单同步更新。
- 影片、演员、清单：核对已有版本参数与兼容 IPC 的版本读取适配。
- 分类编辑：核对 expectedVersions 的 IPC 透传及服务端聚合校验。
- 媒体库配置、来源目录、扫描：核对 revision 转换与现有预览摘要流程。
- 文件改名、手工导入、待确认：核对预览返回版本和 Q 版本适配。
- 浏览器配对、偏好设置：未发现同类单条版本必填阻断。

上述范围未发现 NFO 两个操作之外的新同类阻断；这不代表所有远程功能均经过逐项 GUI 验收。

回归改进：真实服务端测试和双后端测试中的 NFO 请求改为与桌面相同的空 expectedVersions，避免测试自行补入占位版本而掩盖缺陷。

验证：服务端 runtime/C1–C7 共 35 项通过、4 项跳过；双后端 5 项通过、2 项跳过；桌面扫描、媒体库、分类、清单导入 IPC 共 38 项通过。服务端类型检查、构建及相关 ESLint 通过。

部署：重新构建并替换本地 javdex-local-test 容器，保留 javdex-local-test-data、javdex-local-test-config 和 D:\Downloads 到 /media 的挂载；首页和管理握手均可访问。未对用户资料执行测试导出或恢复。
