# 设置页异步布局稳定性回检

日期：2026-09-26。

范围：设置页入口、媒体库设置、`components/settings` 下的面板及设置子弹窗。未扩大修改全站无边框按钮。

## 修正

| 区域 | 处理 |
| --- | --- |
| 资料库连接、代理测试 | 同一反馈位置更新状态；连接重复测试保留结果区域，按钮状态不改变宽度 |
| 设置保存栏 | 保存失败、冲突、未保存和已保存复用一行；取消按钮隐藏时保留尺寸且不可聚焦；长错误不能撑宽布局 |
| 默认播放器、写入授权 | 忙碌、结果和错误复用说明行；授权按钮预留最长文案宽度 |
| MetaTube、AI 模型设置弹窗 | 测试说明和结果复用反馈行；测试、模型查询和保存按钮尺寸稳定 |
| 检查更新 | 状态复用单行；重复检查时保留已有更新内容；最终新结果允许正常改变内容 |
| 智能构图、扫描、未识别资源、组合插件 | 动态按钮按最长状态文案占位，停止和处理中不挤动相邻控件 |
| NFO 导出 | 预览与停止按钮稳定；错误进入紧凑反馈区，支持完整错误详情 |
| 备份恢复 | 创建与导入反馈复用说明行；记录内保存进度及错误替换元信息行，不另插反馈块 |

共享 `SettingsFeedback` 提供单行省略与可通过键盘打开的完整详情；`SettingsActionLabel` 使用不可见的最长文案确定宽度。占位限于单行与按钮，不增加整块空白。

## 保留的内容变化

首次加载完成、切换资料库模式、创建任务、生成预览或最终报告、增加或删除记录，以及用户主动展开详情，属于实际内容变化，不强行锁定整页高度。网页服务与设备配对现有反馈区保留。初始化错误及需要用户处理的持久配置警告继续展示，不隐藏业务状态。
