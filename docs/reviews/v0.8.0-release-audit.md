# 0.8.0 正式版发布复核

日期：2026-09-27。范围：Beta 3 至 `a5dd262` 的备份恢复、旧离线迁库移除与连接设置改动，以及本轮未提交测试清理；版本升级到 0.8.0 后按发布流程验证。

## Standards

检视发现两项备份历史反馈问题：折叠行隐藏“另存为”失败；合并错误文本把本机只读下载目录误指向资料库设备。已使用原状态栏显示短失败提示，完整原因仍在原详情中展开；目录提示按错误路径所在设备处理。没有新增平行详情入口或自动展开历史行。

## Spec

除上述失败不可见问题外，替换清单导入源码测试时遗漏了运行中禁止 Escape/背景点击关闭的覆盖。已通过真实组件事件验证保留弹窗且不隐式取消任务。备份回归同时覆盖直接拒绝和持久 `transferError` 两条错误入口。

两轴静态审查发现的上述问题均已处理。测试清理依据见 [测试检视记录](../TEST_AUDIT_2026-09-27.md)。

## 文档与版本

根、全部 workspace、内部依赖与锁文件统一为 0.8.0。更新 README、使用/开发指南、服务端部署/合同/状态、局域网说明、发布规范、更新日志与 Release 正文，部署示例固定版本 0.8.0。更新官网播放、存储及升级说明；修复当前文档失效链接，研究与旧验收记录保留日期边界。
