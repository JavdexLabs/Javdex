## CI 失败与定向修复

首次 run 的源码为 `f91d26500cf54ca96b3f5e9c1bb80648955e38c6`。Windows Electron 全量测试第一批为 2509 项：2484 通过、1 失败、24 跳过。唯一失败为 `playbackSource.test.ts` 中手动导入文件的物理身份断言：实现使用 `fs.realpathSync.native`，得到 `C:\Users\runneradmin\…`；测试使用 JS `fs.realpathSync`，保留了同一目录的 Windows 8.3 别名 `C:\Users\RUNNER~1\…`。解析和首次验证已成功，失败发生在两种路径文本的严格比较，不是播放授权或文件读取异常。后续打包、服务镜像和发布作业均被跳过。
