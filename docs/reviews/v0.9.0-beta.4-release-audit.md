## 门禁与验证边界

- 本轮执行版本／锁文件一致性、干净依赖安装、类型检查、文档测试与实际正式版清单构建、发布规划及更新回归；结果随后按真实输出补充。
- 完整 Release 输入固定为 `release_tag=v0.9.0-beta.4`、`prerelease=true`、`verify_only=false`。四个原生桌面 runner 通过固定源码播放库、包内加载／PCM EOF、六个最终安装包内容验证、macOS 签名与源码绑定，总源码汇总通过后才进入服务端发布。
- amd64／arm64 在 Linux Docker 中执行签名升级、迁移失败回滚、重启恢复、较新镜像业务自动升级及同／旧版保留。单容器脚本新增真实统一网关的一次配对、两台设备同地址业务／更新访问、单独撤销与其余设备仍有效，不能用宿主模拟替代。
- 核验 10 个自定义附件（六桌面、一总源码、两 `.javdex-update`、一 SHA256SUMS），九条唯一校验记录与完整下载字节；总源码四平台映射／恢复、新升级包官方 Ed25519 签名／内层完整闭包／版本／提交／架构／schema 21；确认双架构镜像、标签与程序提交一致。
- 不读取、输出或轮换签名私钥。官方公开公钥 SHA-256 预期为 `4afe77ca1f32135bcff8449631f38674bab697c86b1347dde9e777be8aa9f689`，核验时只读取公开公钥。
- 稳定 0.8.0、Beta.1–3 标签／资产／版本镜像不动。若 Beta.4 固定产物已公开而仍须改程序源码，先询问下一编号；不覆盖重发。
- 本机检查不等于四平台安装、人工 GUI／硬解／全部格式或双架构 Docker 验收。发布成功后再合入 main；保护分支走正常 PR，不绕过保护。随后核验 Pages 文档站及默认下载未切到 Beta。
