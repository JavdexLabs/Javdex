## 嵌套观看恢复复现与修复

真实历史模块重放三项失败：面板重建后失去下层播放条目，切换全屏会新增条目或覆盖图片层；已经确认收起后导航也无法消费原父层。修复前新增回归三项全红，直接顶层恢复的对照通过。

共享历史协调器保留已放弃的匿名位置，不保留旧回调；浏览器状态增加只含 `kind/token` 的父层位置，保留 Router 字段，非法或重复父链不用于恢复。初始快照可接管已记录且无人持有的同类父层，不能替换活跃回调或在挂载时导航。整页重载后已经消失的临时子层，在用户返回时与恢复的观看层一次消费，只处理同业务路由位置。资料、路径、授权与媒体身份不进入历史状态。

真实浏览器夹具使用实际 HashRouter、播放面板、图片预览和交互层，播放 RPC 为模拟。普通背景点击受到模态隔离，嵌套状态由明确标注的测试入口构造，不据此声明普通点击总能进入该组合。浏览器进一步复现了面板重建抢占已有图片的键盘和模态所有权；新增注册次序回归为红，修复使恢复分支置于已有层之下，普通播放更新不重排，新会话仍按显式操作处理。

浏览器已核对图片层在重建后保持活跃，返回先关闭活跃图片，再返回只发一次收起指令并保留详情；整页重载后图片不复活，一次返回直接收起且详情保留。初始快照 RPC 前收到存活会话的播放事件也可能重排旧层；两个新增重放为红后修复首事件接管，普通更新不改变次序。最终观看历史、交互层及真实面板组件回归 **73 项全部通过、0 跳过**，日志为本轮目录的 `viewing-regressions-final.log`。该证据不代替原生解码、Windows/Linux GUI、硬解、物理返回键或全部格式验收。
