## 本轮阻塞项修复

- 补齐 Linux llama CUDA／Vulkan 原包的 Javdex Runtime 下载 URL 与发行身份，保留原大小、摘要、缓存及有效安装；来源见[独立发行记录](runtime-linux-llama-migration-2026-10-24.md)。
- 浏览器回归原断言旧原生窗口隐藏／遮挡裁剪；改为当前 Canvas 可见性及实际控制行为，加入 Release 硬门禁。
- Mac hosted VM 缺少加速 CGL；只在明确允许且精确缺少像素格式时记录 GPU 覆盖缺口，CPU／传输检查不跳过，其他初始化失败仍拒绝发布。
- Ubuntu runner 的旧预装音频／字体依赖已不在当前 source index；先升级相应已安装依赖闭包，继续要求每个分发二进制匹配精确版本的源码。
- 总源码扫描误将 SDK 的条件 V8 头文件当作应用本地 include；限定应用头文件闭包范围，保留 SDK 身份与必要文件检查，真实四平台汇总通过。
- tar 异步硬链接夹具偶发 `write after end`；小夹具改用同步生成并确认实际 `File`／`Link` 条目，生产异步读取和拒绝链接语义不变；Windows 连续 20 次及 WSL 定向验证通过。
- 新版 `sudo-rs` 忽略 `-E`，导致网络命名空间子进程丢失宿主配置并递归运行测试。两次权限切换后显式传入所需配置；本机真实 sudo-rs 复现前后差异，AMD64 CI 的真实断网／重连通过。
- npm 为 workspace bin 设置可执行位；接续先核对全部源码字节，再恢复入口模式并要求完整 diff 为空。registry 摘要改从 buildx 清单读取，不依赖 Docker 本机 `RepoDigests` 表示。
- GitHub 对显式目标提交的工作流变化要求额外权限；创建匹配标签后，接续省略对既有标签无效的 `target_commitish`，不扩大令牌权限。[接口规则](https://docs.github.com/en/rest/releases/releases#create-a-release)。
