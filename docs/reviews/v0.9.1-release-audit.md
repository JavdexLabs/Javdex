# 0.9.1 正式发布审计

0.9.1 于北京时间 **2026-10-25 07:21:25**（UTC `2026-10-24T23:21:25Z`）正式公开。[Release](https://github.com/JavdexLabs/Javdex/releases/tag/v0.9.1) 为非 Draft、非 Prerelease，包含十个附件，且已成为 GitHub 最新正式版。实际资产身份、大小、摘要和作业状态见[元数据证据](v0.9.1-release-evidence.json)。

固定发行源码为 `7591e21e99d2416fefa01635ec5ba6fc3e1900bd`。[完整 Release CI](https://github.com/JavdexLabs/Javdex/actions/runs/40137112202) 由一次普通标签推送触发，attempt 1，未另行手动调度；11 个正常发布作业全部成功，未使用的服务端接续入口按条件跳过。标签剥离后的提交与 CI head SHA 一致；API 的 `target_commitish: main` 不作为源码身份。

镜像 `ghcr.io/javdexlabs/javdex-server:0.9.1` 的匿名 registry HEAD 摘要为 `sha256:8335f29571737a69d6517351feaad2ea50eaa2002ba27679f1f766e87de36a7f`，与本轮镜像合成日志一致。既有 0.9.0、Beta 和不可变 Javdex Runtime 未覆盖或重新发布。

## Standards

以远程正式 `v0.9.0` 的 `9d48f4fe80df614137a3b67480309aa17e3e6161` 为固定基线，检视至 `2285e89c559bf273f8c0f02124c0465c039b487f` 的 546 个变化文件及相关调用链，再单独复核本轮增量。规范轴发现并修复三项问题：

- 部署示例遗漏必填 `JAVDEX_PUBLIC_URL`，复制后不能启动；现与实际 HTTPS 地址和允许主机合同一致。
- NAS 身份变量误写为 `JAVDEX_BUSINESS_*`；现使用 `JAVDEX_SERVER_UID/GID/GROUPS`，说明默认 `1000/1000` 和空附加组不继承管理器组的行为。
- 安装指南仍要求 Linux X11 原生窗口、声称 macOS AI 工具随包携带；现说明三平台 Canvas、Wayland、CPU 兼容与按需下载。增量复核中的 Windows ZIP 名称也已改为实际 `Javdex-Setup-0.9.1-x64.zip`。

## Spec

需求轴发现并修复两项问题：

- POSIX CPU 运行库镜像迁移改变了旧缓存文件名，违反保留续传缓存的合同；现保留 Whisper／翻译运行库的旧路径，新 FFmpeg 与 Linux GPU 包的独立身份不变。四个 POSIX 目标、两类工具的完整缓存离线安装与 Range 续传共 16 个实际安装场景通过。
- 实验打包先运行集成 Linux 暂存，再写同名实验目录，导致重复暂存失败；现由明确的实验标记选择原有隔离流程，保留运行库和源码验证，SDK 版本从固定清单读取。未发布新的实验安装包。

规范轴三项、需求轴两项均已修复；各轴原最高级别分别为 P1 和 P2。增量复核问题也已关闭，无未解决审查项。

## 发布入口与依赖修复

正常发布在构建和上传前要求标签已存在并指向固定源码；上传不再发送多余的 `target_commitish`，避免已知的 workflow 编辑权限拒绝。缺失标签的回归先失败，修复后发布相关 26 项通过，实际正常发布成功。

Electron 更新为 [43.8.1 安全补丁](https://github.com/advisories/GHSA-jr5w-w6x2-84p9)，同步播放 SDK 与 ANGLE 清单。已核对该版本 DEPS 与原版本一致，57 份 ANGLE 补丁摘要一致，Node headers 仍为 24.22.0。另更新 Undici、重定向、URI、请求解析和 Vite 安全补丁。

干净安装曾复现 npm 10 重新采用上游 shrinkwrap，实际安装 Undici 8.9.0，却在产品锁文件中显示安全版本的问题。移除 Pi 的 `hasShrinkwrap` 标记后，重新 `npm ci` 实际安装 8.12.2／brace-expansion 5.0.12，审计为零漏洞；新增门禁检查实际安装，拒绝版本回退、缺文件和重新引入该标记。相关 npm 行为见[上游问题](https://github.com/npm/cli/issues/5141)。
