## 以 0.9.1 为基线的检视和修复

固定基线为正式 `v0.9.1` 的 `7591e21e99d2416fefa01635ec5ba6fc3e1900bd`。按规范与需求两轴检视至本轮候选的变更及相关播放调用链。规范轴没有确认的高优先级缺陷；需求轴发现新视频流首个 GPU 影片帧可能在显示端接入前被丢弃，使暂停或跳转后的画面停在旧帧。新增回归先复现失败，再让首个影片帧等待实际视频帧回调，并在既有 1.5 秒启动预算内重试；后续帧、GPU 租约和默认 GPU 路径不变。定向回归 78 项通过。

同步修正内置播放与开发文档中仍把当前视频合成路径称为 Canvas／WGL 的描述。首轮 PR 原生预检的 Ubuntu 依赖下载在极慢镜像下超时，另一个桌面作业因此被取消；日志未显示产品测试失败。后续仅为 CI 安装加 `--no-install-recommends` 并适当增加作业时限，没有降低测试门禁。最终 [Server Mode PR](https://github.com/JavdexLabs/Javdex/actions/runs/40533486535)、[三平台原生预检](https://github.com/JavdexLabs/Javdex/actions/runs/40533486454)和文档检查在最终源码提交上均成功。
