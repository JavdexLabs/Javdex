## 本机验证

- 锁定依赖干净安装及 Electron 原生模块重建完成。npm 仓库与 Node 头文件下载使用本次命令的镜像参数，依赖版本和完整性继续使用锁文件。
- 发布元数据、公开版本保护、接续和替换入口测试 58 项通过。`v0.9.2` 解析为正式版，四个原生打包目标均已启用。
- 字幕专项 18 项通过。桌面、Web、服务端构建及服务端依赖闭包检查通过。文档站离线构建核对 28 个页面、2,055 处本地引用。
- 全仓架构边界、TypeScript／CSS lint、类型检查、CSS 架构与控件检查通过。浏览器界面回归和 18 项文档站测试通过。打包、播放夹具、播放构建和备份烟测脚本共 234 项通过、8 项条件跳过。Windows 测试使用系统 tar，并在测试进程的搜索路径末尾加入已有的 OpenSSL。
- Electron 两批共 4,779 项，4,734 项通过、32 项条件跳过、12 项因 Windows 创建符号链接被拒绝而失败。另有一项本机 Windows 原生 CPU 播放测试在全量运行时超时，使用同一本地原生库单独复跑通过。完整测试在本机的原始退出码仍为非零，发布 CI 须重新执行。
- npm 审计接口连接失败。本机已通过锁文件与实际安装版本检查。

## 正式发布门禁

本轮记录的是待发布改动。正式发布须在已提交的同一源码上运行 [Release 工作流](../../.github/workflows/release.yml)，验证四目标原生打包、总播放源码包、双架构服务镜像、签名升级包和十个 Release 附件。历史 Beta CI、本机开发构建及模拟界面测试的结果只适用于各自验证范围。重启后的 Windows 首播、不同显卡硬解和长时间播放仍按实际设备验收记录判断。发布后再填写真实发布日期并核对下载入口。
