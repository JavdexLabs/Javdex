# 演员刮削状态交互决策

关联：[确定演员库状态徽标与筛选交互](https://github.com/JavdexLabs/Javdex/issues/11)

接受方案：头像角标 + 弹层筛选。

- `未刮削`、`刮削失败`显示在头像右下角，避开卡片左上角多选和右上角删除控件。
- `刮削成功`不显示卡片徽标，降低常态噪声。
- 刮削状态进入与媒体库一致的筛选弹层，支持全部、刮削成功、未刮削、刮削失败。
- 非“全部”状态写入 URL，并在工具栏下方显示可移除的已应用筛选标签。
- 维护提示的“查看未刮削”直接应用未刮削筛选；状态筛选继续与搜索、性别和排序组合。

本目录是一次性决策原型，不得直接合入生产分支。

运行：

```powershell
npx vite src/renderer/src/pages/actress-status-prototype --host 127.0.0.1 --port 4178
```

打开 `http://127.0.0.1:4178/?variant=C` 查看已接受方案。
