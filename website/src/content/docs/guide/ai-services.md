title: "AI 服务与网页采集"
description: "Javdex 0.9.0-beta.6 · AI 服务与网页采集"
---

先在“设置 → AI 服务 → 云端服务”配置连接和可用模型，再到“功能”页选择并保存应用默认模型或对应助手的模型。Agent 模型需支持工具调用，模型配置保存后只影响新任务。本机部署的 Ollama 等 API 服务也在云端服务页配置；应用直接下载和管理的语音识别与翻译模型位于“本地模型”页，用于字幕和文本翻译，不会自动成为 Agent 模型。

添加自定义连接时填写名称、服务地址和密钥，通过名称区分不同连接；需要时可在“高级连接选项”中调整协议。

云端服务支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 和 Google Gemini 原生协议。Responses 用于提供 `/responses` 的服务；现有 OpenAI 连接升级后保留原协议，可在高级连接选项中显式切换。Google Gemini 预设使用原生接口，地址默认为 `https://generativelanguage.googleapis.com/v1beta`；若使用 Google 的 OpenAI 兼容入口，请另建 Chat Completions 连接并填写 `https://generativelanguage.googleapis.com/v1beta/openai`。填写基础地址，不要附加具体请求路径。

新建 MiniMax 连接默认使用官方推荐的 Anthropic Messages，基础地址为 `https://api.minimax.cn/anthropic`。已有 MiniMax 连接保留原协议、地址和用途绑定；需要切换时，在高级连接选项中同时修改协议和基础地址，再测试模型。继续使用 Chat Completions 时，官方基础地址为 `https://api.minimax.cn/v1`。

阿里云百炼预设使用北京地域的 OpenAI 兼容地址 `https://dashscope.aliyuncs.com/compatible-mode/v1`；其他地域需填写对应地域的地址和密钥，模型及工具调用能力以服务商在该地域提供的功能为准。Gemini 与百炼可查询远程模型，也可手动添加账户可用的模型 ID。升级补齐新预设，保留已有连接地址、协议、密钥、模型和用途选择。四种协议的模型查询、生成测试、在线文本翻译及 Agent 请求均使用设置中的 AI 服务代理。

提供商详情的“模型管理”在同一弹窗内切换“已添加／远程查询／手动添加”。远程查询可按名称或 ID 搜索，并筛选待添加或已添加模型；查询只读取列表，需要逐项添加。手动添加填写服务商的完整模型 ID，显示名称可选，同一连接不能重复添加相同 ID；添加失败保留输入，添加模型不会改变用途绑定。连接有未保存更改时，先保存再查询、添加或测试。展开已添加模型可测试生成响应，并在该条目内查看原始响应或错误详情；查询成功不表示模型测试通过。每个模型的“能力与上限”展示自动识别值、手动覆盖及依据，可重置为自动值。

内置模型目录更新时，已退出新目录的内置模型，未被用途引用则自动删除；仍被默认模型或某个用途引用时，转为“手动添加”，保留原模型 ID、显示名称、能力覆盖及用途绑定。仍在新目录中的内置模型和用户手动添加的模型保留，已有连接与密钥也保留。新预设只补入同一连接中尚不存在的模型 ID；相同 ID 保留你的记录。未被用途引用的手动模型可以删除，删除后重启不会重新补回。新增预设不会自动替换默认模型；如旧模型已停用，需在“功能”页显式换用其他模型。新 OpenAI 预设使用 Responses 接口，现有模型继续使用原协议。预设不是账户访问授权，实际可用性需通过远程查询和模型测试确认。

插件开发可独立选模型；影片/演员采集、清单导入与媒体库整理共用整理用途的模型。思考强度及输出、超时等限制仍可调整；缓存与上下文压缩自动管理。已有任务继续使用启动时保存的设置。

应用重启后可恢复有效的 Agent 会话检查点。如果检查点损坏或不兼容，会提示新建任务，不再尝试从历史重建对话。已有资料、草稿、操作记录和插件工作区保留；插件工作区可由你明确清除。

1. 在影片或演员详情中选择“Agent 刮削”。
2. 粘贴对应详情页地址，开始采集。
3. 如任务要求登录或处理验证，按界面提示操作后继续。
4. 查看采集草稿、图片与身份提示，勾选需要的字段和应用方式。
5. 预览后应用；也可稍后处理或丢弃草稿。

AI 采集会访问指定网页，并向配置的模型服务发送任务所需内容。可用性取决于网页、网络和模型能力；模型服务的账户、额度与费用由你配置的服务决定。

远程模式下，模型、浏览器和草稿仍只在此电脑运行。点击预览时服务器根据当前资料库核对影响；点击应用时才上传结构化候选和已勾选的图片。若服务端资料在两步之间变化，界面会要求重新检查预览，不会按旧预览覆盖。
