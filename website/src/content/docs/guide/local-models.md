本地模型为字幕和文本翻译共用；“设置 → AI 服务 → 本地模型”管理文件与运行状态，“功能”页设置各用途。模型页分为“语音模型”和“文本模型”，各自显示“运行环境”。每个模型系列可展开精度表，当前选用的系列默认展开；模型文件、用途、配置验证和任务状态属于具体精度与发布者。可以筛选“当前选用”或“已下载”，行内“更多”提供文件操作、依赖及准备清单和完整验证详情。

千问（Qwen3）与 HY-MT2 用于文本翻译，Kotoba Whisper 用于语音识别。下载模型文件和选择功能用途是两个独立步骤。

| 模型系列 | 用途与可选精度 |
|---|---|
| Kotoba Whisper v2.0 GGML | 日语语音识别；Q5_0（推荐）、F16 |
| Qwen3 1.7B GGUF | 字幕或文本翻译；bartowski Q4_K_M（推荐）、Q5_K_M、Q6_K，Qwen 官方 Q8_0 |
| HY-MT2 7B GGUF | 字幕或文本翻译；腾讯官方 Q4_K_M（推荐）、Q6_K、Q8_0，约 4.62／6.16／7.98 GB |

## 下载、导入与修复

在“存储与维护”卡片直接选择“下载来源”：默认 Hugging Face 官方源，也可使用 HF-Mirror 第三方镜像，选择后立即保存，用于后续下载与修复。切换不改变已安装文件、固定版本与 SHA-256 校验；GitHub 运行依赖仍从原地址下载。下载等文件操作期间不能切换来源，镜像不可用时可取消下载、切回官方源重试。

每个精度的操作列提供下载图标与“更多操作”图标，不重复显示文件大小。首次下载或导入前需要安装所属模块的基础运行环境；未安装时会提示，可明确选择只安装基础环境。安装完成后再次选择下载或导入，只处理该精度的模型文件，不安装 CPU 或 GPU 组件；GPU 加速支持始终可选。已下载精度的下载图标禁用，可从“更多操作”检查详情或“校验与修复”模型文件。

文件操作分别显示校验、网络下载与安装阶段；文件大小始终显示完整大小，安装状态单独更新。可取消并续传，期间仍可浏览其他系列。折叠系列或筛选隐藏下载行后，仍可从页面底部取消下载。精度行的“更多”菜单还提供：

- “精度与验证详情”：查看该精度的完整设备名、检查时间、回退原因与来源；关闭后返回原行菜单按钮。
- “复制下载地址”：跟随当前下载来源，可交给浏览器或下载工具。
- “导入模型文件”：先检查所属语音或文本模块的基础运行环境，通过后选择与该精度、发布者匹配的 GGUF／BIN 文件，核对大小和 SHA-256 后复制，保留原文件。只安装基础环境即可导入，GPU 加速支持可选；导入不自动安装运行组件。
- “导出模型文件”：在所选目录创建按模型、精度和发布者命名的子目录，包含模型文件、来源与许可，不包含运行依赖和缓存。HY-MT2 7B 附 Apache-2.0 许可和腾讯版权声明；导出字幕仍在播放器中操作。
- “删除此精度”：仅删除该精度文件，保留其他精度、共享运行依赖、缓存和影片资料；已选用的精度确认后也可删除，用途选择保留并立即显示模型缺失，重新安装后恢复；运行中的精度不能覆盖导入或删除。未完成或损坏的精度文件同样可以删除。

模型来源固定到具体仓库版本，下载、导入、修复和导出均校验文件。下载、导入或浏览精度不会改变功能选择；“已下载”也不等于运行依赖已就绪。

## 分别设置字幕与文本翻译

“功能 → AI 字幕”分别保存语音识别与字幕翻译选择；“功能 → 文本翻译”单独设置标题、简介等翻译的模型来源、精度与发布者。每组保存后用于新任务，“前往下载”与“返回用途配置”之间保留未保存选择。

全新安装的文本翻译默认“使用本地模型”，选择 HY-MT2 7B Q4_K_M（tencent）；AI 字幕默认使用 Kotoba Whisper Q5_0（kotoba-tech）识别、HY-MT2 7B Q4_K_M（tencent）翻译。0.8.0 已有模型配置的用户继续继承应用默认模型，已有本地用途设置也保持原选择；首次选择会保存，重启不会改变。模型仍需按需下载，缺少文件时显示未就绪。

文本翻译可“继承应用默认模型”，通过已配置的 API 服务执行；也可“使用本地模型”，选择 Qwen3 或 HY-MT2 7B。本地来源无需配置在线提供商，所选文件未安装或不可用时会报错，不自动切换到其他模型或在线服务。修改文本翻译不会改变字幕翻译、应用默认或 Agent 用途。

使用时打开“编辑影片资料”，在标题或简介旁点击“AI 译中”。译文填入当前编辑草稿，核对后点击“保存”才写入资料库；取消编辑则不应用。演员、分类和清单简介中带“AI 译中”的字段使用同一文本翻译设置。

本地模型商店是 0.9.0 新增功能，配置从格式 1 开始；不承诺读取未发布开发快照中的中间格式。已有云端连接和 Agent 模型配置按独立升级流程保留，不会被本地模型选择替换。

## 计算设备与显卡加速

“本地模型 → 计算设备”默认“自动选择”，也可选择“仅 CPU”或指定检测到的独显。选择后立即保存并自动验证当前选用模型，对新任务生效；运行中的任务结束后才能更改。

Windows x64 的 NVIDIA 显卡优先使用 CUDA，其他通过驱动和引擎检测的独显使用 Vulkan。语音、文本模块的“运行环境”分为“基础运行环境（必需）”和“GPU 加速支持（可选）”两行，分别显示安装状态、文件大小与操作。首次可“安装运行环境”，部分安装或中断后可“继续安装”，安装完成后可“检查与修复”；“安装 GPU 加速支持”会一起安装缺少的基础组件。点击各环境行左侧的箭头展开对应组件，核对版本、来源、安装状态与文件大小；只展示当前准备计划所需组件，不显示无关后端。基础组件和 GPU 组件分别列在所属环境内。

先安装基础运行环境，再下载模型。基础环境只安装 CPU 引擎与必需工具，不下载 GPU 组件，也不改变已选运行方式和用途。仅安装基础环境即可下载模型并使用 CPU；GPU 支持可稍后单独安装。环境安装不下载模型文件，模型下载与修复也不自动安装环境。环境安装完成后会自动验证已有的当前选用精度；GPU 是否可用仍以精度验证结果为准。环境安装期间可在原位置暂停安装。安装状态只表示文件是否齐全；切换到“仅 CPU”后，已安装 GPU 支持仍显示“已安装”，同时提示暂不使用。

基础运行环境与 GPU 加速支持均提供整组删除按钮，展开清单只用于查看，不支持逐个组件删除。删除基础环境前，必须先删除对应类型下的所有模型文件，包括所有精度及未完成的下载；语音环境只检查语音模型，文本环境检查 Qwen3、HY-MT2 等文本模型，两类互不阻挡；删除 GPU 支持无需删除模型，基础环境可用时自动使用 CPU。删除受阻时会列出具体模型、精度和文件状态，可“查看相关文件”自动展开并定位，同时解除不匹配的筛选。模型精度和环境删除均只确认一次。确认后会一并删除该组已安装文件和续传数据，并立即重新检查依赖、清除旧验证结果。已安装但当前未启用的其他 GPU 后端仍可展开查看和随组删除；内置组件只移除模型存储中的安装副本。任务运行期间禁止删除运行环境。

Vulkan 设备探测需要检测组件，尚未准备时会提示“GPU 检测尚未完成”，可安装 GPU 加速支持后继续检测，不将其当作机器没有独显。仅准备语音 Vulkan 时，清单会明确列出文本引擎检测组件。模型权重由 CPU/GPU 共用。CUDA 需要匹配的 NVIDIA 驱动；Vulkan 需要驱动提供相应支持，普通用户无需安装编译器或开发 SDK。macOS 自动模式沿用 Metal，Linux 暂保留已有 CPU 路径。

精度表显示“模型文件”“用途绑定”和“配置验证”，不再单列“当前任务”或重复显示“已选用”标签。使用中的精度旁显示“CPU 使用中”或“GPU 使用中”；设备尚未报告时先显示“使用中”，结束后自动隐藏。删除、导入覆盖、修复及目录迁移等使用限制保留。“已下载”只表示权重存在，环境中的“组件已安装”也不代表该精度已经通过 GPU 验证。配置修改后立即检查依赖、清除旧验证结果，再显示等待或正在验证；缺少组件时直接指出需要补齐的内容。依赖完整的当前选用精度会自动短推理，显示“GPU 已验证”或“CPU 已验证”，无需先启动字幕或翻译，也可点击“重新检测并验证”。检查只使用内置测试内容，不读取影片或麦克风；正式任务优先，检查会在空闲后继续。

没有可用独显、所选设备消失、加速运行库不完整或 GPU 初始化／显存分配失败时，自动使用独立的 CPU 运行库，保留同一模型与精度。自动模式下未安装可选 GPU 支持时，CPU 验证通过显示“CPU 已验证”和“CPU 就绪 · GPU 可选”；指定显卡或已安装加速但未通过时，显示“CPU 可用 · 显卡未启用”和具体原因。没有独显或主动选择 CPU 时，CPU 验证通过也属于正常状态。验证结果反映检查时的环境，实际任务仍可能因显存占用变化而回退；精度旁的使用中标签按实际任务报告更新，具体设备和回退原因可在精度详情查看。GPU 任务失败时最多重试一次 CPU，不重新生成已完成的字幕区间。取消任务、模型损坏或用途配置错误仍直接报错，不会改用其他模型或在线服务。

加速设置保存后，本地配置升级为格式 2；既有格式 1 默认使用自动模式，读取和普通重启不会自动改写配置。

下载中断后可用“未完成下载”筛选找到精度，并从下载图标继续下载；系列标题显示未完成数量。失败原因就近显示，提供针对原精度或环境的重试和完整错误详情。精度菜单可“前往用途配置”，只负责导航，不会更改用途；从功能页进入时，返回原来的文本翻译或 AI 字幕分区并保留草稿。窄窗口固定精度与操作列，中间列可横向滚动。

## 保存位置与清理

“存储与维护”卡片显示“保存位置”，路径旁可“打开保存目录”“更改并迁移”，“更多操作”中可“恢复默认位置”。文件表格按实际文件统计模型、运行环境、未完成下载、安装暂存与推理缓存占用及文件数，包含说明和校验文件；语音检测文件计入运行环境。标题旁显示合计占用，可“刷新统计”更新任务产生的缓存。标准 Windows 安装默认在 `%LOCALAPPDATA%\Javdex\local-ai`，其他系统在应用用户数据目录的 `local-ai`；自定义配置目录使用该配置目录下的位置。

模型按“系列／发布者／固定版本／精度”组织并保留上游文件名，运行依赖按“引擎／版本／平台与架构”共享保存，不按功能重复下载。更改位置会先复制并校验模型、共享运行依赖和未完成下载，成功后切换位置并清理旧副本。缓存独立保存，不随模型迁移；共享运行依赖修复和目录迁移需等待相关任务结束。

在“未完成下载”和“推理缓存”行点击“清理”，保留已安装模型、运行依赖和影片资料；没有文件时禁用，运行任务期间不可清理。清理后立即刷新文件清单、续传状态和删除条件。未完成下载保留七天供续传，安装暂存保留一天，过期文件自动清理。推理缓存清理会删除可复用字幕和工作文件，再次使用需重新生成。

## 运行环境

本地推理支持 Windows x64、macOS 13.3+（Apple Silicon／Intel），以及满足运行依赖要求的 Linux arm64／x64。Linux 需要 glibc 2.38+、GCC 14 的 C++ 运行库与 xz-utils，例如已更新的 Ubuntu 24.04；Debian 12、Ubuntu 22.04 和 musl 系统不在当前推理支持范围内。macOS 安装包提供识别与音频工具，无需另装编译器。

支持的平台会补齐匹配系统、架构的运行依赖；不同平台工具分开保存。其他平台仍可管理、下载和导出权重，但不能启动本地推理。请检查共用环境、精度验证结果及可用内存，模型文件大小不是内存需求；不会因某模型无法运行而自动改用在线服务。


## 播放时快速开启 AI 字幕

展开或全屏播放时，底栏倍速左侧的「AI 字幕」开关可直接启停日中字幕。模型未配置或文件尚未就绪时，点击会显示引导，开关保持关闭；选择「前往配置」会收起播放器并进入字幕模型用途设置。配置和下载完成后，返回播放器手动开启即可。

准备字幕期间也可关闭开关，停止后恢复此前字幕。生成进度、显示语言、字号及重试入口仍在「播放设置 → 字幕」中。
