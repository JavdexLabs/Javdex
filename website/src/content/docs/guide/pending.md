title: "待确认与媒体库维护"
description: "Javdex 0.9.0-beta.6 · 待确认与媒体库维护"
---

“待确认”集中展示扫描资源归属、资源身份、影片刮削候选与演员名称冲突。根据分类核对文件名、NFO 番号、图片和候选资料，再作出选择；丢弃待办前注意确认弹窗中的影响说明。

不同维护操作的结果不同：

| 操作 | 影响 |
|---|---|
| 从清单移除影片 | 取消清单引用，不删除影片文件 |
| 自动清理空归属 | 多库影片在某个库的资源记录归零后自动移出该库；此规则保留最后一个归属；清单引用和置顶会阻止清理，影片资料、评分和图片保留 |
| 归档媒体库 | 暂停扫描并从侧栏隐藏，保留资料与来源；可在“设置 → 媒体库”选择归档库恢复 |
| 永久删除媒体库 | 删除该库成员、资源记录和扫描等数据，保留本地文件与全局影片资料 |
| 永久删除影片 | 删除全局影片资料、各库成员与资源记录，并删除关联的本地视频和 STRM 源文件 |

不再提供手动“移出媒体库”操作。原“清理无资源成员”开关保留：开启后，安全扫描也可清理影片的最后一个无资源归属；清单引用和置顶仍阻止清理，不删除全局影片。资源删除、跨库移动、目录迁移和备份恢复在操作完成后检查空归属；扫描只在完整扫描且所有目录在线的安全清理阶段检查。NAS 断线、目录无权限或扫描失败不会仅凭文件不可访问移除归属。

执行前以操作弹窗的影响预览为准。只想暂时隐藏整库时，可以归档；不要用永久删除影片代替隐藏。
