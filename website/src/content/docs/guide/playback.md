## 选择默认播放方式

默认使用基于 **libmpv 原生渲染**的内置播放器，本机文件与服务端原文件共用同一播放引擎。远程模式从服务器读取原文件，仍在此电脑解码，无需先配置外部播放器。直链、STRM 中的网络目标、网页、Magnet 和 ED2K 等链接继续外部打开，不属于内置文件播放。

在“设置 → 存储与导出 → 资料库连接 → 播放器”选择“默认播放方式”，点击卡片右上角保存，从下一次播放生效。新安装及未记录播放方式的旧设置都默认内置播放；明确选择过的外部播放、程序路径与续播选项会保留。仅填写外部程序路径不会自动切换默认方式。

启动初始化时，外部程序路径为空会尝试读取系统默认视频播放器，成功后自动保存路径；检测失败或系统暂不支持时才留空，不影响启动。已有程序路径会保留，补全路径不会切换默认播放方式。

选择外部播放器时须有程序绝对路径，也可通过“选择程序”或 Windows 的“使用系统默认”填入；路径为空时无法保存。Windows 按 MP4、MKV、AVI 顺序检测可直接调用的默认程序；在设置页点击按钮只填入草稿，需保存后再试播，不会修改系统默认应用。检测不到时手动选择程序；系统文件关联不保证网络播放兼容，服务端文件需要支持网络播放的外部程序。文件资源菜单可单次选择“内置播放”或“外部播放”，不改默认设置。内置运行库不可用时会提示错误，不自动换播放器；播放中出错可重试同一资源、显式外部打开或关闭。

Linux 内置播放支持 X11／XWayland。需完整退出后使用 `--javdex-x11`（或 `--ozone-platform=x11`）启动，并提供 X11/XWayland 显示；这是启动参数，不是设置页开关。原生 Wayland 暂不支持。使用完整安装包中的匹配播放运行库；不要混用其他架构的运行文件。可播放的格式、硬件解码和音频输出取决于运行库、文件及设备，不能据此推断网页端也支持相同格式。

## 展开、全屏与底部迷你播放器

在影片详情点击“播放”打开主资源，也可在文件资源菜单中指定。展开播放器占满应用窗口并隐藏左侧导航；点击“收起到底栏”后，可边播放边浏览资料库。底栏有正在播放的实时小视频，并非封面缩略图；点击小视频或“恢复展开”返回大画面。底栏只占主内容区，不覆盖左侧导航；番号与标题可点击进入影片详情，播放继续。停止后释放底部空间。

播放区域支持空格播放／暂停、←/→ 定位 5 秒、Shift+←/→ 定位 30 秒、M 静音、F 全屏与 Esc 返回。Windows 窗口未聚焦时，单击展开或全屏的视频画面只恢复焦点；已聚焦时单击播放／暂停。在 macOS 全屏中可用 Tab/Shift+Tab 遍历控制，Space/Return 激活按钮，滑杆方向键调整自身。播放结束可选择“从头重播”。隐藏或最小化主窗口会暂停内置播放，不能把系统托盘当作视频后台播放入口。

系统后退、鼠标返回键、Alt+Left 和 macOS 的 ⌘[ 等同于“收起到底栏”：一次收起展开或全屏播放器，并关闭播放设置，保留当前播放、进度和业务页面；底栏状态下再次后退才执行页面导航。Esc 保持逐层关闭：先关闭播放设置，再退出全屏，最后收起播放器。设置草稿和插件未安装更改在真正离开页面时仍按界面提示确认。

## 播放设置与字幕

“播放设置”在底部工具栏右侧、全屏按钮左边，打开后有“播放／字幕／信息”页签。底栏模式需先恢复展开。

| 页签 | 可操作内容 |
|---|---|
| 播放 | 选择当前媒体库内同一影片的文件来源、外部打开、切换音轨、倍速和章节 |
| 字幕 | 选择字幕轨道、加载本机 SRT/ASS、调整纯文本字号与字幕延迟、使用 AI 日中字幕 |
| 信息 | 查看本机／远程来源、视频编码与分辨率、实际硬件解码、音频及快捷键 |

切换来源会重新打开所选文件，不修改主资源，也不会自动换源；外部打开成功后停止当前内置会话，失败则保留。轨道名称显示可用的语言、编码及音轨声道提示，声道标记不代表设备实际输出。ASS 自带样式和图像字幕不提供字号覆盖；字幕延迟可按 0.5 秒提前、延后或重置。倍速支持 0.5×、0.75×、1×、1.25×、1.5×、2× 和 3×，工具栏也有快捷菜单。

Windows 非全屏使用固定双层工具栏；全屏控制覆盖在视频上，进入顶部区域显示标题栏、进入底部区域显示控制栏。画面中央移动不会唤出控制栏，暂停时也相同；打开播放设置、拖动滑杆、键盘聚焦控件或打开菜单时保持相关操作区域显示。

## 本机续播进度

“保存续播进度”默认开启，仅在此电脑记录内置播放进度；已有有效位置时，先暂停等待选择“继续”或“从头播放”。在播放器设置卡片右上角保存更改；开启后从下一次播放生效，关闭后立即停止当前记录，但保留旧进度。需要删除旧进度时，另行点击“清除全部本机续播进度”并确认。

外部播放器自行管理续播，此模式下开关不可操作，切回内置会保留原选项。续播进度不写入服务端、不跨设备同步、不纳入资料库备份；收起与恢复当前会话不属于持久续播。进度与音量偏好分开，关闭续播仍记住音量；清空“最近播放”不会清除续播进度。
