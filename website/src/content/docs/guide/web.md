title: "局域网浏览与播放"
description: "Javdex 0.9.0-beta.7 · 局域网浏览与播放"
---

1. 在桌面端打开“设置 → 网络 → 网页服务”，设置访问账号、独立密码与端口，开启服务并保存。设置概览的状态卡片也可进入该页。
2. 让手机、平板、电脑或电视连接同一局域网，在浏览器打开桌面显示的局域网地址；“访问入口”提供复制、打开地址及“扫码访问”。
3. 使用账号密码登录，或在桌面点击“开启配对”，让新设备选择“与桌面配对”并显示六位码，再在桌面输入、核对并批准。
4. 按需勾选“记住此设备”，重启应用后仍可保持登录；桌面的“授权设备”表格分别显示登录类型、最近访问与有效期，行末提供重命名和撤销授权。修改账号或密码会让所有设备重新登录。

配对开启后可“延长配对”或“关闭配对”。关闭会立即作废未完成的配对码，已授权设备仍可正常浏览和播放；需要时可以重新开启。

网页可浏览活动媒体库、搜索影片、查看清单与详情，通过随机发现和近期添加挑选影片。手机可在“浏览范围”切换媒体库或清单；返回列表会恢复浏览位置，剧照可点击预览和缩放。

影片详情可播放浏览器支持的本地视频与直连资源，支持拖动进度和全屏，也可下载本地资源或复制、打开其他链接。不提供转码，能否播放取决于浏览器、设备编码支持和资源可达性。

Web 端只读，编辑、扫描和刮削仍在桌面端完成；网页不使用桌面的 libmpv、本机续播或本地 AI 字幕，也不显示此电脑的“最近播放”。桌面本地网页服务使用 HTTP，需保持应用运行。独立服务端在同一公共端口支持 HTTP 和 HTTPS 网页，共用登录状态；访问入口可选择两种地址。HTTP 仅开放 Web，桌面客户端通信仍强制 HTTPS。HTTP 未加密，只在可信局域网使用，不要映射公网端口；HTTPS 自签证书需浏览器单独信任。已有 Cookie 不做迁移。完整配置、播放限制和网络说明见 [网络与权限](/Javdex/reference/server/)。

## 关闭窗口后保留后台运行

在“设置 → 外观与隐私 → 窗口行为”开启“关闭窗口后最小化到系统托盘”（默认关闭、立即生效）。之后关闭窗口只会隐藏主窗口，网页服务与后台任务继续运行。点击托盘图标或选择“打开主窗口”可恢复；选择“退出 Javdex”或使用系统的退出应用命令会完全退出并停止服务。前台 NFO 导出期间仍需先完成或终止任务。
