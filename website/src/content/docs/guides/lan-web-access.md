## 开启网页服务（桌面本地模式 vs 独立服务端）

### 1. 桌面本地模式下开启
1. 前往 **“设置 -> 网络 -> 网页服务”**。
2. 开启“局域网网页服务”开关。
3. **配置参数**：
   - **服务端口**：默认为 `8096`（支持在 `1024 ~ 65535` 范围内自由修改）。
   - **登录用户名**：默认为 `viewer`。
   - **登录密码**：设置一个长度为 12 ~ 128 位的访问密码（系统会自动进行加盐哈希保护）。
4. 界面上会立即生成当前电脑在局域网中的专用访问地址（如 `http://192.168.1.5:8096`）以及一个**专属连接二维码**。
5. :::note[桌面运行前提]
   桌面本地模式下的网页服务依赖当前 Electron 主进程运行。你可以将桌面端安全最小化到系统托盘，只要电脑未关机休眠，局域网网页便能持续访问。
   :::

### 2. 独立服务端（Docker 容器模式）
- 如果你部署了独立服务端，网页服务默认在容器的 `8096` 端口常驻开放（无需电脑开机）。
- 桌面端连接后，可以在“设置 -> 网络 -> 网页服务”中随时对服务端的网页服务进行一键启闭与密码修改。

## 手机扫码连接与两种认证方式

打开手机相机或浏览器，扫描桌面设置页面中的二维码，即可在手机浏览器打开登录页。

Javdex 支持两种各具优势的认证手段：

### 方式一：6 位动态配对码（免输长密码【最推荐】）
1. 在手机浏览器点击 **“配对连接”**，手机屏幕上会呈现一个 6 位数字配对码（5 分钟内有效）。
2. 同时，你的电脑桌面客户端上会实时弹出一个审批通知：“检测到新的设备请求接入，配对码：XXXXXX”。
3. 在电脑上核对数字一致后，点击 **“批准连接”**，手机端便会瞬间自动登入！

### 方式二：账号密码登入
- 直接输入设置的用户名与密码登入。
- 勾选 **“记住此设备”**，系统会为该浏览器颁发专属的持久化 Session Token，下次打开同一网络下无需重复登录。
- **设备权限集中审计**：在电脑端的“设置 -> 网络 -> 已授权设备”列表中，你可以随时查看所有已登录的手机或电视，并一键踢出或撤销任意设备。

## 移动端、平板与智能电视浏览体验

网页端不仅拥有与桌面端一脉相承的视觉美感，还针对触屏与电视遥控器进行了专属适配：

### 1. 手机与平板触控体验
- **瀑布流与随机发现**：在手机上随时点击“换一批”，快速浏览随机挑选的作品封面与评分。
- **按库与清单筛选**：支持在左侧抽屉中快速切换不同的媒体库或自定义播放列表。
- **原片播放与下载**：点击资源卡片直接播放；若希望将影片缓存至本地，可直接点击“下载原文件”。

### 2. 智能电视遥控器 2D 空间导航
- 在 Android 电视盒子或智能电视（如 Apple TV、小米电视、索尼电视）的浏览器中打开该地址。
- **电视遥控器方向键无缝支持**：
  - 网页内置了精准的二维方向键焦点移动算法。按下遥控器的 `上/下/左/右` 键，焦点会在顶部搜索、侧边栏和主海报网格之间平滑跳转，并以醒目高亮外框提示当前选中项。
  - 按下遥控器 `确定/OK` 键直接打开详情，按下 `返回/Back` 键即可退出全屏或退回上一级。

## 浏览器播放兼容性与局域网安全边界

### 1. 为什么服务端不进行视频转码？
- 传统的转码服务器（如开启转码的 Jellyfin）在面对 4K 10-bit H.265/HEVC 高清影片时，会对服务器 CPU/显卡造成毁灭性的负荷，还会导致严重的发热、画面模糊和电量损耗。
- Javdex 坚持**原画直传**原则。几乎所有近五年的现代手机（iOS Safari、Android Chrome）以及现代智能电视芯片，都原生具备硬解 H.264、H.265/HEVC、AAC 音频的能力。

### 2. 最佳格式建议
- **视频编码**：绝大多数主流格式（`.mp4` 与 `.mkv` 封装的 H.264 / H.265）均可直接在移动端秒开。
- **音频兼容性提示**：若视频内嵌了生僻的 DTS-HD 或未被移动端浏览器原生支持的音频编码，浏览器可能会提示无法解码音轨。此时建议在电脑桌面端使用功能完备的内置 `libmpv` 播放器观看。

### 3. RFC1918 局域网安全沙箱
- 网页服务内置了严格的网段白名单过滤机制（`isLocalPeer`），仅允许同一本地回环（`127.0.0.1`）以及标准局域网私有 IP（`192.168.x.x`、`10.x.x.x`、`172.16.x.x ~ 172.31.x.x`）访问，坚决拒绝来自公网的非法嗅探与跨站利用（CSRF）。
