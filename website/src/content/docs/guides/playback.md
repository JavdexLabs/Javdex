Javdex 默认使用基于 **libmpv** 的内置播放器，支持本机与远程资料库的文件资源。解码和字幕处理在桌面端完成，硬件加速使用当前运行库和设备实际支持的能力。

---

## 内置 `libmpv` 渲染架构与三态视图

macOS 默认将 libmpv 输出经 IOSurface 与 Electron 共享纹理绘制到 Canvas2D，画面和 HTML 控件在同一窗口合成，无需试验启动参数；Windows 默认使用 D3D11 共享纹理到 Canvas。三个平台均提供 CPU 兼容 Canvas，影片解码不由 HTML `<video>` 承担。

Windows 与 macOS 在检测到显卡／驱动不支持当前播放路径或发生可检测的图形故障时，自动切换到 CPU 兼容播放，并恢复播放位置、暂停状态、音量、倍速和字幕。播放信息中会显示“CPU 兼容（自动回退）”；本次应用运行保持 CPU 模式，重启后重新尝试 GPU。启动参数 `--javdex-cpu` 可强制选择 CPU 兼容模式。CPU 兼容模式按实际显示尺寸绘制，高分辨率、高帧率影片的流畅度取决于 CPU 性能；媒体、授权或音频错误不会触发图形回退。

macOS 当前输出为 8-bit SDR，不提供 HDR 直通保证。GPU 共享帧引用的完成与释放受三槽上限约束；自动回退时也不强行回收未确认引用。页面关闭、CPU 自身故障或驱动完全挂死时不保证进程内恢复。GPU 默认路径保持不变，新增 CPU 兼容路径不代表播放性能提升。

播放器支持三种自如切换的呈现形态：

### 1. 展开模式 (`expanded`)
- 点击影片即可在主界面弹出大画幅播放视口。
- 顶部常驻控制栏（收起到底栏、停止播放），中央为主画面，右侧为快捷设置抽屉（音轨、字幕、AI 选项），底部为进度条与播放工具栏。

### 2. 底部画中画迷你小窗 (`docked`)【边看边整理】
- 点击左上角“收起”，播放器会以流畅动画收缩至应用最底部的横条形小窗。
- 视频画面继续以微缩画中画实时无卡顿播放，音频保持流畅。此时你可以自由浏览媒体库、筛选其他影片、编辑演员档案或修改标签。
- 点击迷你小画幅上的任意位置，播放器瞬间恢复为展开大画面；点击“停止播放”则彻底关闭并释放底栏空间。

### 3. 沉浸式全屏模式 (`fullscreen`)
- 双击视频画面，或按下键盘 `F` 键即可进入系统级全屏。
- **智能自动隐退**：全屏状态下只要鼠标指针静止超过 `3 秒`，顶栏与底栏会自动淡出隐藏，带来极致的沉浸体验；轻轻晃动鼠标或触碰顶部 64px / 底部 96px 感应区即刻重新显现。

## 音轨、内嵌/外挂字幕、章节与倍速控制

内置播放器在右侧抽屉与工具栏提供了专业播放器水准的控制项：

- **音轨与内嵌字幕切换**：
  - 自动识别多音轨与多字幕轨道，在“播放设置”抽屉中一键点选切换或关闭。
  - 完美支持 **SRT / WebVTT** 纯文本字幕、**ASS / SSA** 高级特效字幕（完整保留字体、位置与色彩特效），以及 **PGS** 原生图形字幕。
- **加载本机外挂字幕**：
  - 点击“选择本机外挂字幕”，可自由选择 `.srt`, `.ass`, `.ssa`, `.vtt`, `.sub`, `.sup` 格式文件实时加载。
- **文本字幕字号与延迟微调**：
  - 对于纯文本字幕，提供 5 档预设字号切换（`30 | 40 | 55 | 70 | 85`）。
  - 支持在 `-60秒 ~ +60秒` 之间以 `±0.5秒` 步进精确微调字幕时间轴同步。
- **倍速与章节选择**：
  - 支持 `0.5x | 0.75x | 1x | 1.25x | 1.5x | 2x | 3x` 无失真变速变调播放。
  - 如果视频内嵌了时间章节（Chapters），可通过章节下拉菜单直接跳转目标精彩片段。

## 本机续播进度记忆

- **自动保存**：当在设置中开启“保存续播进度”后，只要播放有效时长超过 `5 秒`，系统会自动将精确的播放进度记录在本地缓存中。
- **智能清除**：当一部影片播放至距结尾不足 `30 秒` 时，系统会自动判定为你已完整观影完毕，下次打开将自动从片头开始，避免遗留无意义的片尾进度。
- **贴心继续播放提示**：再次打开有续播记录的影片时，底部会浮现友好提示栏：`上次播放到 45:12`，你可以点击 **“继续 45:12”** 快速跳入，或者点击 **“从头播放”**。

## 远程资料库原画直连流 (`PlayGrant`)

当你的桌面端连接到远程 Docker 服务端时，视频播放体验与本地文件几乎完全一致：

1. **零转码原画直传**：
   - 服务端绝不对视频进行高损耗、高延迟的 CPU 实时转码。
   - 桌面端播放时，服务端会签发一份带有时效认证的 `PlayGrant` 安全播放令牌。
2. **本地硬件加速解码**：
   - 桌面端内置的 `libmpv` 通过 HTTP 流分段读取原始媒体，并根据本机设备能力进行硬件或软件解码；服务端负责文件读取与网络传输，桌面 CPU 兼容模式的解码和绘制也在本机完成。

## 指定外部播放器与故障回退

如果你偏好使用 PotPlayer、IINA、VLC 或 mpv 等成熟的第三方独立播放器：

1. **设置全局外部播放偏好**：
   - 前往“设置 -> 存储 -> 资料库模式 -> 播放设置”，将播放器选项由“内置播放器”切换为“外部播放器”。
   - 浏览选择你的播放器 `.exe` 可执行文件路径（macOS 下选择 `.app` 包路径），或直接选择“使用操作系统默认”。
2. **单次临时指定播放方式**：
   - 在任意影片详情页的资源卡片右侧菜单，直接点击 **“使用外部播放器打开”**，即可单次脱离内置播放器启动第三方软件，这不会修改你的默认播放偏好设置。
3. **播放异常无缝回退**：
   - 若内置播放器在面对极端生僻编码或音频格式时发生解码错误，播放界面会立即呈现友好的故障卡片，并提供 **“改用外部播放器打开”** 快捷按钮，无需重新去文件管理器翻找目录。
