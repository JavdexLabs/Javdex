清单（Playlists）能够打破媒体库的物理边界，将分散在不同分类或磁盘中的影片按专题、心仪程度或观看计划自由组合在一起。结合 Javdex 强大的端侧与云端 Agent 平台，你还能直接从网页中批量抓取并收录外部推荐榜单。

---

## 内置清单、自定义清单与本机“最近播放”

Javdex 在左侧导航栏的“播放列表”分组中，预置了三类不同生命周期的清单：

### 1. 系统内置清单（Built-in Playlists）
- **`我喜欢` (Favorites)**：在任意影片卡片或详情页点击心形图标即可快速加入或移出。
- **`稍后观看` (Watch Later)**：专为待看计划设计。进入“稍后观看”清单详情页，可按需开启**“播放后自动移出（`remove_after_play`）”**开关。开启后，只要在内置播放器中打开过该影片，系统就会自动将其从清单中移出，保持待看清单清爽。

### 2. 自定义主题清单（Custom Playlists）
- 点击左侧“播放列表”旁的 `+` 按钮即可创建自定义清单（如“2026 年度最佳”、“高分神作”、“睡前精选”等）。
- 支持自定义清单封面图片、填写长篇专题简介、添加外部参考链接，并在清单内部对收录作品自由拖拽重新排序。

### 3. 本机专属虚拟列表：“最近播放”
- 侧边栏列表中的 **“最近播放”** 是一个特殊的本地虚拟视图（`RECENT_PLAYBACK_LIST_ID = 0`）。
- **技术特性**：
  - **当前电脑隔离**：仅保存在当前使用的这台电脑上（每个资料库最多保留 `1000` 条记录或 `8 MiB` 缓存）。
  - **不跨端同步**：连接远程服务端时，最近播放不会同步至服务器或其他设备，也不会被纳入资料库备份包中，最大程度保护隐私。
  - 支持在列表顶部随时点击“清空记录”。

## 配置“媒体库整理 Agent”模型服务

当遇到冷门影片或非标准页面、传统插件无法抓取时，Javdex 提供了由大语言模型（LLM）驱动的智能 Agent 平台。

要启用这些高级采集功能，请先前往 **“设置 -> AI 服务 -> 功能”**：
1. 在 **“媒体库整理 Agent (`library-curator`)”** 选项中，为其指派一个可用的大模型。
2. 推荐选择具有强大指令遵循与上下文解析能力的模型（如 Claude 3.5 Sonnet、GPT-4o、DeepSeek-V3 等）。
3. 前往“服务商”标签页填入对应平台的 API Base URL 与密钥并完成连接测试。

## 单页 AI 辅助采集（Agent 刮削）

对于没有公开插件支持的小众发布站、厂商独立专题页或博客推荐页：

1. 进入库内某部未刮削的影片或演员详情页。
2. 点击右上角菜单中的 **“Agent 刮削”**。
3. 粘贴目标网页的完整 URL 地址。
4. **Agent 执行流程**：
   - 客户端后台启动受控的隔离浏览器会话，静默抓取目标页面 HTML 与视觉布局。
   - 大模型自动解析页面内容，精准提取番号、标题、简介、制作商、演员阵容与高清封面链接。
5. **人工预览确认**：
   - 解析完成后，系统会弹出字段级对比框，清晰标注 AI 提取到的每项数据。
   - 勾选你需要采纳的字段，点击“应用到影片”，即可将资料安全写入资料库。

## 从外部网页批量导入播放列表

看到网络上的精选推荐贴或年度榜单页面时，你可以直接让 AI 帮你批量“抄作业”：

1. 点击左侧工具栏底部的 **“媒体库整理”**（`/library-curator`），选择 **“从外部网页导入清单”**。
2. 输入外部清单或排行的网页 URL，并选择目标媒体库。
3. **AI 自动抓取与匹配引擎**：
   - 整理 Agent 会自动识别网页的结构化列表，甚至自动执行翻页滚动，识别出所有出现的番号列表。
   - 系统将抓取到的番号与库内已有影片进行实时比对：
     - 若库内已有唯一匹配，直接关联合适的影片。
     - 若发现多部同番号作品或存在歧义，弹出对比卡片由你手动核对选择。
4. **生成“无资源影片”占位**：
   - 对于外部榜单中出现、但你本地尚未下载的影片，你可以勾选**“自动创建为无资源条目”**。
   - 系统会在库内先行建立该影片完整的资料、海报与简介档案（但没有挂载本地视频文件）。未来一旦你下载了该文件并执行扫描，系统便会自动与其对齐绑定，无需重复刮削！

:::note[远程模式说明]
连接独立服务端使用此功能时，系统会在目标远程媒体库中创建对应的影片资料档案。当前暂不支持向服务端追加到已有自定义清单中。外部清单导入仅同步资料与结构，不会下载外部视频实体文件。
:::
