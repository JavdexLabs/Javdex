在家庭、合租宿舍或办公室等可能有人经过的场合使用媒体库，视觉敏感内容的外露可能引发尴尬。此外，许多用户也不希望磁盘里的高清封面被系统相册或其他扫描软件意外读取。

Javdex 在客户端提供了完善的**界面防窥遮罩**与底层**图片磁盘级加密**双重防护。

## 防窥模式（Privacy Mode）与 7 项细粒度遮罩

前往 **“设置 -> 外观 -> 防窥模式”**。你可以打开防窥总开关，并根据具体场景自由组合开启以下 7 项细粒度遮罩：

1. **遮盖影片封面**：列表与卡片中的封面海报全部替换为优雅的暗色磨砂占位卡片，仅保留番号与片名文字。
2. **遮盖影片详情背景**：进入详情页时，不渲染大面积的高清半透明主题背景图。
3. **遮盖影片样张**：详情页底部的剧照样张画廊默认全部模糊遮罩，鼠标悬停时才显现。
4. **替换演员头像**：将所有女演员的真实头像替换为抽象的极简剪影图标。
5. **遮盖演员写真**：进入演员详情页时，写真画廊默认进行马赛克打码遮罩。
6. **遮盖分类与清单封面**：片商、系列以及自定义播放列表的封面图片进行模糊隐藏。
7. **禁用大图预览灯箱**：在界面上点击任何缩略图都不会弹出高分辨率大图预览灯箱。

:::tip[快捷防窥]
防窥模式纯粹改变界面的呈现渲染逻辑，不会修改或破坏数据库中的真实图片数据。当环境安全时，只需在设置中关闭开关，一切高清画面便会瞬间恢复原貌。
:::

## 图片资源 AES-256-GCM 磁盘加密 (`.javdexenc`)

许多系统相册（如 Windows 照片、macOS 相册）或第三方云同步盘会自动扫描并备份磁盘中的图片，极易造成隐私泄露。

Javdex 提供了高安全等级的底层**静态图片加密（At-Rest Asset Encryption）**机制：

### 1. 技术实现细节
- 前往 **“设置 -> 存储 -> 图片资源”**，开启 **“图片磁盘加密”**。
- 系统会在应用根目录安全生成一个专属的 32 字节主密钥文件（`.media_assets_key`）。
- `media_assets/` 目录下的所有封面、剧照与头像文件在写入磁盘时，都会通过 **AES-256-GCM** 算法加密为 `.javdexenc` 二进制密文文件。
- 操作系统自带的相册、看图软件、缩略图提取器由于没有密钥，无法预览这些图片中的任何内容。

### 2. 应用内无感透明解密
- Javdex 客户端与局域网 Web 服务在读取图片时，会在内存管道中根据 `.media_assets_key` 自动进行瞬时解密渲染。
- 软件内部的浏览速度与明文存储几乎完全一致，对日常观影体验毫无负面影响。

### 3. 加密边界与密钥安全说明
- **加密范围**：磁盘加密**仅针对图片资源（海报、样张、头像）**，不会加密庞大的原始视频文件。
- **密钥保管**：请妥善备份 `<userData>/.media_assets_key`。如果该密钥丢失，已加密的 `.javdexenc` 图片将永远无法被解密。

## 迁移本地图片存储目录

随着收集的影片增多，高清封面、背景图与海报所占用的空间可能会达到数十 GB，容易撑满系统盘（如 C 盘）：

1. 前往 **“设置 -> 存储 -> 图片资源”**。
2. 在“存储路径”栏，系统会显示当前图片库所占用的精确磁盘空间与绝对路径（默认位于 `<userData>/media_assets`）。
3. 点击 **“更改存储位置”**，选择其他拥有充裕可用空间的大容量磁盘分区（如 `E:\JavdexData\Images`）。
4. **系统自动原子迁移流程**：
   - Javdex 会在后台自动完成历史文件的完整复制、哈希比对校验与新路径绑定。
   - 确认全部文件在新位置完好无损后，系统会自动清理原目录中的历史冗余文件，全程无需手动复制粘贴。
