---
title: "遇到问题"
description: "Javdex 0.9.0-beta.6 · 遇到问题"
---

| 现象 | 先检查 |
|---|---|
| 扫描后找不到影片 | 当前媒体库、来源目录是否启用且可访问、扫描结果、最小时长设置与待确认项 |
| 刮削来源不可用 | 来源是否配置完成、网络是否可访问、组合来源的字段分配是否有效 |
| Agent 采集或清单导入无法开始 | 是否已添加支持工具调用的可用模型，并保存默认模型或对应助手用途配置；本地字幕模型不能代替 Agent 模型 |
| 内置影片无法播放 | 所选资源是否为可访问的影片文件、安装包是否含匹配运行库；Linux 是否显式启用 X11／XWayland；远程连接与授权是否有效。可重试同一资源或显式外部打开 |
| 外部播放或链接打不开 | 播放器程序路径是否有效；远程文件是否使用支持网络播放的程序，网页或 Magnet/ED2K 是否有对应应用 |
| AI 字幕或本地翻译不可用 | “功能”页的模型与精度是否已保存；对应文件和运行依赖是否“可运行”，系统、内存是否满足要求；先校验与修复，再查看字幕日志或错误详情 |
| 最近播放或续播没有出现在另一台设备 | 两者均只在当前电脑保存，按资料库身份区分，不会同步；最近播放记录开始播放，不表示已看完，也不等于续播进度 |
| 远程资料库连不上 | 服务是否在运行、地址是否可访问、桌面与服务版本是否相同；版本不符或缺少写入凭据时按界面提示处理，不会自动改回本机库 |
| 导出后目标软件没变化 | 是否跳过了已有文件、目标软件是否启用本地资料并刷新，以及兼容性说明中的限制 |
| 归档后侧栏找不到媒体库 | 在“设置 → 媒体库”选择归档库并恢复 |

仍无法解决时，请 [提交 Issue](https://github.com/JavdexLabs/Javdex/issues/new)，附上应用版本、操作系统、复现步骤及界面显示的错误。分享日志或截图前隐去令牌、私人路径和不希望公开的资料。
