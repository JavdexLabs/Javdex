## 桌面端全局导航与列表多选快捷键

| 操作场景 | Windows / Linux 快捷键 | macOS 快捷键 | 鼠标与触控板操作 | 具体行为说明 |
| :--- | :--- | :--- | :--- | :--- |
| **全局跨库搜索** | `Ctrl + K` | `Cmd + K` | 点击侧边栏“搜索” | 打开全局搜索页（`/search`）；若已在搜索页则直接聚焦并全选顶部搜索框。 |
| **历史后退** | `Alt + ArrowLeft` | `Cmd + [` | 鼠标侧键后退 (`BrowserBack`) / 触控板双指右滑 | 返回栈后退上一页（编辑输入框、全屏播放器或弹窗打开时不误触）。 |
| **历史前进** | `Alt + ArrowRight` | `Cmd + ]` | 鼠标侧键前进 (`BrowserForward`) / 触控板双指左滑 | 返回栈前进下一页。 |
| **连续范围多选** | `Shift + 左键点击` | `Shift + 左键点击` | 按住 `Shift` 点击首尾卡片 | 在影片列表或演员列表中，一次性选中上一次点击项与当前点击项之间的全部条目。 |

## 内置播放器 (`libmpv`) 键盘与鼠控快捷键

当内置播放器处于**展开模式 (`expanded`)** 或 **全屏模式 (`fullscreen`)** 时（且焦点不在输入框或下拉菜单上），支持以下操作：

| 功能 | 键盘快捷键 | 鼠标交互动作 | 具体行为说明 |
| :--- | :--- | :--- | :--- |
| **播放 / 暂停** | `Space`（空格键） | 单击视频画面区域 | 切换播放与暂停；若影片已播放结束，按空格或单击画面将从头重新播放。 |
| **恢复展开视图** | — | 单击底部迷你播放器 (`docked`) 小视频画面 | 从底栏画中画迷你模式立即恢复为展开大画面。 |
| **快退 5 秒** | `ArrowLeft`（左方向键） | — | 向后跳转 `5 秒`（最小至 `0s`）。 |
| **快进 5 秒** | `ArrowRight`（右方向键） | — | 向前跳转 `5 秒`（最大至视频总时长）。 |
| **大幅快退 30 秒** | `Shift + ArrowLeft` | — | 按住 `Shift` + 左方向键，向后大幅跳转 `30 秒`。 |
| **大幅快进 30 秒** | `Shift + ArrowRight` | — | 按住 `Shift` + 右方向键，向前大幅跳转 `30 秒`。 |
| **静音 / 取消静音** | `M` 或 `m` | 点击底栏音量图标 | 切换静音状态，取消静音时恢复此前音量百分比。 |
| **切换全屏模式** | `F` 或 `f` | 双击视频画面区域 | 在展开视图（`expanded`）与系统级全屏（`fullscreen`）之间切换。全屏下鼠标静止 `3 秒` 自动隐藏顶栏与底栏。 |
| **逐级退出 / 收起** | `Escape` | 点击左上角“收起”或“退出全屏” | 按优先级依次执行：① 若右侧“播放设置”抽屉打开则先关闭抽屉 $\to$ ② 若处于全屏则退回展开模式 $\to$ ③ 若处于展开模式则收起至底部迷你播放器（`docked`）。 |

## 图片预览灯箱 (Lightbox) 缩放与浏览控制

在影片详情页点击封面/样张、或在演员详情页点击写真打开高清大图预览灯箱（`ImagePreviewLightbox.tsx`）时：

| 功能 | 键盘快捷键 | 鼠标操作 | 具体行为说明 |
| :--- | :--- | :--- | :--- |
| **上一张 / 下一张** | `ArrowLeft` / `ArrowRight` | 点击左右箭头，或在 `100%` 默认缩放下左右拖拽超过 `56px` | 在当前图片集合中循环切换上一张或下一张图片。 |
| **缩略图条横向滚动** | — | 在底部缩略图导航条上滚动鼠标滚轮 | 将垂直滚轮动作自动映射为缩略图条的横向平滑滚动。 |
| **放大 / 缩小图片** | `+` / `=`（放大）<br/>`-` / `_`（缩小） | 在画面区域向上 / 向下滚动鼠标滚轮 | 以 `0.15x` 步进自由缩放图片，支持范围 **`0.5x ~ 5.0x`**（`50% ~ 500%`）。 |
| **平移查看细节** | — | 放大（`> 100%`）后按住鼠标左键拖拽 | 自由平移放大后的高清画面细节。 |
| **重置 100% / 快速 200%** | `0`（重置为 `100%`） | 双击图片画面 | 按键盘 `0` 重置为 `100%` 居中；鼠标双击图片在 `100%` 与 `200%` 之间快速切换。 |
| **关闭预览灯箱** | `Escape` | 点击右上角关闭按钮或黑色背景遮罩 | 退出大图预览灯箱。 |

## 局域网 Web 端与智能电视方向键导航

在手机、电脑浏览器或智能电视（TV 端）访问局域网网页端（`apps/web/src/navigation.ts`）时：

| 按键 | 适用场景 | 具体行为说明 |
| :--- | :--- | :--- |
| `/`（斜杠键） | 网页浏览任意页面 | 立即聚焦并选中顶部搜索输入框（`#web-search`）。 |
| `ArrowUp` / `Down` / `Left` / `Right` | 智能电视遥控器 / 键盘导航 | 激活 **2D 空间几何焦点导航算法**，跨顶部搜索栏、左侧边栏与主内容海报网格智能计算最近邻元素并移动焦点（电视端支持开机自动落焦）。 |
| `Enter` / 遥控器 `OK` 键 | 智能电视遥控器 / 键盘导航 | 打开当前焦点所在的影片、演员、清单或触发按钮动作。 |
| `Escape` / 遥控器 `返回` 键 | 播放中或详情页 | 若焦点在 `<video>` 播放器内，退回详情页返回按钮；若在详情页，直接返回上一级浏览列表。 |
