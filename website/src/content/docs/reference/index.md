## 不同端的能力

桌面内置播放在这台电脑使用 libmpv 解码；网页使用浏览器自身支持的格式；服务端提供原文件而不转码。本机最近播放、续播和本地 AI 推理不会因连接远程资料库而自动同步到其他设备。

具体操作见[播放指南](/Javdex/guide/playback/)与[网页访问](/Javdex/guide/web/)。技术实现合同和历史验证记录继续保存在 GitHub 仓库，不自动收录到本站搜索。
