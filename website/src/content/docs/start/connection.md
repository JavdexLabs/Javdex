---
title: "选择本地或远程资料库"
description: "Javdex 0.9.0-beta.4 · 选择本地或远程资料库"
---

只在一台电脑使用时，保留默认本地模式即可。希望 NAS 或常开电脑持续扫描并提供网页访问时，先按 [单容器部署步骤](/Javdex/server/deploy/) 启动同版本服务，再连接桌面；已有 0.8.0 部署先读[采用托管更新](/Javdex/server/adoption/)。媒体配置见 [服务端指南](/Javdex/reference/server/#媒体目录权限)。浏览器只用于浏览和播放，资料管理仍使用桌面应用。

使用新 Compose 示例的统一 HTTPS 地址时，请部署者在服务机器运行 `pair`，按[配对说明](/Javdex/server/pairing/)生成一次性配对 JSON。打开桌面“设置 → 存储与导出 → 资料库连接”，粘贴完整信息，点击“配对并保存连接”并重启。地址、证书指纹、资料管理和更新授权一次保存；无需先手动填写地址或测试连接。每台电脑重新生成一份配对信息，已有电脑继续可用；网页账号密码不能代替桌面授权。

旧双端口部署未设置 `JAVDEX_PUBLIC_URL` 时，仍在“手动连接与本地模式”选择远程资料库，填写业务地址、测试连接、保存并重启，再按[旧部署授权流程](/Javdex/server/pairing/)领取凭据。测试只读取公开连接信息，不验证写入凭据，也不能在尚未保存证书指纹时验证新部署的自签 HTTPS 证书。切回本地也使用此折叠区；切换连接不会复制资料，仍记住上次填写的服务器地址。

页面的“正在使用”显示当前会话，保存后另行显示重启后将使用的资料库。远程模式使用同一套管理界面，不再打开本机 `library.db`，也不在本机恢复扫描或启动网页服务。插件、采集助手和头像裁切仍在这台电脑上运行。“图片资源”显示服务端当前目录，由服务端部署配置管理；本机图片目录和加密设置不会随模式切换而改变。

远程媒体库添加目录时，从服务端配置的挂载（示例为 `library`）及其子目录中选择，不使用这台电脑上的路径。默认使用内置播放器播放本机及服务端影片文件，外部程序的配置见 [选择默认播放方式](/Javdex/guide/playback/#选择默认播放方式)。

桌面与服务必须是同一应用版本；连接设置显示桌面版本，以及服务端握手返回的版本，便于核对。版本不一致时不会写入远程资料库，也不会自动改连其他地址。工作记录尚未复制完成时，先回到本地模式完成准备，不要在远程模式打开原库。配对失效时由管理员重新运行 `pair`；全部设备遗失才使用会撤销旧授权的 `pair-recover`，见 [配对与客户端使用](/Javdex/server/pairing/)。同一局域网的只读网页见 [局域网浏览与播放](/Javdex/guide/web/)。

远程模式沿用这台电脑上的 `desktop-work.db`。该文件在任意桌面首次启动时就会建立，不依赖是否切换远程，见 [数据保存在哪里](/Javdex/reference/data/)。它不是服务端资料库的副本；服务端备份只包含正式资料和正式图片，不含此电脑上的 Agent 运行记录和草稿。
