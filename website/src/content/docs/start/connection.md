---
title: "选择本地或远程资料库"
description: "Javdex 0.9.0-beta.6 · 选择本地或远程资料库"
---

只在一台电脑使用时，保留默认本地模式即可。希望 NAS 或常开电脑持续扫描并提供网页访问时，先按 [单容器部署步骤](/Javdex/server/deploy/) 启动同版本服务，再连接桌面；已有 0.8.0 部署先读[采用托管更新](/Javdex/server/adoption/)。媒体配置见 [服务端指南](/Javdex/reference/server/#媒体目录权限)。浏览器只用于浏览和播放，资料管理仍使用桌面应用。

在服务机器运行 `token` 获取一次性令牌，见[令牌与客户端使用](/Javdex/server/pairing/)。打开桌面“设置 → 存储与导出 → 资料库连接”，选择远程资料库，填写统一 HTTPS 地址、粘贴令牌并完成授权。地址与设备授权一起保存，重启后生效；每台电脑获取独立令牌，已有设备继续可用。

本地与远程模式的切换入口始终显示。远程只提供手动连接，地址、连接测试与一次性令牌授权放在一起，不再切换连接方式。首次自动接受并保存证书；合法公开 HTTPS 证书正常校验及续期无需确认，自签名证书指纹变化时显示新旧指纹，确认后继续连接。证书规则同时适用于业务、图片、播放和更新。测试只读取公开连接信息，不授予管理权限。切换连接不会复制资料；本机资料导入提示仅在当前远程连接和写入授权都正常后展示。

页面的“正在使用”显示当前会话，保存后另行显示重启后将使用的资料库。远程模式使用同一套管理界面，不再打开本机 `library.db`，也不在本机恢复扫描或启动网页服务。插件、采集助手和头像裁切仍在这台电脑上运行。“图片资源”显示服务端当前目录，由服务端部署配置管理；本机图片目录和加密设置不会随模式切换而改变。

远程媒体库添加目录时，从服务端配置的挂载（示例为 `library`）及其子目录中选择，不使用这台电脑上的路径。默认使用内置播放器播放本机及服务端影片文件，外部程序的配置见 [选择默认播放方式](/Javdex/guide/playback/#选择默认播放方式)。

桌面与服务必须是同一应用版本；连接设置显示桌面版本，以及服务端握手返回的版本，便于核对。版本不一致时不会写入远程资料库，也不会自动改连其他地址。工作记录尚未复制完成时，先回到本地模式完成准备，不要在远程模式打开原库。授权失效或设备遗失时由管理员运行 `token` 获取新令牌，授权新设备后按需撤销旧设备，见 [配对与客户端使用](/Javdex/server/pairing/)。同一局域网的只读网页见 [局域网浏览与播放](/Javdex/guide/web/)。

远程模式沿用这台电脑上的 `desktop-work.db`。该文件在任意桌面首次启动时就会建立，不依赖是否切换远程，见 [数据保存在哪里](/Javdex/reference/data/)。它不是服务端资料库的副本；服务端备份只包含正式资料和正式图片，不含此电脑上的 Agent 运行记录和草稿。
